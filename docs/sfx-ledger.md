# 音效账本（D-198）

声音桥用的八条音效：原件 YIDI 下，放仓库根 `sfx/`（不进版本库）；CC1 转成 `public/sfx/<名>.m4a`（单声道 AAC 48 kbps）上线。

**只收 CC0 或 Pixabay 内容许可**（D-198）。BBC 音效库是非商用许可，不用。

**来源和许可（D-202）**：YIDI 说八条**全部是 Pixabay Sound Effects 下的**，许可栏一律填 Pixabay 内容许可。原件元数据是空的、下载链接没存，链接栏先写「Pixabay，链接未存」，YIDI 有下载记录再补，**不卡上线**。BGM 那四首的来源仍是欠账（D-179），不在这张表里。
