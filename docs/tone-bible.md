# tone-bible：基调守则

> 《吾则天》全体成员必读，ChatGPT 每次动笔前重读一遍。
> 理论依据见 `吾则天-女性主义精神指南.md`。这份文件只讲怎么做，不讲为什么；想知道为什么就去读那一份。
> 与任何其他文档冲突时，本文件在内容与基调上优先，仅次于 `00-指挥日志.md`。

---

## 一句话

**她的胜利不是把男人的王座换个人坐，而是让王座本身变了形状。**

## 一、四张正负例清单

### 1.1 主角

| 不要 | 要 |
|---|---|
| 因为受过男人的伤才变强 | 她本来就有野心、有欲望、有判断 |
| 「我和那些女人不一样」 | 她知道自己和那些女人处境相同，只是选择不同 |
| 用男人的方式证明自己（更狠、更冷、更能打） | 用她自己的方式赢：诗、判断力、人脉、耐心、对人心的理解 |
| 孤胆英雄，谁都不信 | 她有一张网，网里全是女人 |
| 一路正确，观众只能崇拜 | 她会错、会后悔、会被拒绝，观众能理解她 |
| 悲情、苦大仇深、隐忍到底 | 有力量感，会笑，会享受，会说「我要」 |

### 1.2 女性角色与关系

| 不要 | 要 |
|---|---|
| 其他女人是障碍、情敌、工具人 | 每个重要女性角色有自己的欲望和轨迹，不围着主角转 |
| 女人之间的冲突是争宠 | 冲突是价值冲突（忠于旧制还是改制、家族还是自我） |
| 好感度等于攻略进度条 | 关系是双向的，对方可以离开、拒绝、反对 |
| 恋爱是奖励 | 恋爱是关系的一种，和盟友、师徒、对手一样有分量 |
| 「百合」当卖点，关系只为了好看 | 她们的关系有政治后果：会被弹劾、会被利用、也会改变权力格局 |
| 一个完美恋人 | 至少一个恋人和她在根本问题上意见不合 |

### 1.3 权力与结局

| 不要 | 要 |
|---|---|
| 登基等于通关等于唯一真结局 | 多个平等结局，登基只是其中一个 |
| 赢了之后一切照旧，只是龙椅上换了个人 | 赢了之后规则变了：女子科举、女冠入朝、无字碑 |
| 通过踩人往上爬 | 至少一半的上升是「让别人也站起来」 |
| 复仇是主要驱动力 | 建造是主要驱动力 |
| 失败结局是惩罚 | 失败结局是另一种人生：退隐、办学、流亡但自由 |

### 1.4 文本与时代

| 不要 | 要 |
|---|---|
| 唐朝人说现代女性主义口号 | 她们说唐朝人的话，做唐朝人能做的反抗 |
| 用现代价值观俯视古人 | 尊重她们的处境，在处境里找到力量 |
| 说教 | 让玩家自己得出结论 |
| 男人全是坏人 | 男人是背景。有的好、有的坏、都不是重点 |

## 二、六个自审问题（每章交付必须附自答）

1. 这一章里，主角最重要的一步是靠谁？如果答案是一个男人，重写。
2. 这一章里有没有女人之间的冲突？冲突的原因是价值观还是争宠？
3. 这一章有没有一个「无用」的场景，不加数值、不推剧情、只是两个人在一起？
4. 主角这一章做的事，换成一个男主角会不会一模一样？如果会，问题在哪。
5. 有没有让玩家觉得「她赢了但她变成了她讨厌的人」的风险？如果有，是故意的吗？
6. 一个 2026 年的拉拉朋友玩到这一章，会不会觉得「这是写给我的」？

**第 3 问在数据格式里是有字段的。** 场景表的「无用场景」列填「是」的那一个，就是这一问的答案。校验工具会检查每一幕至少有一个，缺了会报警告。这条最容易在赶工时被丢掉，所以让机器盯着，见 `story-schema.md` 第四部分第 5 条。

## 三、六段样本文本

每组一正一反，都在唐代宫廷语境里。反例后面标出问题，照着这个尺度写。

### 3.1 主角与女官初见

**正例**

> 女官把砚推过来半寸，停住。
> 「才人识得这方砚么？」
> 她没有去看砚，看的是那只手——指节上有旧茧，是常年握笔的人。
> 「不识。」她说，「但识得用它的人。这半寸推过来，是要我说错。」
> 女官笑了一下，把砚收了回去。
> 「你会在这里活得久。」
> 「承教。」

**反例**

> 她慌忙起身，深深拜下去：「婢子愚钝，从未见过这样贵重的东西，还请姑姑教我。」
> 女官看着她眼里的怯，忽然觉得这女孩和别的才人不一样——别人只会争宠，她却懂得低头。

反例的问题：**主角靠自贬求生存**，第一句就把自己放到了地上。**「和别的才人不一样」是内化的厌女**，用贬低其他女人来抬高主角，精神指南第 1 节点名批过。而且这句评价出自对方之口，等于**她的价值要由别人来认证**。

### 3.2 主角被羞辱后的反应

**正例**

> 内侍当众念她的名字，把「添」字念得很重，像在念一件添头。廊下有人笑。
> 她等笑声停了，才把袖子理平。
> 那天夜里她点了灯，把今天在场的人一个一个写下来。谁笑了，谁没笑，谁看了别处。
> 名单收进箱底。
> 笑是不要钱的，她想，我记下来也不要钱。

**反例**

> 她死死咬住嘴唇，不让眼泪掉下来。回到房里，她把被子蒙在头上，哭到天亮。
> 第二天对着铜镜，她发下毒誓：总有一天，要让今天笑过我的人，全都跪在我面前。

反例的问题：**苦情**，把受辱写成一场表演式的痛苦。**复仇成了主要驱动力**，而不是建造。**「跪在我面前」是纯粹的 power-over**，她想要的东西和羞辱她的人想要的东西一模一样，那她赢了也只是换了个人坐。

### 3.3 主角与恋人的「无用」场景

**正例**

> 夜里下了点雨。两个人谁都没提白天的事。
> 她把灯挑亮一点，念了半句：「至近至远东西。」
> 「至深至浅清溪。」那人接了下半句，又说，「李冶的。你念得比她慢。」
> 「我念得比她高兴。」
> 雨还在下。她们把那首诗从头到尾念了两遍，没有第三遍，也没有别的事发生。

**反例**

> 好感度已满。她推门进去，那人正等在里面。
> 「我等你很久了。」
> 屏风倒下，烛火灭了。
> 【解锁 CG：海棠春】

反例的问题：**把关系写成了攻略奖励**，好感度是进度条，恋人是兑换物。**关系是单向的**，对方唯一的动作就是等着被解锁。**这一场没有她自己的欲望**，只有玩家的收集欲。

正例里那句「至近至远东西，至深至浅清溪」出自唐代女冠诗人李冶的《八至》，是真诗，可以放心用。**唐代女性文化不需要我们发明，只需要打捞。** 薛涛、鱼玄机、李冶、上官婉儿都是现成的资源。

## 四、常见失败模式速查

写完一章，对着这张表扫一遍。

| 症状 | 说明 |
|---|---|
| 隐形男性保护者 | 她的每一步背后都有一个男人在托底。这是「大女主剧」最典型的病 |
| 斗争矛头指向同性 | 一路打的都是女人，最后的胜利是获得某个男人的宠爱 |
| 现代口号硬塞 | 让唐朝人说 2026 年的宣言，玩家立刻出戏 |
| 喊口号但没有处境 | 主角「不一定完美，但一定正确」。她需要有代价、有误判 |
| 什么都得靠自己 | 这是孤胆英雄叙事的翻版。允许她依赖、求助、被照顾，只要对象不是隐形男性保护者 |
| 女性化劳动被当作弱 | 护理、教导、陪伴在这个游戏里要有分量 |
| 只有压抑没有明亮 | 八个场景里有黄昏的诗社、有漫射光的女冠观。整章看下来只有阴雨，基调就跑了 |

最后一条同时是美术要求，见 `art-style` 的禁止项。

## 五、交付规则

ChatGPT 每次交付，末尾必须附上这一段，一个都不能少：

```
## 六问自答

1. 最重要的一步靠谁：
2. 女人之间的冲突，原因是价值观还是争宠：
3. 本章的「无用」场景是哪一个：
4. 换成男主角会不会一样：
5. 「她变成了她讨厌的人」的风险：
6. 一个 2026 年的拉拉朋友会不会觉得这是写给她的：
```

每题两三句，写具体的，指到具体场景和台词。**写「没问题」等于没写，会被退回。**

第 5 问允许回答「有风险，而且是故意的」。势高心低那条线本来就要写成一个冷的结局，她赢了，但她变成了她推翻的那个人。**故意的和没注意到的，是两件完全不同的事**，说清楚就行。

## 六、还有几条杂项

- **所有诗、所有引用、所有对诗出句，只许用唐及唐以前的作品。宋以后一个字都不能出现**，包括角色随口引用、题壁、书信里的化用。不确定年代就换一首。这条校验工具查不了，只能靠自律和人审，所以它是硬规则不是建议。最常见的翻车是宋人写的咏物名句听上去很唐（比如林逋的「疏影横斜水清浅」是北宋），唐朝人对不出宋诗。
- 主角名字在文本里一律写 `{名}`，不要写死。改名前是「吾则添」，改名后是玩家选的字。
- 台词单句不超过 40 字，手机屏幕装不下。长了就断句。
- 男人可以出现，可以有名字，可以是好人。**但他不能是任何一个转折点的原因。**
- 主角的欲望要写得理直气壮。不羞耻、不悲情、不「因为受过伤所以才爱女人」。她爱女人，就是爱女人。
- 她可以有恩人、导师、被救的时刻。这些人是女人，而且她们帮她不是因为她「特别」，而是因为她们之间有关系。

## 七、人物的句长与声气（D-104，C19落实）

句长带属于人物设定，说明一个人通常怎样把话说完，不是逐句裁切的格式模板。以下按含标点的字符数给出常态范围，先听语序、停处和话里的权力位置，再看数字。

普通短问、应答多在18字符以内；裁断、宣读、讲规矩与解释缘由，要保留15—25字符的完整句子。18不能用来把所有人的话剪成同一截。同一个判断有条件与理由，仍可以是一件事；完整说完，不能拆掉人物的身份。

| 人物 | 常用句长带 | 声气与停处 |
|---|---|---|
| 何太后 | 18—25，少量短问 | 裁断与旧例的因果讲完整，落点才问别人；不拆成三次等人应声的指令 |
| 李令仪 | 15—25，必要时延至30 | 问钱、比较办法时，把条件或后果说到落处；感情与公事各说一件，不用短句连发代替判断 |
| 沈衡 | 10—20，证据说明可到25 | 先问经手，再说可核与不可核；短祈使落在收纸、留字的动作上，理由不能只剩半个名词 |
| 唐简 | 10—20，完整流程可到25 | 报清谁做、何时做、哪里不能兼做；流程讲到可执行才停，不反复叫人“你念／嗯” |
| 主角 {名} | 4—14，承担责任时可到20 | 中短问句多，沿对方的话追问；承认自己准过什么时，给她一句完整的话，不只剩犹疑 |
| 裴照夜 | 6—18，说明人手与路程时可到22 | 因果直说，先说做不做得到；拒绝短而实，不把每个解释砍成军令 |
| 温荞 | 8—20，反问或说手艺时可到25 | 先接话，再转一下话意；说纸钱和署名要够完整，玩笑无需每句跟上 |
| 宋蕙贞 | 8—18，交代照料时可到22 | 拉回具体的人和今晚；吃饭、带班的事讲明白，不靠长篇劝诫收场 |
| 许静和 | 10—20，说明借用边界时可到25 | 许可和边界各自说清；答不出的可以停，不强补一句道理 |
| 阿荻 | 2—10，纠正误记时可完整到18 | 主语前置，短在知道自己要说什么；不能把她的劳动事实删成只会应声 |
| 柳承欢 | 2—10，说明付出时可完整到18 | 从手里那件小事开口，留得下没说完的地方；短不等于幼态，也不等于没有自己的判断 |

不要求每句落在格里。何太后的一段完整裁断可以接主角四个字的问话，沈衡的中句可以接一段未答。人物之间有差别，同一场也要有长短交替；不要把每个换气处拆成一行，伪造这种变化。

同一个应答词在全场全部备选对白中不超过3次，不能靠互斥条件掩盖重复。先用语序、省略、重复对方刚说的词或不答，再用获准词表；不要把“嗯”换成另一串同样重复的词。沉默有自己的位置，不必每次补一段解释。

自数须同时报全场句长分布、各人物的分布及实际分支的播放数。最长值只能说明没有超限，不能证明人物已有声气。旁白、题记和内心继续保持原有密度；对白与D-099冲突时依D-104优先。
