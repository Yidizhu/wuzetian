## 上元 · 灯下等一等

发信人：温荞；自制花笺。可见名“上元”。

**明面**

灯轮底下太挤，我把新裁的笺收进袖里，空着手出来了。方才有盏小灯快灭，领灯的人拿回去添油，我便在旁边等了会儿。

今夜想同你走一段。你若来，别往最亮的地方找，我在灯轮外那株树下。你不来，我看够了也会回去。

**空白处**

（她说空着手。想知道她会不会把手递过来。）

| 回法 | 主角回信 | 她的反应 |
|---|---|---|
| 直言A | 我来。你先替自己找个不挤的地方。 | “找好了。你到了再看够不够两个人站。” |
| 直言B | 今夜想独处，把你看见的留一句给我。 | “灯影在树干上爬了半截。只这一句。” |
| 直言C | 今夜不约，你看够了就回去。 | “好。我还想再看一轮。” |
| 以诗代答·相应 | 玩家自选诗；意象为灯下相见、夜游、各自归路 | “读到了。你要来，仍写一句来，别让我猜时辰。” |
| 以诗代答·不相应 | 玩家自选诗 | “这首我留着。今夜来不来，另答就好。” |
| 不回 | 不寄回信 | 她看过灯便自行回去，没有在树下等到天明。 |

本信不自动建立或恢复私约；答诗不替代赴约的明确回答。不因不回信扣分。

## 寒食 · 凉了也能吃

发信人：沈衡；黄麻纸。可见名“寒食”。

**明面**

饼是昨日备好的，放在笼里，取了把布盖回去。灶口的封泥没动。你若领晚了，先吃自己的，不必分给我，我已经吃过。

案上还有半卷，我核完便歇。今日不谈卷里的事。你带着你的那份来坐，也可以吃完再走。

**空白处**

（“已经吃过”。她知道我又会先问她。）

| 回法 | 主角回信 | 她的反应 |
|---|---|---|
| 直言A | 我拿自己的来，卷先合上。 | “这一行核完就合。你不必替我等饼凉。” |
| 直言B | 饼领到了，今日想自己吃。 | “布盖好。吃完再办你的。” |
| 直言C | 今日接不下相坐，改日再问。 | “好。改日也先问，不替彼此空着。” |
| 以诗代答·相应 | 玩家自选诗；意象为停歇、相坐、日常照料 | “诗收到了。饼别压在纸底下。” |
| 以诗代答·不相应 | 玩家自选诗 | “这首另看。今日那句话，你不急着答。” |
| 不回 | 不寄回信 | 她收好自己的卷，将余下饼食盖住，没有催第二封。 |

不写当天现做热食，不把禁火等同于全体宫人放假；不增加病人断药的新支线。

## 八月望夜 · 酒只倒一盏

发信人：裴照夜；军中素笺。可见名“八月望夜”。

**明面**

月从窗里进来，酒只倒了一盏。碟里的梨切偏了，一边厚，一边薄，我先吃了薄的。

今夜没有新定的归期。我想问的是，等真有空相见，你肯不肯陪我坐一会儿。你那边若也有月，抬头看一眼就好，不必替我等。

**空白处**

（想坐到她那一边。厚的那片也想尝。）

| 回法 | 主角回信 | 她的反应 |
|---|---|---|
| 直言A | 想陪你坐。等有空，再把日子说定。 | “好。有日子就写，不拿今夜的月充数。” |
| 直言B | 月看见了，相见的事先不定。 | “先不定。我把这盏喝完。” |
| 直言C | 今后不约私见，差程仍照实来。 | “听见了。往后只写该交的差事。” |
| 以诗代答·相应 | 玩家自选诗；意象为月、相隔、各自归程 | “你那边的月也收到了。日子仍等有空再问。” |
| 以诗代答·不相应 | 玩家自选诗 | “诗留着。没写日子，我便不当作约好了。” |
| 不回 | 不寄回信 | 她吃完梨，收走空盏，没有续添一盏等候。 |

仅写月、私人饮酒与寄信；无月饼、团圆宴或全民庆典。直言C的停止私邀语义需在接线时尊重，不能只显示拒绝文字却保留旧约；本轮文案不直接写存档效果。

## 重阳 · 到塔栏就歇

发信人：李令仪；常笺。可见名“重阳”。

**明面**

走到塔栏，茱萸囊被风吹到袖子另一边。我解下来重新系了一回，酒也没喝完。

从这里看，坊墙窄了许多，路上的人却仍要一步步走。今日不拿这个作驳议。我只想问你，下回肯不肯同来。走累了就坐，不必陪我到最上头。

**空白处**

（她也会走累。想看看她停下来时的样子。）

| 回法 | 主角回信 | 她的反应 |
|---|---|---|
| 直言A | 想同去。走到哪一层，各自说。 | “好。我不替你定，你也别替我少走。” |
| 直言B | 这回不登高，想听你说栏外看见什么。 | “两条路拐在同一座坊后。我下去再看。” |
| 直言C | 不约同游，来信读过了。 | “知道了。那只囊我自己系好。” |
| 以诗代答·相应 | 玩家自选诗；意象为登高、远望、各自停步 | “诗里那一层很高。到时仍看你的脚，不照诗走。” |
| 以诗代答·不相应 | 玩家自选诗 | “这一首先收着。同不同来，不从诗里替你认。” |
| 不回 | 不寄回信 | 她把未饮尽的酒收走，按自己的脚程下塔，不另差人问回信。 |

不增重阳糕，不写统一宫俗。邀请不预设此前相爱，不许借不回信替对方答愿意。
