# 部署：三个出口

同一份代码出三个东西，用途不重叠。

| 出口 | 给谁 | 怎么出 |
|---|---|---|
| **Vercel 网址** | 正式发布，发给任何人 | `vercel` 命令行，见下 |
| **单文件 `wuzetian-standalone.html`** | 微信、网盘、打不开 Vercel 的朋友 | `npm run build:artifact` |
| **Artifact 链接** | 内部试玩、给指挥部看 | Claude Code 发布 |

---

## 一、Vercel

### 头一次

装好命令行工具，在项目根目录跑：

```bash
npx vercel login
```

它会开浏览器让你用邮箱或 GitHub 登录。登完回到终端：

```bash
npx vercel link
```

它会问几个问题：Set up and deploy 选 **Y**，scope 选你自己的账号，link to existing project 选 **N**，项目名可以直接回车用 `wuzetian`。

### 之后每次

```bash
npx vercel --prod
```

一两分钟出一个 `https://wuzetian-xxxx.vercel.app` 的网址。这就是可以发出去的链接。

### 自定义域名

域名买好之后（YIDI 定），在 Vercel 网页后台的项目里 Settings → Domains 添加，
按它给的两条 DNS 记录去域名商那边填。生效通常十分钟以内，HTTPS 证书 Vercel 自己签。

### 构建配置在哪

`vercel.json`。三件事：

- **构建命令是 `npm run build:web`**，不是 `npm run build`。两者的区别只有一处：
  `build:web` 跑的是 `test:engine`（引擎自己的测试），不跑 `tests/convert.test.ts`。
  转换器是 CC2 的工具，一个字节都不进玩家拿到的包，用它挡发布是拿一件事去卡住另一件事。
  引擎、存档码、章末这些真会影响玩家的测试，一条都没少跑。
- **`assets/` 一年强缓存，`index.html` 每次都问**。文件名带哈希，改了名字就换文件，
  所以静态资源可以放心缓存一年；入口页不能缓存，否则改了没人看得到。
- **`.vercelignore` 挡掉 `src/data/adult/`**。18+ 数据包（D-029）连上传都不上传。

## 二、单文件版

```bash
npm run build:artifact
```

出两个文件在 `dist-artifact/`：

- `wuzetian.html` —— 发 Artifact 用，外层会补 doctype 和 charset
- `wuzetian-standalone.html` —— **发给人用这个**，自带完整的 `<head>`，双击就能开

一个文件三百来 KB，微信能直接发，不需要任何网址。

### 单文件版的一个真问题：存档

本地文件在有些环境里是**存不住档**的——localStorage 要么直接报错，
要么写了读不回来。iOS 从文件管理器打开、Safari 无痕、系统里关掉了网站数据，都会这样。

游戏开局会自己探一次（`storageWorks()`）。探不到就在顶上挂一条不会自动消失的红框提示，
告诉玩家这次玩的进度留不住，要留就随时导出存档码。这比玩到一半发现进度没了要好得多。

**还没在真机上验过的两件事**（要 YIDI 用手机做）：

1. 微信里把 `wuzetian-standalone.html` 发给自己，点开，看能不能玩、退出再进还在不在。
2. iPhone 上用 Safari 打开同一个文件，同样看一遍。

两件事的结论只有一个用途：决定给国内朋友发链接还是发文件。

## 三、换设备怎么带走进度

存档在每个人自己浏览器的 localStorage 里。同一个链接一百个人打开就是一百份独立进度，
不需要账号，也没有服务器（D-034）。代价是：**换浏览器等于换人**。
微信内置浏览器点“在 Safari 中打开”，那一下就换了一份空进度。

带走进度的办法是存档码（D-031）：HUD 上「存档」→ 导出，复制那一串 `WZT1.` 开头的文字，
到新设备上同一个面板粘贴进去。码里带校验和，复制少了一截会当场说“不完整”，
而不是读出半份存档让人以为进度还在。

首屏那条提示（`src/ui/FirstRunNotice.ts`）说的就是这件事，只出现一次。
