# 部署：三个出口

同一份代码出三个东西，用途不重叠。

| 出口 | 给谁 | 怎么出 |
|---|---|---|
| **Vercel 网址** | 正式发布，发给任何人 | `vercel` 命令行，见下 |
| **单文件 `wuzetian-standalone.html`** | 微信、网盘、打不开 Vercel 的朋友 | `npm run build:artifact` |
| **Artifact 链接** | 内部试玩、给指挥部看 | Claude Code 发布 |

---

## 一、Vercel

### 头一次

装好命令行工具，在项目根目录跑：

```bash
npx vercel login
```

它会开浏览器让你用邮箱或 GitHub 登录。登完回到终端：

```bash
npx vercel link
```

它会问几个问题：Set up and deploy 选 **Y**，scope 选你自己的账号，link to existing project 选 **N**，项目名可以直接回车用 `wuzetian`。

### 之后每次

```bash
npx vercel --prod
```

登录信息存在你自己的账号里。**如果要让 CC1 替你发**，token 得在它开的终端里也能读到，
所以要用 `setx`（写进用户环境变量）而不是 `set`（只活在当前这个窗口）：

```bash
setx VERCEL_TOKEN "你的token"
```

设完新开的终端才读得到。发完记得去 https://vercel.com/account/tokens 把它删掉重建一个。

一两分钟出一个 `https://wuzetian-xxxx.vercel.app` 的网址。这就是可以发出去的链接。

### 第一次部署 404 的两个原因（2026-09-12，已修）

首次 `npx vercel --prod` 十秒就 Ready，然后 https://wuzetianle.vercel.app 返回 404。
十秒太快了——那不是构建成功，那是**根本没构建**。两个原因叠在一起：

1. **项目根目录的文件不见了。** `package.json`、`vite.config.ts`、`index.html`、
   `tsconfig.json`、`vercel.json`、`.vercelignore` 全部从工作区消失，`.gitignore` 被
   换成了 Vercel 默认的两行。没有 `package.json`，Vercel 认不出这是什么项目，
   也没有构建命令可跑；没有 `index.html`，根路径就没有东西可以返回——于是 404。
   我从 git 里签回来了（这正是 D-037 第 4 条要 git 的理由：三条命令就全回来了）。
2. **`.vercelignore` 把 `tests/` 挡在外面，而构建命令要跑它。**
   `build:web` 的第二步是 `npm run test:engine`，测试文件没上传，构建当场就死在那一步。
   我按「只挡构建用不到、或者不该离开这台机器的东西」重写了那份清单。

第 2 条是我在 B7 写的，当时没验过。现在验法是本地模拟一次上传后的构建：
把项目按 `.vercelignore` 复制到一个临时目录，链一个 `node_modules`，在那里跑 `build:web`。
改之前死在测试那一步，改之后 `dist/index.html` 正常产出。

### 分享卡

`index.html` 的 `<head>` 里有一组 OG / Twitter 标签。链接发到微信、微博、任何聊天窗口时，
展开的就是那张图；没有这几行，展开的是一个灰方块加一条网址。

图是题画合成器出的默认那一幅（御花园夜），`public/share.jpg`，1200×630、38 KB。
立轴整幅放进去不裁，两边留纸色——裁成 1.91:1 会把右上的题跋切掉，那半张纸才是这张图的意思。
要换图就开 `/src/scene/tihua-preview.html`，把想要的那张导成 jpeg 存回 `public/share.jpg`。

**换自定义域名的时候记得改 `og:url` 和 `og:image` 两行。** 它们必须是绝对地址：
抓取的机器不在这个页面上，解不了相对路径。

### 自定义域名

域名买好之后（YIDI 定），在 Vercel 网页后台的项目里 Settings → Domains 添加，
按它给的两条 DNS 记录去域名商那边填。生效通常十分钟以内，HTTPS 证书 Vercel 自己签。

### 每次构建都会体检一次

`npm run check:bundle`（构建的最后一步，`build` 和 `build:web` 都带）查三件事，
三件都**不会让构建报错**，只会安静地让产物变坏：

| 查什么 | 为什么 |
|---|---|
| zod 有没有混进玩家的包 | 它是构建期的校验器。engine 里有人从 `schema.ts` 取一个运行时的值，整个 zod 就跟着进包，实测 +62 KB。这件事真的发生过一次 |
| 18+ 数据包有没有混进默认产物 | D-029。默认构建里那些文字一个字节都不该有 |
| CC2 的转换产物有没有混进正式产物 | `converted/` 没过 validate，只给 `?data=converted` 预览用 |

### 构建配置在哪

`vercel.json`。三件事：

- **构建命令是 `npm run build:web`**，不是 `npm run build`。两者的区别只有一处：
  `build:web` 跑的是 `test:engine`（引擎自己的测试），不跑 `tests/convert.test.ts`。
  转换器是 CC2 的工具，一个字节都不进玩家拿到的包，用它挡发布是拿一件事去卡住另一件事。
  引擎、存档码、章末这些真会影响玩家的测试，一条都没少跑。
- **`assets/` 一年强缓存，`index.html` 每次都问**。文件名带哈希，改了名字就换文件，
  所以静态资源可以放心缓存一年；入口页不能缓存，否则改了没人看得到。
- **`.vercelignore` 挡掉 `src/data/adult/`**。18+ 数据包（D-029）连上传都不上传。

## 二、单文件版

```bash
npm run build:artifact
```

出两个文件在 `dist-artifact/`：

- `wuzetian.html` —— 发 Artifact 用，外层会补 doctype 和 charset
- `wuzetian-standalone.html` —— **发给人用这个**，自带完整的 `<head>`，双击就能开

一个文件三百来 KB，微信能直接发，不需要任何网址。

### 单文件版的一个真问题：存档

本地文件在有些环境里是**存不住档**的——localStorage 要么直接报错，
要么写了读不回来。iOS 从文件管理器打开、Safari 无痕、系统里关掉了网站数据，都会这样。

游戏开局会自己探一次（`storageWorks()`）。探不到就在顶上挂一条不会自动消失的红框提示，
告诉玩家这次玩的进度留不住，要留就随时导出存档码。这比玩到一半发现进度没了要好得多。

**还没在真机上验过的两件事**（要 YIDI 用手机做）：

1. 微信里把 `wuzetian-standalone.html` 发给自己，点开，看能不能玩、退出再进还在不在。
2. iPhone 上用 Safari 打开同一个文件，同样看一遍。

两件事的结论只有一个用途：决定给国内朋友发链接还是发文件。

## 三、换设备怎么带走进度

存档在每个人自己浏览器的 localStorage 里。同一个链接一百个人打开就是一百份独立进度，
不需要账号，也没有服务器（D-034）。代价是：**换浏览器等于换人**。
微信内置浏览器点“在 Safari 中打开”，那一下就换了一份空进度。

带走进度的办法是存档码（D-031）：HUD 上「存档」→ 导出，复制那一串 `WZT1.` 开头的文字，
到新设备上同一个面板粘贴进去。码里带校验和，复制少了一截会当场说“不完整”，
而不是读出半份存档让人以为进度还在。

首屏那条提示（`src/ui/FirstRunNotice.ts`）说的就是这件事，只出现一次。

## 四、美术验收：三个抽查台

这三页只在 dev 下存在，**不会进任何产物**（vite 的入口只有根目录的 `index.html`）。
它们是 CC3 交付时用来出数和截图的地方，YIDI 想自己看一眼画面也走这里。

```bash
npm run dev -- --port 5175
```

CC1 的 dev server 常年占着 5173，所以美术这边固定用 5175（`.claude/launch.json` 里的 `wuzetian-art`）。

| 开哪一页 | 看什么 |
|---|---|
| `/src/scene/stage-preview.html` | 八个场景 + 色板/幕数/布置的变体排成一联，每格自带面数、每帧毫秒、留白%、朱砂%、各色面积% |
| `/src/scene/tihua-preview.html` | 题画四张定版；加 `?live=yuanye` 是活的合成器，机位、姿态、题跋可挑 |
| `/src/scene/title-preview.html` | 标题画面，点一下看墨晕合上 |
| `/docs/char-sheet.html` | 立绘对照表。「切色板」看金碧下的样子，「纯剪影」查涂黑还认不认得出 |

联排页上的数字**是那一页当场读画布像素算出来的**，不是谁手写的。要单看一场加参数：

```
/src/scene/stage-preview.html?key=zhaoyang&palette=gold&act=2&dress=gongyi&w=390&h=844
```

`dress` 现有四个值：空（平常）、`gongyi`（公议，昭阳殿与含元殿）、
`yeyu`（夜雨，女冠观，第三章 10 场夜谈三）、`shouwei`（受位议决，含元殿，第三章 12 场）。
标题那一页加 `?resume=1` 看有存档时的两个入口。

`w`、`h` 决定按什么分辨率量。**默认的 390 × 844 是手机竖屏**，改小了每帧毫秒会跟着变小，
不能拿小图上的数去说手机跑得动——真机闸门（D-003）仍然只能由手机说了算。
