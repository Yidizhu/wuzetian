### 接口（已写进 `docs/story-schema.md` 1.3.1，可以直接转给 CC2、ChatGPT）

```json
  "text": "你照她指的地方伸手，一滴没接到。指背挨上窗框，沾了一条灰。",
  "image": "shenheng_3_zhibei" }
```

### 运行语义

- **字和图同时出来**，对话框压在图上照常读；**立绘收起**（图里已经有人，不叠一个站着的）。
- **下一格没写就退回舞台**，人淡回来。
- **连着同一个 key 不闪**、不重铺。换 key 时新图解码好了淡进来盖住旧图，不先空一下（和 B41 换景同一个办法）。
- **空镜格也能写**。
- **绯版自动换**：主角是绯、有绯版图就铺绯版（D-216）。只写原图 key。
- **条件跳过的格**：连它的画面一起不出。
- **做决定、对诗、题记、换场、结局**：画面收起。
- **第一次真的铺出来**才记进回廊和存档：原 key 记一笔，铺的是绯版就另记一笔。读档读到这一格，图照样在。
- **旧的事件图格照旧能用**，两种不冲突。已有事件图格的地方要改成同一拍：删掉那一格，把 key 挪到台词格的「画面」列。**不要两种都写同一张**，会弹两次。
- **不碰亲密图的关系门槛**：画面列只管「这一格铺哪张」，那一格有没有条件照剧本走。

### 校验（`npm run validate`）

| 情况 | 结果 |
|---|---|
| 旧稿整列不写 | 正常 |
| key 不在表里 | **错误**（新图先请 CC1 登记） |
| 结局图、`_fei` 绯版 | **错误** |
| 题记格、事件图格写画面 | **错误** |
| key 在表里、图没上线 | 警告：这一格照常读字，图上线自动有 |

### 验证

- **测试**：格事件带 id 和 image；同 key 连着两格照样带出；条件跳过的格不带出它的画面；旧稿没有这一栏照常过 schema。
- **浏览器**：临时给 ch03-17 第 8、9 格写上 `shenheng_3_zhibei`（验完 `git checkout` 还原）：
  - 第 7 格：舞台；
  - 第 8 格：指背那张图铺上，立绘收起，字压在图上读；
  - 第 9 格：同一张，没重铺；
  - 第 10 格：图收，人回来；
  - 存档 `cgsSeen` 记下了 `shenheng_3_zhibei`。
- **验出来修掉的一处**：对话框在 z-index 2，事件图层是 3（点开看图时对话框本来就收起，所以从来没碰上）。画面要和字一起读，把画面那一层降到 1。

### 覆盖统计也认它

- `check:art` 的「剧本写到的图」把画面列算进去；
- 回廊按剧本第一次写到它（事件图格或画面列都算）的那一章排。
