## 六问自答

1. 最重要的一步靠谁：03要经手人指出原页少了字，05要劳动者亲领、原议本人查过，主角无法一人宣布完成。宋不代伴侣署名，阿荻领完便回自己的去处。
2. 冲突来自价值观还是争宠：沈反对毁原件，李反对由在位者独占提名，温不替主角写颂。三人的私下回声都不能抵掉公事分歧。
3. 无用场景在哪里：夜谈四06和夜谈五18共用正文在C-14，本批10先留一张饼的时间。它不发奖励，也不把拒位者送去另一份无尽工作。
4. 换成男主角会不会一样：结契者的病舍照料与分别授凭来自这些女人的生活，宋仍不能替不在场的女人答应。非宗室女人得位后，也不自动拥有所有女人的署名。
5. 变成讨厌的人的风险：03和04让玩家看见缺字、确认焚毁、沈辞署的具体次序。05付清本批钱也不能让原件复生，07仍可能再关一道门。
6. 拉拉朋友会觉得写给她的吗：旧信有被记住的回应，没有回的也不被追问。明言相爱不替代另一人的职分，正文给不留下的人保留完整生活。

## 自审与交接

每场只有一张连续台词表；条件段不插空行。第一批只写全名旗标，意向与正式事实的交接为02→03、03→04、07→17；05严格由两个留存事实派生public_review。各普通场至少两句20—40字符对白，无条件或按当次必播分支落实。书阁08明确夜里；10明确园外买好后入园，园内不设摊，不要求CC3改夜景。

Prompt C13补齐第二、三章四封信的直言A／B／C、诗答与主动不回；每封每人最多一句，每条路线只经05或08，李的旧夜另一句。第二章诗答标记在C-8，第三章诗答标记在C-11，合意与不合共用一条历史回声，原数值不变。未标记的旧存档不猜诗答，未读不伪作主动不回。旧邀请只记曾怎样回答，不覆盖另一封信或今日选择；详见C13-修订交付清单.md。
