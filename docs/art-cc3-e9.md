## 二、对照图：看什么

`Claude outputs/E9-色板对照.png`，手机视口整屏（D-071 那一张），左两格昭阳殿、右两格书阁夜。

**昭阳殿（重彩）**：
- **殿柱从石青换成铅丹。** 唐代殿柱是土朱／铅丹刷的——这是这张图里最「唐」的一处，也是最大的变化。
  柱子用的是**铅丹不是朱砂**：朱砂仍然只给她拿主意那一下（D-082 第 2 条）。
- 两个人第一次有了颜色：主角**青**、沈衡**深绿**。头、发、剪影脸仍是墨。
- 袍子加了一道墨线勾边——**线描勾勒 + 填色**，不勾线就是剪纸（`palette.css` 末尾那条规则）。
- 梁、帷幔、匾、地这一轮没动：石青石绿泥金的值只比旧的饱和一档。**要不要再往浓里走，看了图再定。**

**书阁夜（素彩）**：
- 窗框、案从墨换成赭石，远墙从清墨换成淡赭，书架墨青。纸底不变、留白不变（44%）。
- **克制是故意的**：这是她的地方，不该和朝廷一样满。重彩与素彩的差，就是旧色板里金碧与水墨的差，只是不再是「有色 vs 无色」，而是「浓 vs 淡」。

**两个我自己看出来的问题，先说**：
1. **状态条的四根墨线**在素彩板里跟着变成了赭、绿、墨青四种颜色，读不出高低（它们是用墨的浓淡表示数值的）。已经改成走人的墨色（`--c-char-*`），对照图里是改过的。
2. **马还是石青**。它在旧色板里是「最重的一块」，重彩里站在铅丹柱子前面偏冷，对比是够的，但它是不是该换成赭白马，要看图的人定。

## 三、十一人的主色（方案，等审）

`Claude outputs/E9-十一人品色.png`（上排纸底、下排绢底，同一个人两块板下同一种颜色——E4「人不随色板变」照旧成立）。

**方法**：C0-3 第五节唐代品色服——三品以上紫、四五品绯、六七品绿、八九品青。角色圣经给了身份，尚宫局的职官有品级，照着落；**不入品的人**（公主、太后、民间、宫人、女冠）按身份取常服色。

| 人 | 主色 | 依据 |
|---|---|---|
| 吾则添 | **青** `#4F7FA8` | 新入宫才人，从最低一格起。**一个问题要定**：她的袍色要不要随章节变（青 → 绿 → 绯），让她的上升在衣服上看得见？那要引擎按章节切一个变量，归 CC1 |
| 柳承欢 | **灰青** `#8FA3B0` | 和主角同一族、淡一截——她是主角差点成为的那种人 |
| 沈衡 | **深绿** `#2F6F55` | 尚宫局司记，正六品 |
| 唐简 | **浅绿** `#6E9A7C` | 尚宫局典记，正七品。和沈衡同是绿，一深一浅：**同一个衙门、差一级**，这件事本身就在画面上 |
| 裴照夜 | **绯（胭脂）** `#8E2F52` | 女将，比四五品。**是胭脂不是朱砂**，偏紫红；剑穗那一点朱砂在绯袍边上仍分得开 |
| 李令仪 | **郁金**（藤黄）`#D2A035` | 公主不入品色；唐代贵女的郁金裙 |
| 何太后 | **深石青** `#1F3F6E` | 朝廷的颜色本身 |
| 宋蕙贞 | **赭** `#9A6A45` | 资深才人的旧常服；簪头一点紫照旧 |
| 温荞 | **铅丹** `#D8702F` | 民间，石榴裙，全员最亮 |
| 许静和 | **蛤白** `#E6E0CE` | 女冠。蛤白压在纸底上对比弱，靠加粗的墨线保轮廓 |
| 阿荻 | **本色麻** `#BFA27C` | 宫人，没染 |

**紫不给任何人做主色**：三品以上的紫在这个游戏里是结契的暗号（D-035），做了主色暗号就没了。李令仪、何太后按身份本可以紫，所以换成了郁金和深石青。

**方案里自己知道的三处风险**：
- **温荞的铅丹和昭阳殿的柱子是同一个颜色。** 她要是站进昭阳殿，就会和柱子同色同位——E4 的石青病换一种颜色再犯一次。要么她不进重彩场景，要么给她换成藤黄以外的另一种暖色。
- **许静和的蛤白在纸底上几乎没有对比**，只靠墨线。
- **主角和柳承欢同族**：两人同场（第三章多场）时靠明度分，意思是对的，但要在整屏里看一眼。

**区分轴的另一半「墨线粗细」这一轮没做**：先看颜色这一轴够不够。袍色已经把十一人分开了，线的粗细我倾向于留给「身份轻重」而不是「区分是谁」。
