# 《吾则天》女性主义精神指南（tone-bible 素材）

> 用途：这份文件是 `tone-bible.md` 的理论底稿。第 3、4 节可以直接贴进 tone-bible，第 1、2 节给写剧本的人（ChatGPT / 你自己）读，第 6 节给 Claude Code。
> 一句话版本："她的胜利不是把男人的王座换个人坐，而是让王座本身变了形状。"

---

## 1. 先诊断：什么叫"精神男"叙事

俗称"精神男"的问题，文化研究里其实有一个很准的名字——戴锦华说的**"花木兰式困境"**："一个自由解放的女性，进入社会生活的前提，是'化妆'为男性，因为社会生活的全部规范都是男性规范。" 花木兰能建功立业，代价是她得穿上男人的盔甲、用男人的标准证明自己。这就是大多数"大女主"的内核：**她赢了，但赢的规则一个字没改。**

近两年国内评论对"大女主剧"的批评可以直接当反面教材用：

- **隐形男性保护者是金手指**（白惠元）：苏明玉背后有蒙总，房似锦背后有徐文昌。表面独立，实际每一步都靠一个男人托底。
- **斗争矛头指向同性**（白惠元）：魏璎珞一路打的都是女人，最后的胜利是"成为皇帝最宠爱的妃子"。这是宫斗剧的默认结构，也是最典型的"精神男"——女人之间互相消耗，男性权力坐收渔利。
- **模板化爽文**（腾讯新闻 2025）：身世悲惨 + 受尽欺凌 + 性格倔强 + 搞事业 + 嫁如意郎君。女主"不一定完美，但一定正确"，喊口号但没有处境。
- **现代口号硬塞进古代**（同上）：让唐朝人说 2025 年的女性宣言，观众立刻出戏。好的做法是让人物"在既定游戏规则中实现自洽"——她的反抗必须是那个时代的人能做出来的反抗。

另外一条是上野千鹤子在《厌女》里讲的：**厌女不只是男人恨女人，也是女人内化了对女性的轻视**——包括"我和那些女人不一样"这种自我例外。宫斗剧里女人互斗、女主鄙视"只会争宠的庸脂俗粉"，本质上都是厌女。这条对我们的游戏特别重要，因为主角是女同性恋，她和女人的关系是主线，如果这些关系写成争宠或利用，整个游戏就塌了。

## 2. 五个理论支点，每个都能落到游戏机制上

### 2.1 勒古恩的"提包理论"：故事不是矛，是袋子

Ursula K. Le Guin 在《The Carrier Bag Theory of Fiction》(1986) 里说，人类最早的工具大概率不是矛而是袋子（采集用的），但我们的叙事传统全是"矛"的故事：一个英雄，一条直线，刺穿目标，胜利。她提议一种"袋子"的小说：把各种东西装进来，让它们彼此发生关系，没有唯一的高潮和终点。

有人已经把这套搬到游戏里（Unwinnable, 2020）：矛型游戏 = 打怪升级通关拿"最佳结局"；袋子型游戏 = 玩家是"织布的人"而不是"征服者"，把散落的人和事编成网，"游戏不会等你"，没有单一正确路线。

**落地：**
- 结局树不设"真结局/完美结局"。登基是其中一个结局，但不是"通关"。退隐办女学、扶持另一位公主、把皇位传给非血亲——都是同等分量的结局。
- 进度不用任务列表，用"关系图"。玩家看到的是她认识了谁、谁和谁之间有了什么，而不是"主线任务 3/7"。
- 数值里的"心"（定力）不是打怪掉的，是从关系里长出来的。

### 2.2 酷儿游戏研究：queer 不是加个女友，是"歪着看"

Bo Ruberg 和 Amanda Phillips（Game Studies 2018 特刊《Not Gay as in Happy》）的核心观点：queer 在游戏里不是"有 LGBT 角色"，而是一种姿态——借用 Sara Ahmed 的话，"aslant, askew, out of line"，歪着、斜着、不在线上。他们明确批评《质量效应》《Dream Daddy》这种"包容性代表"：把酷儿装进原有的资本主义/英雄叙事框架里，什么都没动摇。

具体的 queer 设计手法包括：**拒绝效率**（不奖励最快最优的玩法）、**允许失败**（失败本身可以是有意义的路径，参考 Jack Halberstam 的《失败的酷儿艺术》）、**非规范时间**（不是每一段都要推进剧情，可以有"什么都没发生只是两个人在夜里读诗"的段落）。

**落地：**
- 每一幕至少有一个"无用"场景：不加数值、不推剧情、只是两个女人相处。这些场景反而是玩家记住游戏的地方。
- 至少一个结局是"她选择不要"——不要皇位、不要那段关系、不要复仇。这个结局不能写成失败。
- 好感度不叫"攻略"。没有"刷满好感解锁 CG"这种结构。关系是双向的，对方也会拒绝她、离开她、和她意见相左。

### 2.3 权力观：power-over 还是 power-with

对"girlboss 女性主义"的批评（2020 年后已成共识）说的是同一件事：女人坐上 CEO 的位置不等于女性主义，如果她做的事和男 CEO 一模一样。区分两种权力：**power-over**（支配、让别人服从）和 **power-with**（联合、让彼此都更有力量）。

Audre Lorde 的《Uses of the Erotic: The Erotic as Power》(1978) 给了更深一层：她说的 erotic 不只是性，而是一种"深层的知道"——女人对自己感受、快乐、渴望的确信，这是父权社会最想让女人放弃的一种力量，因为一个知道自己要什么的女人很难被使唤。对一个女同性恋主角来说，这条几乎是量身定做的：**她的欲望本身就是政治的。**

**落地：**
- 数值系统里"势"（权力）不能是唯一通向登基的路。"势"高但"心"低的登基结局，应该写成一个冷的结局——她赢了，但她变成了她推翻的那个人。
- 主角的每一次重大胜利，至少有一次是"让别人也站起来"而不是"把别人踩下去"。
- 她的欲望要写得理直气壮。不羞耻、不悲情、不"因为受过伤所以才爱女人"。她爱女人，就是爱女人。

### 2.4 戴锦华：把女性的整体生命经验当文化资源——不是发明，是打捞

戴锦华化解花木兰困境的方案不是"女人打败男人"，而是：女性要对权力结构有清醒认识，然后**"以女性的整体生命经验作为新的文化资源"为世界提供新的可能性**。

对唐朝背景这是天大的好消息，因为唐代女性文化根本不需要我们发明：
- **女诗人群体真实存在**：薛涛（制"薛涛笺"，与元稹、白居易唱和）、鱼玄机（女冠，"易求无价宝，难得有心郎"）、李冶（女冠诗人，"至近至远东西，至深至浅清溪"）、刘采春。她们互相知道、互相唱和。
- **女冠（女道士）制度**：唐代贵族女子出家为女冠是合法地脱离婚姻、拥有社交自由的通道。这是现成的"女性自治空间"。
- **上官婉儿**：武则天时代实际主持诏令、品评天下诗文的女官，"称量天下士"。她和武则天的关系是历史上最接近"两个女人共治"的样本。
- **武则天本人**：设铜匦纳谏、创殿试、重用寒门、改字造字（曌）、无字碑。这些是"改规则"的动作，不是"赢游戏"的动作。

**落地：**
- 主角的盟友来自这些真实的女性空间：女冠观、女官署、诗社、教坊。
- 她登基后做的事要能体现"规则变了"：比如女子可考科举、女冠可入朝、无字碑（把评价权留给后人，拒绝被定义）。

### 2.5 "借力不是耻辱"：反过来警惕另一种精神男

腾讯那篇文章引了梁永安一句话："真正的成熟不是摆脱依赖，而是学会借力。" 这条是反向提醒：**"女人什么都得靠自己"也是男性英雄叙事的翻版**（孤胆英雄）。真正的女性主义叙事允许她依赖、允许她求助、允许她被照顾，只要依赖的对象不是"隐形男性保护者"。

**落地：**
- 主角可以有恩人、导师、被救的时刻。这些人是女人，而且她们帮她不是因为她"特别"，而是因为她们之间有关系。
- 她也会照顾别人。护理、教导、陪伴这些"女性化"劳动在游戏里要有分量，而不是被当作弱。

## 3. 正负例清单（直接贴进 tone-bible）

### 主角

| 不要 | 要 |
|---|---|
| 因为受过男人的伤才变强 | 她本来就有野心、有欲望、有判断 |
| "我和那些女人不一样" | 她知道自己和那些女人的处境是一样的，只是选择不一样 |
| 用男人的方式证明自己（更狠、更冷、更能打） | 用她自己的方式赢：诗、判断力、人脉、耐心、对人心的理解 |
| 孤胆英雄，谁都不信 | 她有一张网，网里全是女人 |
| 一路正确，观众只能崇拜 | 她会错、会后悔、会被拒绝，观众能理解她 |
| 悲情、苦大仇深、隐忍到底 | 有力量感，会笑，会享受，会说"我要" |

### 女性角色与关系

| 不要 | 要 |
|---|---|
| 其他女人是障碍、情敌、工具人 | 每个重要女性角色有自己的欲望和轨迹，不围着主角转 |
| 女人之间的冲突是争宠 | 女人之间的冲突是价值冲突（忠于旧制 vs 改制、家族 vs 自我） |
| 好感度 = 攻略进度条 | 关系是双向的，对方可以离开、拒绝、反对 |
| 恋爱是奖励 | 恋爱是关系的一种，和盟友、师徒、对手一样有分量 |
| "百合"当卖点，两个女人的关系只为了好看 | 她们的关系有政治后果：会被弹劾、会被利用、也会改变权力格局 |
| 一个"完美恋人" | 至少一个恋人和她在根本问题上意见不合 |

### 权力与结局

| 不要 | 要 |
|---|---|
| 登基 = 通关 = 唯一真结局 | 多个平等结局，登基只是其中一个 |
| 赢了之后一切照旧，只是龙椅上换了个人 | 赢了之后规则变了（女子科举、女冠入朝、无字碑） |
| 通过踩人往上爬 | 至少一半的上升是"让别人也站起来" |
| 复仇是主要驱动力 | 建造是主要驱动力 |
| 失败结局是惩罚 | 失败结局是另一种人生（退隐、办学、流亡但自由） |

### 文本与时代

| 不要 | 要 |
|---|---|
| 唐朝人说现代女性主义口号 | 她们说唐朝人的话，做唐朝人能做的反抗 |
| 用现代价值观俯视古人 | 尊重她们的处境，在处境里找到力量 |
| 说教 | 让玩家自己得出结论 |
| 男人全是坏人 | 男人是背景。有的好、有的坏、都不是重点 |

## 4. 每写一章问自己的六个问题

1. 这一章里，主角最重要的一步是靠谁？如果答案是一个男人，重写。
2. 这一章里有没有女人之间的冲突？冲突的原因是价值观还是争宠？
3. 这一章有没有一个"无用"的场景——不加数值、不推剧情、只是两个人在一起？
4. 主角这一章做的事，换成一个男主角会不会一模一样？如果会，问题在哪。
5. 有没有让玩家觉得"她赢了但她变成了她讨厌的人"的风险？如果有，是故意的吗？
6. 一个 2026 年的拉拉朋友玩到这一章，会不会觉得"这是写给我的"？

## 5. 名字与主题的呼应

《吾则天》："吾"是第一人称——我即为天，不是"武"（武力）。这个字本身就是对"精神男"的回答：她的天不是打下来的，是她自己就是。可以在游戏里做成一个 beat：她登基后要改名（对应历史上武则天造"曌"字），玩家来选那个字。

## 6. 美学与 3D：给 Claude Code 的技术备忘

### 技能现状
- 你的 Claude 技能库里目前**没有**游戏美术 / 游戏美学设计技能，只有一个 `canvas-design2`（静态海报用的）。
- 插件市场里有一个 **Unity 官方插件**（`unity`），带 29 个技能，但绝大多数是 UI、变现、内购、多人联机，只有 `urp-postprocessing`、`shader-graph-create-custom-node`、`optimize-web` 三个和视觉/网页导出有关。Unity WebGL 包在手机上又大又慢（首屏 20–50 MB 是常态），一周内不建议。
- 所以 **`art-style` 技能得自己写**，Claude Code 的计划里已经列了，这份文件的第 6.3 节可以当它的骨架。

### 6.1 3D 的现实方案：3D 舞台 + 2D 对话

Claude Code 说"Three.js 不做"，理由是一周内它会吃掉美术和剧情时间。这个判断对全 3D 是对的，但有一个折中方案能保住 3D 又控制成本——**把 3D 当"舞台布景"，不当"游戏"**：

- 6–8 个固定机位的 3D 场景（宫殿一角、女冠观、诗社、御花园夜、大殿、无字碑），每个场景是一个 low-poly 模型 + 水墨着色器。
- 相机不由玩家控制，只在场景切换和关键 beat 时做缓慢推拉（像舞台灯光）。
- 人物立绘和对话框仍然是 DOM 层叠在 3D 画布上，中文排版、字体、无障碍的优势全部保留。
- 手机上 Three.js 渲染一个静态 low-poly 场景是轻的，比 Unity WebGL 轻一个数量级。

预算：2 天（Day 4–5），如果 Day 5 结束还没稳，**退回 CSS 多层视差水墨背景**，对话层代码一行不用改——这是把 3D 和 2D 分层的最大好处。

### 6.2 水墨风在 Three.js 里怎么做

- 基础：`MeshToonMaterial` + 自定义渐变贴图（3 级色阶），把光照量化成平涂色块。
- 轮廓：反向法线外扩（inverted hull）画墨线，或者后处理 Sobel 边缘检测。
- 墨晕：地面阴影用 `smoothstep` + 噪声，"边缘软、内部不均"，这是 Codrops 2026 年 9 月一篇 WebGPU 水墨庭园案例的做法（用了 Three.js + TSL），证明这个方向在浏览器里是可行且好看的。
- 纸纹：全屏一层宣纸纹理叠加（multiply），加轻微抖动让它不像机器生成。
- 色板：墨五色（焦、浓、重、淡、清）+ 一个点睛色（朱砂红）。整个游戏只允许这六个颜色，UI 也是。

### 6.3 `art-style` 技能的骨架（给 Claude Code 写技能用）

```
art-style/
├── SKILL.md          # 何时调用：生成/审核任何视觉资产时
├── palette.md        # 六色色板 + 每个颜色的语义（朱砂 = 主角的欲望/决断）
├── composition.md    # 构图规则：留白 ≥ 40%，主体偏左下，题跋区在右上
├── character.md      # 立绘规格：尺寸、安全区、差分表情清单、服饰考据来源
├── scene.md          # 8 个场景的机位、时间、光线、情绪关键词
├── ui.md             # 对话框/选项/状态条的墨线风格，字体（思源宋体子集）
└── negative.md       # 禁止项：不要 3D 写实、不要"仙侠感"发光、不要 anime 大眼
```

美学上的一条总原则，和第 1–3 节呼应：**留白就是她的权力。** 水墨画里最有力量的部分是没画的部分——无字碑是这个游戏的视觉母题。
