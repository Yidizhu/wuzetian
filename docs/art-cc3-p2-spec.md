## 一、穿什么：幞头圆领袍（D-074 已定）

D-074 第 4 条写明「裴照夜是男装幞头」，原稿第一节那个待定项结束。3D 版走**幞头 + 圆领窄袖袍 + 袴 + 革带 + 靿靴**，剑挂左胯。

**代价照旧**：她和沈衡、唐简撞衣服。区分只靠五样，参考图里都做了：**最宽的肩、最高的个子、腰间挂剑、两脚分开站、靴筒**。
SVG 版的「束发 + 明光铠」不改（D-072：2D 只修 bug），P2 验收通过后按角色逐个替换。

## 二、参考图（image-to-3D 的输入）

**用 SVG 加 Three.js 体块渲，四分之三视角、带明暗**（D-074 第二条）。纯黑剪影不能喂：没有明暗就没有体积，生成出来是一片板。

```bash
npm run tripo -- ref
```

出两张到 `Claude outputs/tripo/`：`peizhaoye-ref.png`（1024 方图，喂给 Tripo 的那张）和 `peizhaoye-ref-sheet.png`（审图页）。

| 做法 | 为什么 |
|---|---|
| 灰阶四档：幞头与靴最深、革带次之、袍中灰、头与手最浅 | 肩、胸、袖、下摆的转折各有一档光，生成工具才读得出前后 |
| 主光左前上方 + 一道右后的轮廓光 + 半球补光 | 背面那一侧也要有形状，不然背面会被猜成平的 |
| 头是一只光滑的蛋，没有五官 | 生成工具给不了它没见过的东西；脸上一旦有起伏，toon 着色会切出一道硬影 |
| A 字站姿，两臂离身约三十度，两脚与肩同宽 | 自动绑骨要手臂离开身体；并拢的脚会被生成成一块 |
| 幞头两脚极短、硬；无飘带、披风、宽袖 | 规格第 2 条：薄布不生成，软脚接入后用两节骨头后补 |
| 剑挂左胯斜向后下，手不在剑上 | 角色圣经「不持续握剑」；也免得手和剑柄长成一块 |
| 剑穗不做 | 那是她全身唯一的朱砂点，由 CC3 在引擎里加，不让生成工具随手给颜色 |
| 背景近白、无纹理、无地面、单人 | image-to-3D 会把地面和背景当成模型的一部分 |
| 比例：身高约 1.72，肩宽取 SVG 表的 1.14 倍 | 十一人里最高、肩最宽，这是和沈衡、唐简分开的地方 |

## 三、提交参数

```bash
npm run tripo -- submit            # 不加 --confirm 只打印参数，不花钱
npm run tripo -- submit --confirm  # 约 25 credits
npm run tripo -- wait <task_id>    # 轮询到结束，glb 下载到 public/char/3d/src/
```

| 参数 | 值 | 为什么 |
|---|---|---|
| `type` | `image_to_model` | D-074 |
| `texture` / `pbr` | `false` / `false` | 规格第 3 条；也省时间 |
| `face_limit` | `2600` | 规格第 4 条 ≤ 3000，留 400 给后补件 |
| 其余（`model_version`、`quad`、`orientation`…） | 不传，走服务端默认 | 不拿猜的参数去试错；第一次失败再看是哪一项 |

接口照 Tripo 官方 Python SDK 的实现写（上传取 `image_token` → `POST /task` → `GET /task/{id}`）。
**每一步花钱的命令都要显式 `--confirm`**：200 credits 实际只够两个角色（D-074 第三条），自动化的是跑，不是决定花。

凭证只从环境变量读，代码、日志、报告里不出现值（D-075）。读不到就打「TRIPO_API_KEY 未设置」。

## 四、生成结果先过六条，不过就不绑

模型下载后先看 Tripo 回传的预览图，再在抽查台里转着看。**任何一条不过，不花绑骨的 25 credits**，回第二节改参考图：

1. **脸上没有起伏。** 看得出眼窝、鼻梁、嘴的，不要。
2. **肩比胯宽一大截。** 肩和胯差不多宽的，那是沈衡。
3. **身上没有东西飘着、挂着。**
4. **两只手是空的，离开身体。**
5. **剑挂在胯上，是一根完整的直线。** 剑和腿长成一块的，不要。
6. **脚底平，两脚分开。** 站在一块底座上的，不要。

## 五、绑骨与授权

```bash
npm run tripo -- rig <task_id>            # 先跑 animate_prerigcheck（Tripo 说绑不了就停）
npm run tripo -- rig <task_id> --confirm  # animate_rig：biped、tripo 骨骼规范、glb，约 25 credits
```

- 不要动画：姿态由 CC3 在代码里转骨头做（第七节第 4 条）。
- D-059 的横评说 Tripo 在风格化角色上骨骼放得合理；**所有工具都处理不了布料次级运动**——所以薄布本来就不让它生成。
- **授权与数据保留要人确认**（D-074 第四条）：免费档的输入输出会被平台广泛保留。裴照夜这一个实验不受影响；
  **把十一人全交上去之前**，先决定是否升级付费档。发布前 YIDI 查一次当时那一档的授权条款，截图存进 `docs/`。

## 六、交给 CC3 之后：文件放哪、硬指标

**放这里**：`public/char/3d/peizhaoye.glb`（D-036：`public/char` 归 CC3）。原文件另存一份
`public/char/3d/src/peizhaoye.raw.glb`，减面前的底子，不进产物。

CC3 接进来时在加载器里整理（不另写构建期脚本：`face_limit` 在生成时就压了面，剩下的都是加载时几行代码）：
丢贴图和材质、每个顶点最多 4 根骨头、单位统一成米、朝向与原点归正。面数超了才考虑构建期再减。

| 项 | 要求 | 不过怎么办 |
|---|---|---|
| 面数 | ≤ 3000 三角面（含后补的幞头软脚与剑穗，所以本体目标 **≤ 2600**，生成时 `face_limit` 已压） | 超了先查是不是 `face_limit` 没生效；再不行回第二节 |
| 一场的人数 | 最多两个 3D 人；主角暂时仍是 SVG 时，一场只有她一个 3D | — |
| 每帧 | 场景 + 人合计 ≤ 3 ms（390 × 844），**以 YIDI 手机上的读数为准** | 先减人的面，再减人的描边 |
| 体积 | GLB ≤ 400 KB | 3000 面带骨骼一般 150–250 KB，超了说明贴图没丢干净 |
| 朝向与原点 | Y 朝上，面朝 +Z，原点在两脚中间的地面上，身高约 1.72 m（全员最高） | 整理脚本里统一改，不回工具 |
| 骨骼 | 至少有 Hips、Spine、Neck、Head、左右 UpperArm / LowerArm / Hand、左右 UpperLeg / LowerLeg / Foot | 名字不限，接入时建一张映射表；缺 Neck 或 Head 的回工具重新绑 |
| 贴图、变形目标 | 都不要 | 整理脚本删 |

## 七、CC3 接进引擎后怎么验

**抽查台**：P2 时写 `/src/scene/char3d-preview.html`，和舞台抽查台一样当场读像素出数。

### 1. 着色：和八个场景同一套

- `MeshToonMaterial` + 同一张三档 ramp + 同一套笔刷描边（反向外壳，按粗细带压力变化）。
- **颜色从 `--c-char-*` 取，不从场景色板取**（E4 硬规则「人不随色板变」，3D 同样适用）。
  裴照夜主调重墨 `--c-char-2`，幞头和靴焦墨 `--c-char-line`。
- 场景的光照直接照在她身上，不另打人物光——同一个空间里的人和殿要被同一束光照着。
- 在金碧场景里验一次：**身上不许出现石青、石绿、赭石**。

### 2. 脸：剪影脸 + 一笔墨点

- 在游戏机位、手机竖屏的尺寸下（人高约 600px，头约 70px），脸上**不许出现三档明暗切出来的块**。
- 有块的，先试加载时把头部顶点的法线换成以头骨为心的球面法线（代码里做，不动模型）；
  还有块，回第四节换候选。
- 眼神方向用**一笔墨点**：一个 6–8 个三角面的小片贴在脸前、跟着头骨转，焦墨，只在 open 表情出现。
  不做眼睛。

### 3. 纯剪影认得出是谁（D-052 第 5 条，和 SVG 同一把尺）

抽查台上一格一格排：**纯黑剪影、纸色底、同样的高度**。

| 并排放 | 为什么是这几个 |
|---|---|
| 裴照夜 3D ×3（default / guarded / open） | 三个姿态各自要认得出 |
| 沈衡 SVG、唐简 SVG | 同是幞头圆领袍，最容易混 |
| 主角 SVG | 同场最常见的另一个人，比身高和肩宽 |

**两个尺寸都验**：游戏里的大小（人高 600px）和缩略图大小（人高 120px）。
**通过的标准**：去掉名字、打乱顺序，找一个没看过设计稿的人（YIDI 或她的朋友），120px 那一排里一眼指出哪个是裴照夜。
指错一次就不过。另外量两个数写进验收报告：**肩宽 / 身高**要是十一人里最大的，**身高**要是最高的。

### 4. 三个姿态靠转骨头，不靠生成

来自角色圣经「轮廓与表情」一栏：

| 表情 | 角色圣经 | 骨头怎么转 |
|---|---|---|
| default | 安稳，先给旁人留通道 | 重心落一条腿（胯偏 4°），另一脚略外撇；手自然垂，**不碰剑**；头正 |
| guarded | 立正不近前 | 两脚收拢、脊柱挺直、下巴微抬 3°、双手贴裤缝；整个人往后退半步（根骨后移 0.15 m） |
| open | 坐下拆衣带上的死结 | P2 先不做坐姿：低头 18°、两手收到腰前革带处、肩放松下沉 |

### 5. 看向说话的人（look-at）

- 谁开口，她的头转向那个人所在的一侧。**头骨偏转 ≤ 25°、俯仰 ≤ 10°**，颈骨分走四成。
- 转过去用 380 ms，缓动和墨晕同一条曲线；**只在换人说话时转**，同一个人连说几句不动。
- 她自己说话时看前方略偏对方，不看镜头。

### 6. 后补的两样薄东西

- **幞头软脚**：两片各 8 个三角面的窄条，挂在头骨后面，两节骨头，跟着头转有 120 ms 的滞后。
- **剑穗**：剑柄末端一小段，4–6 个三角面，**全身唯一的朱砂点**。金碧场景里转泥金（D-010 硬规则 1），
  和 SVG 的 `var(--c-accent, var(--c-ink-4))` 同一条规则。

### 7. 交付时的自评

art-director 十条照打，**只认手机上的截图**。第 1 条剪影与第 7 条姿态各低于 7 分，不上线，回到上面对应一步。

## 八、不做的

- **不用生成工具给的贴图、脸、头发、动画库里的夸张动作。**
- **不做写实脸、不做口型、不做眨眼。** D-012 定死的。
- **不用 Blender 建模**（D-058）。它只作 Tripo 绑坏时的后备：绑骨样板与面数体检。
- **不改 SVG 立绘**（D-052 末条）。P2 验收通过之前，游戏里裴照夜仍是 SVG；通过之后按角色逐个换，
  任何时候都有一个能发给朋友的版本。
