# P2 · 3D 人物生成规格：第一个角色裴照夜

> CC3 写，E5 第 6 条。依据 D-012（3D 人物分两步）与 D-052 规格表。
> **这份是给 YIDI 在 P1 收尾时照着点的**：注册 Tripo 或 Meshy，照第二节贴描述，照第四节挑，照第五节导出，
> 把文件放到第六节说的位置，剩下的归 CC3。**现在不做模型，这份只是备着。**
>
> 两家工具的界面和选项名会改，下面凡是写到按钮名的地方都**以当时界面为准**，找意思相同的那一项。

## 一、先说一处要 Cowork 定的

**SVG 版的裴照夜是「束发 + 明光铠简化」，D-052 和 C0-3 写的是「男装幞头」。** 两者不一致。

3D 版我建议走**幞头 + 圆领袍 + 袴 + 蹀躞带 + 靿靴**，即她的日常衣着。三条理由：

1. 角色圣经原话：「常年穿便骑乘搬运的男式袍裤，是公开日常」。铠甲是出征的样子，戏里她多数时候不在出征。
2. **铠甲是生成工具的另一个重灾区**：甲片是大量细碎硬面，生成出来要么糊成一块、要么面数爆掉。
   圆领袍是一整块筒形，最容易干净。
3. D-052 选她当第一个，理由就是「男装幞头、几何性最强、薄布最少」——这条理由说的是袍，不是铠。

**代价**：她会和沈衡、唐简撞衣服（两人也是幞头圆领袍）。所以第四节的剪影验收**必须拿这两个人并排比**，
区分只能靠：最宽的肩、最高的个子、腰间挂剑、两脚分开站、靴筒。这五样在生成描述里都写死了。

Cowork 若定「还是铠」，第二节换一段描述即可，其余各节不变。

## 二、给生成工具的描述（文生 3D）

两家对英文描述的理解都比中文稳，所以正文用英文，中文附后备查。**正向描述与反向描述分开填**；
没有反向描述栏的，把反向那段接在正向后面，前面加 `Avoid:`。

### 中文对照（不填进工具，只备查）

> 高个、宽肩的女子，三十二岁，唐代男子日常骑装：黑色幞头（两脚极短、硬），素面圆领窄袖袍，
> 长及小腿、前襟闭合，革带挂两个小囊，直筒袴，高筒靴。直刀带鞘挂在左胯，**手不握**。
> A 字站姿，双臂离身约三十度，两脚与肩同宽，正面。**脸是光滑的，没有眼、鼻、口**，像美术人台。
> 头发全收在幞头里。形体简单、剪影干净、风格化、低面数、单人、无底座。

### 为什么这样写

| 写进去的 | 对应 D-052 哪条 | 为什么 |
|---|---|---|
| featureless face / mannequin | 第 1 条：脸不生成五官 | 生成后再抹比一开始不要难得多，而且我们没有 Blender（D-052 已否） |
| 幞头两脚极短、硬；无飘带披风 | 第 2 条：薄布不让它生成 | 唐初幞头是软脚垂在脑后，那两条是薄布，生成出来会塌成两团泥。**软脚后补**，见第七节 |
| 窄袖、袍闭合、无裙 | 第 2 条 | 宽袖和开衩的下摆同理 |
| 手不握剑 | 角色圣经「不持续握剑，先给旁人留通道」 | 也省得手和剑柄长成一块 |
| 剑穗不要 | 朱砂规则 | 剑穗是她全身唯一的朱砂点，**由 CC3 在代码里加**，不能让生成工具随手给个颜色 |
| A-pose | 自动绑骨 | 两家的自动绑骨都要求手臂离开身体，贴着身体的手臂会和躯干粘成一块 |
| low poly | 第 4 条：≤ 3000 面 | 见第五节，生成出来一般仍远超，要再减 |

## 三、生成时的设置

按意思找，名字以界面为准：

| 设置 | 选什么 | 为什么 |
|---|---|---|
| 模式 | 文生 3D（Text to 3D） | 我们没有合规的正面参考图；拿 SVG 剪影去做图生 3D，出来的是一块扁板 |
| 贴图 / 纹理 | **关**，或只生成无贴图的预览模型 | D-052 第 3 条：贴图一律丢弃。关掉省点数、出得快 |
| 对称 | **开** | 人台式的站姿本来就对称；剑在一侧不影响，对称只管身体 |
| 姿态 | A-pose | 同上 |
| 拓扑 / 面数 | 三角面；有「目标面数」就填 **3000**，有「低面数」开关就开 | 见第五节 |
| 一次出几个 | 能出四个就出四个 | 第四节从里面挑 |

## 四、从几个候选里挑哪个（YIDI 在工具网页上就能判断）

转到**正面**和**正侧面**各看一眼。**下面任何一条不过，直接换下一个候选或重新生成，不要想着后面修**：

1. **脸上没有起伏。** 看得出眼窝、鼻梁、嘴的，不要。（我们的着色只有三档明暗，一个鼻梁就会在脸上切出一道硬阴影）
2. **肩比胯宽一大截。** 她是十一个人里肩最宽的。肩和胯差不多宽的，那是沈衡。
3. **身上没有东西飘着、挂着。** 披风、飘带、流苏、长发，有一样就不要。
4. **两只手是空的，离开身体。** 手里握着东西、或手臂贴着身体的，不要。
5. **剑挂在胯上，是一根完整的直线。** 剑和腿长成一块的，不要。
6. **脚底平，两脚分开。** 站在一块底座上、或两脚并成一块的，不要。

六条都过的里面，**选剪影最「方」的那个**——宽肩、直袍、方靴，整个人是一块竖着的长方形。
那是她和沈衡（挺直但窄）、唐简（矮而前倾）拉开距离的地方。

## 五、减面、绑骨、导出

1. **减面到 3000 三角面以内**（D-052 第 4 条，硬上限）。工具里有「重新拓扑 / Remesh」的就在那一步填目标面数。
   做不到 3000 的也没关系，**导出后 CC3 在构建期再减**（第六节），但请尽量在工具里先减到 1 万以内——
   减得越少，形状丢得越少。
2. **自动绑骨**：选人形（Humanoid）。它会要你在模型上点几个位置（下巴、手腕、手肘、膝盖、裆部之类），照提示点。
   **不用加动画**，姿态由 CC3 在代码里转骨头做（第七节）；有「待机呼吸」之类免费的可以一起带上，不带也行。
3. **导出 GLB**（不是 FBX、不是 OBJ）。有「包含贴图」选项的**不勾**。
4. **看一眼授权。** 免费档和付费档生成的模型授权可能不同（有的免费档要求署名，有的不允许商用）。
   **这个只有人能确认**，和 D-053 音乐那条一样：发布前 YIDI 查一次当时用的那一档怎么写，
   截图存进 `docs/`。

## 六、交给 CC3 之后：文件放哪、硬指标

**放这里**：`public/char/3d/peizhaoye.glb`（D-036：`public/char` 归 CC3）。原文件另存一份
`public/char/3d/src/peizhaoye.raw.glb`，减面前的底子，不进产物。

CC3 接进来之前先过一道构建期整理（`tools/prep-char3d.ts`，P2 时写，基于 `@gltf-transform/core`，纯 Node，不用 Blender）：
丢贴图和材质、合并重复顶点、减面到 3000 以内、每个顶点最多 4 根骨头、单位统一成米。

| 项 | 要求 | 不过怎么办 |
|---|---|---|
| 面数 | ≤ 3000 三角面（含后补的幞头软脚与剑穗，所以本体目标 **≤ 2600**） | 构建期再减；减到形状塌了就回第四节换候选 |
| 一场的人数 | 最多两个 3D 人；主角暂时仍是 SVG 时，一场只有她一个 3D | — |
| 每帧 | 场景 + 人合计 ≤ 3 ms（390 × 844），**以 YIDI 手机上的读数为准** | 先减人的面，再减人的描边 |
| 体积 | GLB ≤ 400 KB | 3000 面带骨骼一般 150–250 KB，超了说明贴图没丢干净 |
| 朝向与原点 | Y 朝上，面朝 +Z，原点在两脚中间的地面上，身高约 1.72 m（全员最高） | 整理脚本里统一改，不回工具 |
| 骨骼 | 至少有 Hips、Spine、Neck、Head、左右 UpperArm / LowerArm / Hand、左右 UpperLeg / LowerLeg / Foot | 名字不限，接入时建一张映射表；缺 Neck 或 Head 的回工具重新绑 |
| 贴图、变形目标 | 都不要 | 整理脚本删 |

## 七、CC3 接进引擎后怎么验

**抽查台**：P2 时写 `/src/scene/char3d-preview.html`，和舞台抽查台一样当场读像素出数。

### 1. 着色：和八个场景同一套

- `MeshToonMaterial` + 同一张三档 ramp + 同一套笔刷描边（反向外壳，按粗细带压力变化）。
- **颜色从 `--c-char-*` 取，不从场景色板取**（E4 硬规则「人不随色板变」，3D 同样适用）。
  裴照夜主调重墨 `--c-char-2`，幞头和靴焦墨 `--c-char-line`。
- 场景的光照直接照在她身上，不另打人物光——同一个空间里的人和殿要被同一束光照着。
- 在金碧场景里验一次：**身上不许出现石青、石绿、赭石**。

### 2. 脸：剪影脸 + 一笔墨点

- 在游戏机位、手机竖屏的尺寸下（人高约 600px，头约 70px），脸上**不许出现三档明暗切出来的块**。
- 有块的，先试加载时把头部顶点的法线换成以头骨为心的球面法线（代码里做，不动模型）；
  还有块，回第四节换候选。
- 眼神方向用**一笔墨点**：一个 6–8 个三角面的小片贴在脸前、跟着头骨转，焦墨，只在 open 表情出现。
  不做眼睛。

### 3. 纯剪影认得出是谁（D-052 第 5 条，和 SVG 同一把尺）

抽查台上一格一格排：**纯黑剪影、纸色底、同样的高度**。

| 并排放 | 为什么是这几个 |
|---|---|
| 裴照夜 3D ×3（default / guarded / open） | 三个姿态各自要认得出 |
| 沈衡 SVG、唐简 SVG | 同是幞头圆领袍，最容易混 |
| 主角 SVG | 同场最常见的另一个人，比身高和肩宽 |

**两个尺寸都验**：游戏里的大小（人高 600px）和缩略图大小（人高 120px）。
**通过的标准**：去掉名字、打乱顺序，找一个没看过设计稿的人（YIDI 或她的朋友），120px 那一排里一眼指出哪个是裴照夜。
指错一次就不过。另外量两个数写进验收报告：**肩宽 / 身高**要是十一人里最大的，**身高**要是最高的。

### 4. 三个姿态靠转骨头，不靠生成

来自角色圣经「轮廓与表情」一栏：

| 表情 | 角色圣经 | 骨头怎么转 |
|---|---|---|
| default | 安稳，先给旁人留通道 | 重心落一条腿（胯偏 4°），另一脚略外撇；手自然垂，**不碰剑**；头正 |
| guarded | 立正不近前 | 两脚收拢、脊柱挺直、下巴微抬 3°、双手贴裤缝；整个人往后退半步（根骨后移 0.15 m） |
| open | 坐下拆衣带上的死结 | P2 先不做坐姿：低头 18°、两手收到腰前革带处、肩放松下沉 |

### 5. 看向说话的人（look-at）

- 谁开口，她的头转向那个人所在的一侧。**头骨偏转 ≤ 25°、俯仰 ≤ 10°**，颈骨分走四成。
- 转过去用 380 ms，缓动和墨晕同一条曲线；**只在换人说话时转**，同一个人连说几句不动。
- 她自己说话时看前方略偏对方，不看镜头。

### 6. 后补的两样薄东西

- **幞头软脚**：两片各 8 个三角面的窄条，挂在头骨后面，两节骨头，跟着头转有 120 ms 的滞后。
- **剑穗**：剑柄末端一小段，4–6 个三角面，**全身唯一的朱砂点**。金碧场景里转泥金（D-010 硬规则 1），
  和 SVG 的 `var(--c-accent, var(--c-ink-4))` 同一条规则。

### 7. 交付时的自评

art-director 十条照打，**只认手机上的截图**。第 1 条剪影与第 7 条姿态各低于 7 分，不上线，回到上面对应一步。

## 八、不做的

- **不用生成工具给的贴图、脸、头发、动画库里的夸张动作。**
- **不做写实脸、不做口型、不做眨眼。** D-012 定死的。
- **不上 Blender**（D-052）。所有整理都在 `tools/` 的 Node 脚本和加载器里做。
- **不改 SVG 立绘**（D-052 末条）。P2 验收通过之前，游戏里裴照夜仍是 SVG；通过之后按角色逐个换，
  任何时候都有一个能发给朋友的版本。
