# 《吾则天》女团面部参考与角色立绘升级调研

日期：2026-09-14。用途：供指挥部与立绘制作讨论，未生成、替换或发布任何立绘，未修改技能与生产配置。

## 一、结论

建议采用“现代辨识度的面容＋唐风衣冠＋国漫厚涂半写实”的方向。好看的目标不是十一张同款精致脸，而是玩家能记住每个人，并从她的视线、嘴角和身体状态读出关系变化。

首轮只试三人：**吾则添以宋昕冉为轮廓参考；沈衡以戴萌为眉眼参考；裴照夜以孙芮为正面结构参考、RYUJIN 为嘴部与表情重心的补充参考。** 不是一比一换脸，也不代表演员选角。

本轮使用 art-style 与 art-director 检查项目适配，以 agent-reach 的网页检索路径核查公开资料。关键发现是：现行规则把面型、眼型、眉型、嘴型限制得太一致；若不先调整这部分，单往提示词里添加偶像姓名，很可能仍得到同一张脸。

## 五、必须同步调整的规则

依据：`.claude/skills/art-style/SKILL.md` 第三道“脸”门槛，以及其说明中指向的公共提示词；当前另有 `.agents/skills/art-style` 旧版水墨剪影规范。新旧规则需明确适用范围，不能让旧版“不要细画五官”继续约束光栅立绘。

用户本轮已允许现代偏古风面容。建议指挥部记录这一新方向，并在执行时同步生成与验收规则，避免一边要求女团参考、一边按“现代脸”退图。

| 现行限制 | 建议修改 | 保留的质量底线 |
|---|---|---|
| 全员偏圆面，固定宽长关系 | 按角色分别确定圆、长、方及转折程度 | 解剖连贯；不统一削成尖下巴 |
| 全员细长眼，禁止明显眼褶 | 允许不同开合度与自然眼褶 | 不把眼线当眼型，不全员大眼美瞳 |
| 全员粗平眉、小嘴 | 眉弧、眉尾与唇形成为辨识因素 | 同一人不同表情仍保持结构一致 |
| 以“像现代偶像剧海报”直接退图 | 改为检查脸、唐风衣冠与厚涂画法是否融合 | 不把现代舞台妆和摄影皮肤直接贴上衣服 |
| 对女将的“帅气化”作笼统否定 | 允许女性的英气、方下颌和壮实体格 | 不擅自变更角色性别、年龄与体型 |
| 无参考生成后反复压制模型默认脸 | 先做有来源的面部设计板，再锁定原创定稿 | 不用同一张默认脸批量换装 |

本轮不改变衣冠形制、品色、角色 key、道具与既定发式。裴照夜仍是既定袍服与横刀方向，不因参考女团舞台造型改穿铠甲或现代制服。

女性主义表达不要求女性“不漂亮”，也不要求人人都以讨人喜欢的方式漂亮。年轻与成熟、柔和与锋利、壮实与纤细应共同存在。真正需要避免的是把顺从画成美，把拒绝画成丑，把有权力画成衰老阴险。

## 六、下一轮怎样试，才不浪费整身生成

1. **补参考角度。** 首轮三名角色，每个主参补正面、四分之三侧面、自然笑各一张公开成年时期照片。尽量露眉与下颌、光线相近；本轮小拼图只能决定方向，不能直接充当定脸三视图。
2. **先画九个头，不重做十一套衣服。** 主角、沈衡、裴各三种原创方案；统一光线、头部尺寸、近中性表情。初选时遮掉发型与服装判断是否仍分得开。
3. **每人只选一个结构方案。** 不按“谁最像明星”投票，而问：记不记得住？符合年龄吗？与另两人相似吗？读得出她在看谁吗？
4. **再做表情测试。** 同一张原创脸分别做常态、收敛、松动；眉眼、嘴角与肩颈共同变化。拒绝时不丑化，亲近时不统一露齿甜笑。
5. **复用已验收的衣冠方向完成三人试版。** 不覆盖现用文件；保留旧版对照。再检查全身、膝上裁切、120px 剪影与手机实机，脸图好看不代表上屏好看。
6. **最后扩展余下八人。** 把三人试版形成的画法约束推广，而不是把三张脸复制给八个人。成熟角色另外补年龄适配的参考。

建议验收问题：随机遮去姓名和衣服颜色，初次看过设定的人能否将三张脸稳定对应到角色？同一角色换表情后是否被误认成别人？这需要真实比较测试，本报告未声称已完成。
