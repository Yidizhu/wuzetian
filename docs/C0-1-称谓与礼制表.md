## 使用边界

| 标记 | 含义 |
|---|---|
| 史 | 下列古籍可以支持的制度、身份或实例；不表示整个唐代始终一致 |
| 设 | 本作平行世界的制度、称谓统一规则与场面调度；不能反引为唐史 |
| 史→设 | 有历史原型，但本作扩张了适用人群、权力或程序 |
| 时间 | 设：不系真实帝王年号，唐代诗歌作为本世界已流传的文献；不让初唐人物现场创作中晚唐作品。诗人不直接作为同代 NPC 登场 |
| 史书年代 | 《新唐书》为后世修史，供幕后考据；不能让角色提到这部书。禁宋以后诗文是台词用典限制，不排除幕后使用后世史料 |

## 二、易发生冲突的互称与动作

| 场面 | 推荐写法（均为设） | 权力含义 |
|---|---|---|
| 才人与司记初见 | “沈司记，这一行由谁核过？”／“才人请看原簿。” | 位号和业务管辖分开；女官可拒绝手续不全的请求 |
| 宫女向才人报告 | “才人，昨日那匹绢还未入库。”／“阿荻，你慢些说。” | 先交代事项，不先跪地喊冤 |
| 女将与公主议事 | “殿下，请先定下军粮从何处支。” | 尊礼不能替代预算、调兵程序 |
| 太后与长公主分歧 | 用“太后”“长公主”而非未确定的母女亲称 | 避免为了亲近台词临时捏造谱系 |
| 恋人在公务中相见 | 用实授官称；离署后才改私称 | 恋爱可亲密，批牍不能因亲密跳过复核 |
| 入殿与受命 | 通报、奉召、按仪位行礼；重大册命才写完整拜礼 | 不把每次说话写成三跪九叩；具体礼次须随典礼另核 |

## 四、平行世界制度底稿（以下全部为设）

| 事项 | 开场现状 | 后续可争取的改变与代价 |
|---|---|---|
| 祖制，开场可用原文 | “国初定令：皇子、公主，皆得承统。择其能任社稷者，告庙而册之；既受册命，内外奉为储君，不以男女更议。” | 只解决宗室男女继承资格，不宣称人人已经平等；祖制全文为原创拟古文 |
| 册立程序 | 在位者提出人选，相关官署核宗籍、议礼，告庙册立。才名、军功只能构成理由，不能代替程序 | 废立须公开理由及议覆，不能靠一纸私札；女官保留不同意见的案牍成为实质权力 |
| 非宗室的主角为何能登基 | 祖制本身不含她。她须另行取得足以支持改制的联盟与公开授权；具体采用何种授位制度留给 A 审后结局树，不暗写“她本是公主” | 必须在正文完成合法性冲突，不能用隐藏血统、男性遗诏或恋人让位省略 |
| 才人身份 | 本世界将才人改为内廷选士位号，承担文事与学习，有俸给，不附侍寝义务；转女官需另授职，允许按程序辞出 | 保留“才人”对人的等级化清点与流动限制；改革不是争得更高宠位 |
| 女性应举 | 开场限有内廷或指定官学荐牒的女性参加明经、明书／明算类选试，取中优先进入内廷职务；普通女子尚无普遍乡贡进士资格。科名取唐代原型，女性准入限制为设 | 改为女性可经州县贡送应进士等常科，并建立教育与旅费支持；仅删报名禁令仍解决不了贫穷 |
| 女冠 | 依法受度、隶籍；可在观中读书、收徒与有限接待访客，但出入、财产、官务仍有规则。不可任意强令还俗婚配为本作保护条文 | 入朝承办公务须独立任命、明确任期；不必先还俗。观舍不能因主角需要就变成军粮仓或情报站 |
| 亲密关系 | 女子相爱不被治罪，但二人不能作为配偶入婚籍，宗法不算婚；清河公主仍会被议婚。照料、共财与身后安排不能靠一句“有爱人”自动取得效力 | 政争围绕谁受益、是否徇私、谁有权拒绝；不靠普遍同性恋迫害制造苦情 |
| 社会不平等 | 皇室女儿可继位，但普通女人仍受籍属、教育、家产与服役条件限制 | 角色会质问“你开的是谁能走进去的门”；女帝不是改革完成的证明 |

## C6 · 酷儿文化的日常载体（D-035）

| 项目 | 本作设定与使用边界 |
|---|---|
| 结契仪式（设） | 双方自愿到观中立誓、互换发簪，各留契纸；可共居共财，亦可各有住处与收入。宋与伴侣即此关系。退契、改约须容许双方各自说不，簪不能成为控制去留的凭证 |
| 双鲤（史源转设） | 李冶“尺素如残雪，结为双鲤鱼”是已有诗源；本作将双鱼折法设为女子写给女子、只给一人看的记号。折法是显示与文化差异，不加解谜门槛，也不代替对亲密的同意；回绝者不用折鱼证明自己懂暗号 |

| 尚未采用 | “虹”的反夺回仍待YIDI决定，本轮不放入台词、物件或旗标 |

史源与设定分开：结契、双鲤暗号、私册、一点紫的社群意义均为本作原创；不把近代金兰契的年代倒置成唐代史实。角色说的是一包日用品、一支簪、一页愿不愿留的字，研究术语仅留编剧说明。
## 六问自答

1. 最重要的一步靠谁：本件尚非章节，制度预案让司记、宫人、诗人与女冠各掌握不可替代的知识。主角须取得她们的合作，不能由男性密旨一路托举。
2. 女人之间的冲突，原因是价值观还是争宠：皇室继承资格与普通女性应举资格不对等，是首要冲突。才人不设侍寝义务，排除了靠争宠推动升迁的默认结构。
3. 本章的“无用”场景是哪一个：本件没有章节场景，不能声称已经满足。后续每幕需独立安排不带条件收益的共同生活片段。
4. 换成男主角会不会一样：不会完全一样，主角身处内廷选士而被挡在常科之外。她能接近文书，却不拥有同等署名与出仕资格，这将是行动的具体起点。
5. “她变成了她讨厌的人”的风险：有，她可以把女冠观和宫人网络当作自己的资源。这里明确她们有拒绝权，日后是否侵犯必须写成可见后果。
6. 一个 2026 年的拉拉朋友会不会觉得这是写给她的：目标是让关系拥有私生活与公开利益两种重量。不能只凭制度表保证体验，还须在角色与场景中验证。
