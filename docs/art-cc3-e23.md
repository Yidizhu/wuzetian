## 二、八张结局图提示词

写在 `ai-prompt.md` 第十二节。验收规矩写在 `SKILL.md` 新加的「验收结局图」一节，文件名规矩也补进了 `SKILL.md`。

### 八张共用的定法

| 项 | 定 | 为什么 |
|---|---|---|
| 构图 | 八张全竖 | 结局第一拍整屏只有这张图；D-150 |
| 文件名 | `ending_<结局 key>`，key 和 `endings.json` 一样 | 和恋爱线的 CG 放在同一个目录 |
| 字 | **一个字都没有**，写过的纸侧着或背着画面 | 登基三张的正文分天、曌、不改三段，图只有一张，有字就只对得上三分之一的玩家 |
| 印 | 八张都不画印；「无字之碑」的纸留出平整的空白，让引擎叠印 | D-067、E23 |
| 登基三张 | 主角穿绯（D-105）；没有冠冕、龙袍、宝座、朝拜的人群 | 结局树：结局看她怎样用权，不是看她有没有权 |

**公共段**：第十一节的竖构图 CG 公共段逐字照抄，另外加四条（结局图是什么、没有字、表情不做表演、不画冠冕）。八份提示词加上一份展示用的，共九份，脚本核过逐字相同。

### 八张各画什么

每张画面里的东西都能在结局树的正文里找到对应那一句。

| 结局 | 画面 | 冷或暖从哪来 |
|---|---|---|
| 满殿无声（gold） | 主角在大殿里飞快地批一样齐的奏牍，身边的坐席空着；远处殿门里是沈衡的背影 | 颜色是满的；冷来自平光、齐整、空座、走掉的人 |
| 无字之碑 | **没有人**。碑前一张空纸，三个角压着石头，风掀起第四个角 | 正面平光 |
| 未竟之诏 | 天刚黑，小理事房里，主角在灯下用算筹重算一份退回来的账，案上摞得不齐 | 一盏暖灯 |
| 两席之间 | 李令仪书房。主角指着纸驳她，李令仪拿着半块胡饼笑，不让步；她的紫礼衣挂在身后的衣架上 | 午后侧光 |
| 开门授字 | 冬天，门开着。阿荻自己划掉错处，主角抬到一半的手停住了；两个学字的人只画背影 | 门外雪光，加一只炭盆 |
| 不受 | 主角坐在街边台阶上，两手捧着一张胡饼；身边一个小包袱，远处一小段宫墙 | 大太阳 |
| 关山有信 | 驿路岔口。主角坐在行囊上读信笑出来；裴照夜拿着空信封看着前面的路；远处有一棵像坏扫帚的树 | 午后横光 |
| 纸上有名 | 天刚亮，临街小屋里，主角把写满的糙纸翻到背面，偏头听楼下卖纸的吆喝 | 清早的冷光 |

几处写法说明：
- **正文里的「椅子」**：满殿无声、两席之间都写了椅子。唐代没有椅子，公共段也禁止，所以画成坐席。
- **未竟之诏用算筹，不用算盘**：算盘是后来才有的。
- **胡饼**有 `C0-3` 唐代物质生活手册为据。

### 最容易撞的三对，怎么拉开的

| 两张 | 撞在哪 | 拉开的地方 |
|---|---|---|
| 满殿无声 / 未竟之诏 | 都是天子对着案 | 大殿对小屋，齐对乱，冷光对暖灯，批对算 |
| 未竟之诏 / 纸上有名 | 都是一个人对着纸 | 夜里对清早，绯对青，算账对翻纸，宫墙对街 |
| 不受 / 纸上有名 | 都是一个人松下来 | 户外正午对室内清早，吃饼对写字 |

**验收的结果式**：八张到齐以后缩到手机大小并排，遮住标题，看能不能对上八个结局名。

### 为什么这样写，三处

1. **无字之碑不画人**：正文是「许多年后」，她已经不在了。那张纸是留给「后来的人慢慢写」的，画了谁，就替后来的人定了是谁。这是八张里唯一不画人的，提示词里写明了例外。
2. **只露背影和手的人**：沈衡、两个学字的人只画背影，卖饼的人只露一截手臂。有了脸就要过「脸配得上定妆图」那道门槛；这几个人在画面里的作用不需要脸。
3. **无字之碑要量坐标**：出图后我量出纸面坐标交给 CC1，做法和 E18 量碑面坐标一样。
