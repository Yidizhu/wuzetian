## 二、毛笔线：为什么原来的线是「机器线」

整体放大一个比例的外扩壳有两个毛病，凑在一起就是 art-director 第 5 条的「差」档：
粗细均匀；而且薄的那一维几乎没有线（一块 15 米长、20 厘米厚的地板，长边有线，厚边没有）。

这一版换了四件事，已写进 `art-style/references/scene.md` 的「毛笔线」一节：

1. **沿平滑法线外扩一个固定的世界宽度**，不再按比例放大。平滑法线要先合顶点再重算——
   盒子的法线是逐面的，沿逐面法线外扩会在棱上裂开。合顶点只给壳用，填充那一份保持硬边，平涂要的就是硬边。
2. **笔压**：宽度乘一个随物体坐标变化的值，在 0.42 到 1.45 倍之间走，几组不同频率的正弦叠出来。
   噪声取物体坐标不取世界坐标，笔触才钉在物件上，镜头一动不会爬。
   下限不能到 0：一条边整根消失看着像漏画，不像提笔。
3. **细处提色**：线细的地方把焦墨提到浓墨，像笔尖抬起来带的墨少了。
4. **粗线归主体，背景的线要退。** 地、梁、墙压到 0.5 倍，那匹马、案上的笺、门牌加到 1.3 倍以上。
   这条比前三条都管用：线宽是最省事的一套层级，一个颜色都不用改就能把视线带到该去的地方。

线宽的基准取**舞台宽度的比例**（0.008），不是固定的世界长度。八个场景从 3.6 米宽到 20 米宽，
按固定长度写死的话，同一根线在无字碑上只有掖庭的一半粗——第一版就是这个毛病。

代价：壳要多一份几何（合过顶点的那一份），三角面数不变，材质从 `MeshBasicMaterial`
换成一段十几行的 `ShaderMaterial`。实测每帧没有可测量的变化，见下表。

## 四、五场各改了什么

每一条都对着 E1 自评里「最该改的一条」。

**掖庭偏院 65 → 73。** 水瓮从重墨压到淡墨——E1 那一版它比门牌还扎眼，抢了焦点，
而这一场讲的就是「名字还没写上去」。同时把用色收到三级（纸 + 淡墨 + 焦墨两条线），
E1 那一版五级墨色全用上了，是 rubric 第 6 条明写的失分点。门牌的线加到 1.5 倍，
现在它是全画面最亮的一小块加最重的一圈线，视线只能落在它上面。

**书阁（金碧）61 → 73。** 加了五道斜光：窗棂切出来的光落在席上和案上，
其中一道正好落在那张未写的笺上。这一场的情绪（午后、浮尘、势均力敌）全靠它，
E1 那一版一道光都没有，所以只有 61。左边补了一扇屏，留白从 73.6% 收到 69.1%——
金碧的语义是满，那一版太空了。

**书阁（夜）63 → 74。** 案放大一圈往前挪：E1 那一版的案坐不下两个人，
而这一场是「势均力敌的对谈」。补了一面不参加光照的清墨后墙（那一档原本空着，画面少一层远），
灯焰歪着，是全场唯一「将动未动」的地方。

**女冠观 62 → 73。** 柱、台基、松冠一律压到淡墨，全场只有屋顶是重的——
E1 那一版清墨 6.9 / 淡墨 6.7 / 焦墨 6.5 / 浓墨 4.4 四色平分，是 rubric 第 6 条的「差」档。
符纸的线加到 1.4 倍，纸色压在最重的那条黑线上，一眼就看见它。舞台宽度从 7.4 收到 6.4，
观不再是画面中段一条窄带。

**御花园夜 62 → 74。** 海棠的干露出来了：E1 那一版干被栏挡住又偏出了画面，
只剩三根悬空的斜棒，读不出是一株树。月推到右上角、小一圈，灯盏换成最亮的一档——
这一场是「亲密、私语、无用时刻」，落点该在她们坐着的地方，不在天上。
E1 那一版月、灯、栏的豁口三处抢焦点，谁也不是落点。

## 六、题画

`src/scene/TiHua.ts` + `src/styles/tihua.css`。版式规矩已写进 `art-style/references/ui.md`。

- **幅面** 900 × 1200（3:4），画心偏左下，题跋区右上——就是 `composition.md` 原有的布局，没有另设计。
- **构成** 纸 → 画心（舞台按 cover 裁进去）→ 立绘（底对齐，一高一低，不对称）→ 画心细线 →
  题诗竖排（最多四句，从右往左）→ 落款 → 印 → 纸纹压在最上面。
- **印**跟色板走：水墨场景朱砂，**金碧场景转泥金**，和立绘的朱砂点同一条规则（已在抽查台上验过）。
- **保存**：存图按钮 + 「长按图片可存进相册」。`<a download>` 在 iOS Safari 上不可靠，所以两条都给。
- **可挑的三样**（E2 原话：三个预设机位 + 三种立绘姿态 + 从诗库选一句）：
  机位「全 / 近 / 远」都从场景自己的机位派生——D-003 定了相机不交给玩家，
  八个机位是按构图规矩定的，交出去就没有构图了；三个预设保证每一张都还在规矩里。
  姿态就是立绘的三张差分（常 / 敛 / 松）。题跋从诗库里挑，这一层不新写诗。
  每挑一次重合成一张，一张 4 到 22 毫秒，不值得做增量。
- **印文随主角当前名**：取末二字。改名之前是「则添」，改名之后自动变「则天」——
  这是 D-006 那个 beat 在题画上的回声，玩家存下来的图会记得她当时叫什么。
- **保存**：能下载的环境给「存图」按钮，iOS Safari（`<a download>` 在那里是摆设）自动收起按钮，
  只留「长按图片保存到相册」。
- **抽查台**：`/src/scene/tihua-preview.html` 四张定版；`?live=yuanye` 是活的合成器。
  合成 4–22 ms，PNG 约 700–950 KB。

十条自评 **73**：明暗 8、留白 8、色 8（印占千分之三，是全图唯一的红）、层级 8（诗 / 款 / 印三档）、
尺度 8；线 7、焦点 7；剪影 7、姿态 6、节奏 6。

**最该改的一条：立绘。** 题画把立绘放到了整幅的高度，SVG 占位那点毛病在这个尺寸上全看得见——
主角的双环望仙髻远看像两只耳朵，三个人的身体是同一个梯形。R-005 说过 SVG 不再返工，
所以这一条我没有动，但要记在这里：**题画是要发给朋友的东西，朋友看到的第一眼就是立绘。**
要么 P2 的 3D 人物提前，要么再给 SVG 一轮。这个决定不是我的。

## 七、立绘与 3D 的叠合：查出三处

**一、脚没有踩在地上。** 立绘原来用一个写死的 `bottom: -4%`。每场的地平线高低差得远——
掖庭是近景平视，线在画面下三分之一；含元殿是大俯视，线在正中——一个固定值必然有几场人是浮着的。
改法：背景层把「人站的那条线离画面底边的比例」写成根元素上的 `--stage-floor`，立绘层读它对脚。
这条线要按**人站的深度**算（机位到看点的四成五处），不是按 lookAt 算；
按 lookAt 算的那一版把昭阳殿的两个人整个顶到了画面上半张去，头顶穿出屏幕。
规矩已写进 `scene.md` 的「留人位」一节。

**二、人和柱子同色又同位。** 立绘站在画面三成和七成处，昭阳殿近处那一对柱子原来正好戳在两个人身上；
而金碧板里主角的主调是石青，殿柱也是石青——人站在柱前，剪影当场糊掉。
近的一对柱子往外让了半米，两条竖带现在是干净的。同一条规矩写进了「留人位」。

**三、旁白的时候所有人都变成半透明的影子。** 不说话的立绘原来压到 0.55 不透明度，
而旁白那种没人说话的时刻**谁都不是 active**，于是两个人一起变淡，贴在 3D 舞台上像没渲染完。
退后靠位置和大小就够，透明度提到 0.74。

**光向那一条不成立，要说清楚**：立绘是平涂剪影，身上没有亮面暗面，所以没有「亮面要和场景光同侧」这回事。
在这套美术里，人和景对不对得上，靠的是**明度差**不是光向。由此查出一个还没解决的问题：
**许静和的主调是清墨，夜景的底色是夜纸，两个值几乎一样亮**，她站在御花园夜里几乎只剩一圈轮廓线。
`character.md` 的正文写「女冠是淡墨」，冻结的十人表里写的却是清墨，两处本来就不一致。
改表会牵动所有场景，而且温荞已经占了淡墨——**这个决定我留给 YIDI 和 CC1**，没有自己改。
