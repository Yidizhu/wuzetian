# C-4 · 第一章书信

Prompt C4／R-004交付。四封正式信件分别由04沈衡、07裴照夜、09李令仪、11温荞触发。沈衡信从C-2迁入，本文件是第一章书信的唯一正文来源，不重复建信。引用与答诗指引均来自已审C0-2三十首；不新增诗库或改动原诗。

## 投递与回应约定

| 项目 | 规则 |
|---|---|
| 双门槛 | 从触发场景结束起算，经过表定后续场数且真实延迟分钟满足，才投递；两者都满足才到信 |
| 场次计数 | 按实际经过的主场次计，条件承接段不另计，未走的13—16不计；重读不累计 |
| 迟到的信 | 写的是离场后落笔时的心事，不随玩家离线时长改成预知后事；信上可显示落笔场次，避免误读成她刚写的 |
| 主线 | 不以读信、回信或到信为通行条件；章末仍未到的信保留队列，不催玩家空等 |
| 六种回法 | 直言A／B／C、以诗代答合意象／不合、不回，六者互斥且各结算一次；不是先选直言再刷一首诗 |
| 合意象 | 行内是C0-2原有标签，命中其一即按合处理；后附具体诗例，帮助理解而非限制玩家只选一首 |
| 不合意象 | 是这封信没接上的话，不是诗写得差；仍认真读完，不扣才、不判玩家不懂诗 |
| 主动不回 | 只有玩家明确选择“不回”才记沉默；未上线、未点开、稍后再答都不是拒绝 |
| 她可能不回 | 发信不等于保证再次回笺；好感条件在收到玩家答复时、加本次好感前判断。未达条件者不立即生成书面回应；表中口头话留到实际相见，不能强制她再写一封 |
| 回应位置 | “她的反应”是一次私下回响，不能作为无条件新场景自动插入主线。明确说“下次见面”的，仅在真的见面时播放 |
| 后续截信 | 本章四封均不截；第二幕“私笺被展开”仍须另交可截信及完整公议承接，不能拿本章任意闲信自动顶替 |
| 笺与颜色 | 各用角色固定笺型；笺名不授权新增界面色值，仍遵循所在阅读界面的色板 |

## 四封信与主线的界限

四封均不含阿荻的旧欠细节，也不能用“她们回信赞成”证明主角12的擅自引用已获许可。她们回信里的温柔、沉默与不同意各有来处，不是替主角集体赦免。

本幕好感最多到识档，四封私信各仅一个回应结算，不重复刷到契或盟；契档求助与盟档代价仍留后幕按既定节奏写。第二幕如用新的私笺引出公开后果，须保持本章这些回信flag并尊重玩家是否写过，不能凭空念出玩家未选的情话。

## 六问自答

1. 最重要的一步靠谁：信把沈衡守原卷、裴照夜核欠饷、公主重算脚程、温荞改未成诗的独立行动带进关系。她们不是只有等主角回信这一件事，主角也不能靠回信买来通关帮助。
2. 女人之间的冲突，原因是价值观还是争宠：沈的证言、公主的宗籍、裴的期限、温的文意都没有被引诗消除。六种回应分别改变相处方式，不给政治分歧判善恶。
3. 本章的“无用”场景是哪一个：05与13—16是正文中的闲处，书信不代替它们凑数。本文件不给闲处加奖励，也不让去坐一会儿变成必须回信的任务。
4. 换成男主角会不会一样：这里写四个有自己职业与立场的女人，彼此愿意看见未完成的判断、私欲和文字。主角明确可以想再见一个女人，也可以暂不接受邀请，无须借别人的情史解释。
5. “她变成了她讨厌的人”的风险：温荞信特别区分分享与转送，沈衡信区分存疑与代言，照见12的错误但不替她修复。回信不得成为自动原谅阿荻事件的机关。
6. 一个2026年的拉拉朋友会不会觉得这是写给她的：亲近不必先认输，拒绝私邀也不必被剥夺共事资格。每个人既有主动递出的那一点，也有可以收回的下一张纸。
