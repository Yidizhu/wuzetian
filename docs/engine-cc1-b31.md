## 三、空镜（D-176）

**剧本怎么写**：说话人「空镜」、类型「旁白」、台词一句环境。转换出来是：

```json
{ "id": "...", "who": "empty", "kind": "aside", "text": "檐下晾着的布晃了一下，院里没有人。" }
```

**引擎怎么走**（`src/engine/story.ts`）：
- 读到空镜格，发 `castExit`，台上的人全部下台，背景整幅露出来；这一句照旁白进对话框，没有名字。
- 下一格是人说的话，发 `castEnter`，人照这一场的名单回来。
  - 下一格是题记或事件图，不算有人开口，人不急着回来；事件图本来就盖住台面。
- **空镜之后这一场没人再开口就出选项、对诗：出之前先把人请回来。** 做决定时台上不能是空的；校验器也不许这样写，这一步是兜底。
- 序幕那种人还没按 entrances 上过台的场，空镜不动：台上本来就空，上台那一格照旧由原来的机制管。
- 换场、读档都清掉。

**界面**：`#app` 在空镜那一格挂 `data-shot="empty"`，人回来就摘。这一格对话框要不要淡、景要不要推，归 CC3，按这个属性写样式。

**校验**（写在 `Scene` 的 schema 里，CC2 的转换测试也会跑到）：
- 类型要写旁白；
- 不带表情；
- 不许两格空镜连着；
- 不许是选项前的最后一格。

「不许带条件以外的东西」：`when` 允许，表情不允许，台词格本来就挂不了选项。
