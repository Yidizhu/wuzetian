## 六问自答

1. 最重要的一步靠谁：开课须许借出确有空闲的屋、温按约教习、阿荻自己决定学哪段；启程须公开核差、实际付钱。主角不能靠恋人的一句愿意免去这些事。
2. 冲突来自价值观还是争宠：13没有主角，温与宋仍为晾纸和夜里取水争一段通道。09的相爱和14的独立差程分开，李不会替裴决定同行。
3. 无用场景在哪里：06添油，18压纸与放笔，均无数值或政策效果。18不以说对一句话换无字碑，冷路线也会经过同一张没有印的纸。
4. 换成男主角会不会一样：私册里结契女人能取回自己的页，宋不替伴侣取，册主也不能借珍惜逼她留名。柳只定水温与旧鞋，不必先交出一段独立宣言。
5. 变成讨厌的人的风险：17入口给冠线的第一份实际收件或退件，才写真后继提名，18不清除旧行为。私册的存留不能替烧掉的公事原案作伪证。
6. 拉拉朋友会觉得写给她的吗：李先把相爱的愿意说出来，主角既可留京也可爱着她去做自己的事。书信可以不回，朋友和恋人仍有各自的屋、路与关门的时辰。
