## 二、第一笔钱买到的两个答案

**① 能不能真的拿到 glb：能。**
`Claude outputs/tripo/peizhaoye-image_to_model-2246e0e9.glb`，2.9 MB。任务回来的是 `base_model`（不是 `model`），外加一张 `rendered_image` 预览——预览图的下载地址两次都 fetch failed，没取到，不影响模型。

**② 能不能设成私密：API 这边没有这个开关。**
- 官方 Python SDK 里 `image_to_model` 的全部参数我逐个核过（`model_version`、`face_limit`、`texture`、`pbr`、`quad`、`orientation`、`smart_low_poly`……），**没有任何 public / private / visibility 之类的参数**。
- Tripo 的服务条款与隐私政策页面，脚本去取返回 403，读不到原文。
- 所以结论只能写到这一步：**API 不提供「设为私密」这个动作；数据怎么保留、会不会公开，由账户档位和条款决定，要 YIDI 在账户设置或条款里看一眼。** D-074 第四条那个问题（十一人全交之前要不要升档）仍然开着。

## 三、顺手记的第三件：和网页那一次**不一样**

| | 网页那一次（D-080） | API 这一次 |
|---|---|---|
| 模型版本 | P2.0 Preview（免费试用） | **v2.5-20250123**（API 不传时的默认） |
| 面 | 5,499 面 / 5,196 顶点，quad | **100,498 三角面 / 54,224 顶点** |
| face_limit | — | 传了 2600，**没生效** |
| 贴图 | — | 关了，回来有 UV、一个材质、没有贴图，符合规格第 3 条 |

**所以「两条路等价」这一条不成立**——不是 API 和网页有区别，是**默认模型版本不同**。网页那次的面数和拓扑是 P2.0 的，API 不指定版本就走 v2.5。
`face_limit` 没生效，要么是 v2.5 不认这个参数，要么要配 `smart_low_poly` 一类的开关一起用；**我没有试**（D-080 第 4 条：失败不自动重试，参数也不自己去猜着花钱）。

**下一笔要 Cowork 定的**：指定 `model_version` 为网页那个 P2 系列（SDK 里列出的是 `P1-20260311`，网页上叫 P2.0 Preview，两个名字对不上，需要先用免费调用查清楚可选值），还是在引擎这边自己减面。

## 六、代码里的花钱纪律（D-080 六条都落进了 `tools/tripo.ts`，不靠自觉）

1. `submit` 要求先跑过 `check`、而且是同一张图
2. 上一个任务没到终态，`submit` 拒绝
3. `rig` 要求那个模型在 state 里被标了「几何验收通过」
4. 任何失败直接退出，没有重试循环
5. 花钱前自动写一行「预计」，任务结束原地补「实际」和余额
6. 每轮上限写在代码里（E8 = 60），账本里这一轮已花 + 这次预计超了就拒绝

这一轮暴露的一个坑也改了：取预览图失败把整个脚本带停了，账本的实际消耗没写上（那一行是人手补的，账本里注明了）。现在附带的下载失败不影响记账。
