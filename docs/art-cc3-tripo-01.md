## 二、给 Cowork 看的两样

### 参考图

`Claude outputs/tripo/peizhaoye-ref.png`（1024 × 1024，喂给 image-to-3D 的那一张）
`Claude outputs/tripo/peizhaoye-ref-sheet.png`（审图页：参考图、它的纯剪影四分之三与正面、现 SVG 裴照夜、沈衡、唐简的纯剪影）

重渲：`npm run tripo -- ref`。源在 `src/scene/tripo-ref.ts`，每一处形体的理由写在代码注释里。

要点：
- **幞头圆领袍**（D-074 第 4 条），不是 SVG 里的束发明光铠
- 四分之三视角、灰阶分四档、主光加轮廓光——**有体积，不是剪影**（D-074 第二条）
- 头是一只光滑的蛋，**没有五官**；幞头两脚短、硬、贴着颈后；**没有飘带、披风、宽袖**
- A 字站姿，两臂离身约三十度，两脚分开——给自动绑骨
- 剑挂左胯外侧垂下，手不在剑上；**剑穗不做**（全身唯一的朱砂，引擎里加）
- 纯剪影下：肩是全身最宽处，全员最高，腰侧一道剑——和沈衡（窄、挺、笔朝下）、唐简（矮、方、前倾）分得开

### 提交参数

```json
{ "type": "image_to_model", "file": { "type": "png", "file_token": "（上传后得到）" },
  "texture": false, "pbr": false, "face_limit": 2600 }
```

| 参数 | 为什么 |
|---|---|
| `texture: false, pbr: false` | 规格第 3 条：贴图一律丢弃，只取几何 |
| `face_limit: 2600` | 规格第 4 条单人 ≤ 3000，留 400 给后补的幞头软脚与剑穗 |
| 其余不传 | 走服务端默认。不拿猜的参数去试错，第一次失败再看是哪一项 |

**没有文字 prompt**：image-to-3D 这个任务类型不收文字描述，形体全由参考图决定。这正是 D-074 选图生的理由。

花钱的命令都要显式加 `--confirm`，不加只打印参数：

```bash
npm run tripo -- submit --confirm      # 约 25 credits
npm run tripo -- wait <task_id>        # 下载 glb 到 public/char/3d/src/
npm run tripo -- rig <task_id>         # 先跑 prerigcheck；能绑再加 --confirm，约 25 credits
```

## 三、参考图第一版为什么不能交

第一版渲出来，审图页上一眼三处错，**要是交上去就是 25 credits 买一个错的裴照夜**：

| 第一版 | 问题 | 第二版 |
|---|---|---|
| 袍的下摆比肩宽，像一只粽子 | 人显得矮胖；她是十一人里最高的 | 肩最宽，往下直直收窄，下摆到小腿肚 |
| 幞头两脚向两侧平伸 | 四分之三视角里读成一顶**棒球帽的帽檐** | 两脚从脑后正中垂下、贴着颈后 |
| 剑斜横过双腿 | 读成腿前横着一根棍；生成出来剑和腿会粘成一块（第四节第 5 条就是防这个） | 贴着左胯外侧垂下，鞘尾往后翘 |

审图页上 SVG 那几格第一版是纯黑方块——CSS 的 `filter: brightness(0)` 把格子底色也涂黑了。改成只把 SVG 里的形涂黑。
