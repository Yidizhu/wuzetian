## 为什么这样画

**这张图要管六场**（C48 布置「晴光」）：

| 场 | 剧本里的时辰 | 事件图 |
|---|---|---|
| ch01-07 | 「次日，园门边的积水映着晴光」 | 驯马：冬天清晨 |
| ch01-14 | 骤雨将歇之后的下午，树上滴水 | 握手：雨后下午 |
| ch01-16 | 「苑墙上还留着半截日光」 | 递叶：傍晚前 |
| ch03-20 | 擦果子上的水 | 相迎：下午 |
| ch04-05qb | — | 裴照夜答复：冷天下午 |
| ch04-05qd | — | 李令仪答复：下午 |

所以时辰取**冬天晴天、午后偏早**：
- 光偏暖，但不是夕阳，驯马那场的清晨也盖得住；
- 地面带一点雨后的湿，只在两侧几处浅水洼，给 ch01-07 那句「积水映着晴光」和 ch01-14 的雨后；
- 太阳不进画面。

**和 `yuanye_ink` v2 对上**：
- 构图附 v2、提示词锁位置，CC1 按 v2 填的脚线 22%、人高 1、推向中间都不用重填。
- 路从前景收向城门，左边柳树、左右两段夯土矮墙和栅栏、右边鼓架和木桶，位置一样不动。

**只换这几样**：
- 夜换成晴天；
- 月亮、星星、左边木桩上的风灯、角楼窗里的灯都去掉；
- 光从左上方来（v2 的月光也在左上，方向不变）；
- 远处宫城城墙和角楼的灰瓦、灰墙，照递叶那张图里苑墙的颜色。

**这一张最可能画错的**（D-200，写成否定式禁止）：
- 照着 v2 把月亮或风灯留下；
- 画成春夏：柳树满枝新绿、草地鲜绿；
- 画成夕阳：金红天、长长的斜影；
- 水洼落在画面中央，或者水面照出清楚的倒影。

**安全区**（背景版）：
- 画面中央三分之一宽、从底边往上到一半高，是人物站的地方：没有水洼、没有光斑、没有树影横过去；
- 手机竖屏只看得见中间三成，那一条里要有：收向城门的路、远处城门和城墙。

**无字**：天。晴天的淡青灰天，没有云纹、没有鸟；鼓架上两面幡是素的，没有字。

## `yuanye_ink_qingguang` · 苑野 · 冬日晴光——素彩

```

中国唐代（公元8世纪，盛唐）宫廷场景图，横构图。
国漫厚涂风格：颜料厚，笔触可见，笔触顺着衣褶和身体的起伏走；每块布料分出亮面、中间调、暗面三层，有体积；
色彩饱和浓郁，是矿物颜料的浓度——不是淡彩，不是水彩，不是照片。布料本身素面无纹，笔触不是布上的花纹。
光：柔和的主光从左上方来，物体有明确的明暗。
画面上有一层很细的布面纹理，和人物立绘上的一样。

这是一张给人物立绘做背景的图：

- 近处没有东西。建筑、器物都在几步开外的中景与远景，按一个一米六的人比，门、柱、案的大小要对。
```
