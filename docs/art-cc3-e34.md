## 一、第三章题记：每列 11 字，「李令仪」不断

B37 改成 26vh 之后，字全在天上了，但每列 10 字，「李」和「令仪。」被拆在两列。

```
候选名单送下后的次晨，｜书阁又开了门。
非宗室的名字列进来了；｜与它并列的，是李令仪。
```

**做法（请 CC1 换掉现在那一行 `height: min(26vh, 240px)`）**：

```css
.tiji[data-vista-key="vista_ch3"] .tiji__cols { top: 8vh; height: 320px; }
.tiji[data-vista-key="vista_ch3"] .tiji__col  { inline-size: 13.1em; }
```

- **为什么按字数卡，不按 vh 卡**：每个字占 1.14em（字号加 0.14em 字距）。11 字是 12.54em，12 字是 13.68em，列宽给 13.1em 就只能放下 11 个字。按 vh 卡的话，手机一高一矮，每列的字数就跟着变。
- **为什么起笔从 13vh 提到 8vh**：每列多一个字，字尾会往下走；提起来之后，字尾落在屏高约 35%，含元殿屋脊在约 40%。
