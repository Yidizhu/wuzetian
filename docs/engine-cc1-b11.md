## 一、标题画面挂上了

YIDI 打开网址第一眼是「纸上已经写好：自愿试骑。」，没有书名，她以为那是个范例（D-048）。标题 CC3 在 E3 就做好了，一直没挂。现在首屏就是它。

**游戏在她点了之后才开始，不在页面加载时开始。** 两个理由：「入宫」那一下是手机上唯一合法的解锁音频的时机；首屏提示要等她进了游戏再说，压在标题上就成了第四样东西。

- 有自动存档时出「接着上次」，没有就只有「入宫」。
- **点「入宫」从头来之前，上一局的自动存档会挪到 `wuzetian.save.0.prev`。** 两个入口一寸远，点错了要捞得回来。玩家看不到这一份，是留给「我刚才点错了」那一句话的。
- `?notitle=1` 跳过标题，给无头验收用。

CC3 那三条接口：

1. **`spriteKey`**：`CharacterLayer` 查图时套一层。缓存改成按最终图名记，不按表情记，否则 flag 变了图不会跟着换。每次换场先对一遍台上的人，归还戏出口写的 flag 在下一场第一眼就生效，不用等她开口。
2. **`setDressing`**：引擎在 `show` 之后调，和 `setInk` 同一个用法，空串 = 平常。
3. **`mountTitle` 的 `resume`**：接上了。

## 二、登场卡

一个人第一次开口时，名字右边一行职务、下一行一句话，只介绍一次。

B11 点名要验的三件事，我做成了机器检查，数据一到跑 `npm run smoke` 就出结论：

1. **走过的章末场都出过结算页。** 尤其是带选项、去向空着的那种（第二章 24 场）。漏了它，玩家照样能走进下一章，只是这一章做完了什么，谁也没告诉她。
2. **走进固定截获点，那封信真的被截了**（第二章 11 场）。没截的话信还躺在案上，朝堂上却在念它。
3. **换图规则要的 flag 在某条路径上会被写真，换过去的三张图真的存在**（第三章 15 场）。表里写了、图也画了，可剧本出口忘了写 flag，柳承欢腕上那点红就永远不会褪。

`npm run validate` 另加一条：**信的附页标了「不宣读」，那句话就不许出现在截获场景的台词里。** 它是整封信的戏眼，剧本要是念出来了，没有任何别的检查会发现。

拿 CC2 现在的半成品跑了一遍：10 秒，三条都守住，走不到的全是还没转出来的场。穷举上限从 120 条路径放到了 400，三章的岔路多得多。

**关于「第二章 11 场只宣读 readAloud 段」**：我看了 CC2 转出来的这一场，宣读是剧本直接写在台词里的，按 flag 分六句，第 18 句沈衡喊停。引擎不往这一场里塞信的正文，所以「只念该念的」靠的是剧本本身，加上面那条 validate 兜底。

## 四、环境声

`src/audio/ambient.ts` 用 Web Audio 当场合成街鼓、风、雨、纸，一个音频文件都没有。主包因此多了几 KB。

| 声音 | 怎么合成 | 什么时候响 |
|---|---|---|
| 街鼓 | 从 95Hz 掉到 42Hz 的正弦，加一记闷的低通噪声当鼓皮；一通越敲越密 | 开局第一场、每次换幕；旁白写到「鼓」也敲，六秒内不叠 |
| 雨 | 带通噪声，音量慢慢起伏 | 只跟场景布置 `yeyu` 走，不跟台词里的「雨」字——「雨停了」里也有雨 |
| 风 | 低通噪声，截止频率被很慢的振荡推着走 | 合成好了，还没接 |
| 纸 | 七十毫秒的高通噪声 | 合成好了，还没接 |

手机上的三条都守了：**默认静音**；`AudioContext` 在「入宫」那一下建，建了不等于出声，上次开着声音的人才会在这里开；**切到后台就停**。HUD 多一个「声：开／关」，点它本身也是一次手势。

浏览器里验到的：偏好开着时点入宫，排进了五个振荡器，就是开场那一通鼓；模拟切后台，音频上下文变成挂起。**好不好听只能你用耳朵判断**，我验不了。

### 登场卡换成了定稿

`src/data/intros.json` 按 C10 的表整份覆盖，十一张，包括主角那一张（「才人｜刚入宫，先问纸上写了谁。」）。最长的 16 字，都在 20 字以内。浏览器里验了前三张：沈衡、吾则添、裴照夜，名字替换也对。

校验加了两条硬规矩：卡的 key 必须是冻结的角色；职务加一句话不许超过 20 字，超了在竖屏上会折成三行，压到立绘的脚。

C10 说许静和的卡「不应在同场名单读入时提前出现，真正来访的旁白是触发位置」。现在的触发是**她第一次开口**，比来访旁白晚一两句，不会提前，只会稍晚。卡挂在对话框的名字旁边，她没开口时那里没有名字可挂，所以这是结构决定的，不打算改。

### 题记：屏蔽加上了，挂不挂等决定

`.tiji` 已经加进点击的屏蔽名单，测试也加了。这一步先做是因为代价为零，而漏了它的后果是点一下题记、剧情跟着翻一页。

题记本身**没有挂**，因为数据里怎么标还没定。CC3 的提议是剧本「说话人」写「题记」、转换器出一种新的台词类型、引擎把连续的题记句收成一次。**我同意这个方案**，理由有两条：它不新增字段，只是台词多一种类型；第二、三章开头那几句短序也能走同一张纸，三章的开头版式就统一了。定下来之后引擎这边的活很小。
