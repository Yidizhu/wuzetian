## 二、主角袍色跟身份（D-091）

新文件 `src/engine/identity.ts`，两个纯函数：

- **`protagonistRank(has)`**：从 flag 推她现在是青、绿还是绯。按一张表从高到低找，第一条成立的就是；一条都不成立是青。
- **`spriteCandidates(who, expr, has)`**：这一格按顺序试哪几张图，第一张存在的就用。
  - 顺序：换图规则（柳承欢的 `_bare`）→ 主角的身份变体 `wuze_<表情>_<身份>` → 原图。

## 四、PNG 评估（第 6 条）

全文在 [engine-cc1-b16-png.md](engine-cc1-b16-png.md)，三个问题的答案：

1. **立绘换图片，改动面不大**：一处查图、`CharacterLayer` 建 `<img>`、一段 CSS。真正要换思路的是两件：
   - 朱砂亮起在 PNG 上没法单独变色；
   - 脚的位置要靠出图规格固定在画布 93%。
2. **场景整图加缓慢推近，是加法**：`SceneRenderer` 接口不用改，`load()` 现在是空的正好用来预先解码图。建议在 CSS 版里加一层整图，有图用图、没图照旧画渐变，大约一百行。
3. **新旧并存**：`spriteCandidates` 已经是「一串候选、第一张在的就用」，PNG 排最前面就行。
   - 写进清单才算上线，清单由人看过截图才加；
   - 校验器守两道闸：清单写了的图文件必须在；PNG 没覆盖的人，旧 SVG 不许删。

**评估里有三件要 Cowork 先定**：
- **PNG 背景走 CSS 那条渲染器，不走 3D。** 3D 舞台要不要继续投入、D-086 真机验回退还有多大必要，要重新看。
- **剧本里没有「昼夜」这一栏**：同一个书阁有白天场也有夜场。现在剧本用到 16 种「地点·色板·布置」，C15 进来是 17 种，再加昼夜会更多。D-095 估的是 15 张。
- **朱砂亮起、膝上还是全身、李令仪礼衣场次**：这三件剧本里都没有来源，或者 PNG 上做不了。
