# 不受 · 从宫门到结局

她被比较、获授，随后亲口说不受，并把交接做完。

依据 CC2《八条线的场次骨架》，数据指纹 887d6a895ec6（CC2 D29已转换C49，提交706bb86；C50图格条件与灰提示待D30复核）；以下是该结局实走路径的合并阅读页，含可选场，**不是把所有岔路串成同一次游玩**。必经与可选沿用 CC2 的标记；其“条件绕不开”包括定向抽样证据，不能冒称穷举证明。信件按骨架的每封拆读口径；CC2现行说明已记载B19修复不拆信跳场，抽样经过比例不等于真实玩家概率。

## 第四章

- **ch04-05p** 她先选往后怎样见面：只问沈衡、裴照夜、温荞或李令仪；如果仍想见不止一人，便逐个说清；如果想独处，便独自过一阵。有私约时先说停，没有生效私约时直接选“独自过一阵”。
- **ch04-05pe〔C38新增〕** 她出门前拿好空笺；如果要问对方，便在门前等应声；如果要问不止一人，便提醒自己不能只说半句。这几句话只在进入循环前出现一次。
- **ch04-05m〔可选〕** 如果选了不止一人，她先逐个确定还想问谁，再出门说清旧约。
- **ch04-05c → 05ca／05cb／05cc／05cd〔按旧约进入〕** 如果未选的人仍有生效或暂停的私约，她便亲自去说停；每说完一人回到05c，直到旧约交代完。05c本身没有台词。
- **ch04-05q → 05qa／05qb／05qc／05qd〔按所问的人进入〕** 如果还要相爱，她逐个听本人答复。只爱一人须双方再答愿意；如果仍想见多人，沈衡与李令仪会拒绝，裴照夜与温荞按听全后的答复决定。有人退出后，如果先前听到的情形变了，就回去重新说清，不能拿旧答复顶替。05q与05m本身没有台词。
- **ch04-05r** 各自答过以后，她回到自己原有的身份与去处，不凭私情改掉受位或辞受的决定。
- **ch04-08z** 她领回自己的稿，接着选择留京、问办学或问差程；未重问出相爱，不会凭旧信恢复恋人身份。
- **ch04-10** 她在苑里吃完一张饼，将碎屑拢回油纸，今晚不再领一份新职责。
- **ch04-17** 她看见柳自己定一件小事，女人的私页与私字仍由本人收好。
- **ch04-18** 她在夜里看空白碑样，放下笔，之后才显出这一路的结局。

## 关系在哪一场以后变了

李不把她的辞受算成自己的支持，重推也没有把皇位私下送给恋人。阿荻的去处、柳的休假与署名仍要归还，03-13—15不因她拒绝皇位便免掉旧账。

## 为什么落在这里

03-08选A/B/C获两项支持；03-11选B说“我不受，请依原议重推”，03-12选B完成辞受交接。第四章01选D领回自己的东西，02选C递本人意见，08z选A去吃东西，经过10、17到18。本线没有李已受位的09/11/14，也没有实际开课与启程；不能把愿意考察写成改走办学或行路。
