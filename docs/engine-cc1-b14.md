## 一、渲染器：切换写好了，默认没切（D-069、R-017）

**玩家现在打开普通网址，拿到的仍是 CSS 版**，线上还没有变。

切换本身写完了。`src/main.ts` 里一行：

```ts
const DEFAULT_RENDERER: "css" | "auto" = "css";
```

你说切的那天把 `"css"` 改成 `"auto"`，别的一行都不用动。在那之前：

| 地址 | 拿到什么 | 给谁用 |
|---|---|---|
| 普通网址 | CSS | 玩家 |
| `?renderer=auto` | **切了之后玩家会拿到的那一套**：3D，扛不住自动退 CSS | YIDI 真机先试回退判据 |
| `?renderer=three` | 3D，**不自动退** | 看 CC3 的进度、量真机帧数（你给 YIDI 的那个地址照旧能用） |
| `?renderer=css`／`null` | CSS／空渲染器 | 验收 |

**auto 下回退的判据**（没改，和上一版一样）：

| 判据 | 数 | 为什么 |
|---|---|---|
| 前几秒不看 | 4 秒 | 首场推镜 2.6 秒，加上编译着色器，本来就慢 |
| 看多少帧 | 最近 120 帧 | 流畅时约 2 秒 |
| 什么算慢 | 七成以上低于 24 帧 | D-003 的线是 30 帧，这里放宽，因为这一刀不可逆，宁可晚切 |
| 什么时候收工 | 累计 20 秒没判慢 | 看够了就不看，不来回抖 |
| 什么不算 | 单帧间隔超过 1 秒 | 切后台、系统弹窗 |

退了之后当场换 CSS，停在同一场同一句；这台设备七天内直接走 CSS。

**验过的**：无头浏览器里普通网址是 `stage--css`，`?renderer=auto` 是 `stage--three`；`?dev=1` 的把手手动触发回退，停在同一场同一句，接着点照常往下走。判据有 6 项单元测试。

**没验到的**：帧数真的掉下去触发回退那一段。我这边的浏览器面板不在前台时动画帧不跑，造不出「卡」。这一条要 YIDI 用 `?renderer=auto` 在手机上证。

## 二、立绘的错（D-072）

先做了两个工具，因为这几个错单看一张立绘看不出来：

- `npm run screens`：整屏截图，手机 390×844 和宽屏 1440×900 各一张，同时打印每个立绘格子的位置、大小、透明度。`--renderer three` 截 3D，`--prologue` 截序幕三段（第三节）。
- `npm run check:sprites`：36 张立绘各画两遍，看每个朱砂点、紫点外面一圈有没有墨，再数半透明的像素。修之前 8 张不过，修完 36 张全过。

| 错 | 原因 | 怎么修的 |
|---|---|---|
| 宽屏立绘整层不显示 | 人的位置按屏宽算、大小按屏高算。竖屏上凑巧对得上，1440×900 上左边那位在 x=−266，右边那位在 x=1272，都被推到屏幕外 | 两样都按屏高算。手机那条单独调过的规则没动 |
| 人物半透明 | 披帛是 72% 不透明度画的，垂到身侧那一截透出背后的柱子；不说话的人整体还有 93% | 披帛改实心；不说话的人不透明度回到 100%，退后只靠位置、大小和一点点虚 |
| 红点浮空 | 宋蕙贞的尺子、温荞的纸是纸色的，放进纸色的场景就看不见了，尖上那粒朱砂悬在半空；主角袖口的点写死在「压案」那个姿势上，换姿势手挪走了点还在 | 尺子改墨色，纸描一道墨边，袖口的点跟着姿势走 |
| 阿荻头身断开 | 颈子收在肩线上方 14 像素，她的短襦领口低，盖不住，露出一道纸色 | 颈子伸到肩线以下 |
| 人与案的比例 | 立绘在每一场都是同样大，和 3D 场景的远近无关 | 加了一个旋钮 `--stage-person`，默认 1，立绘的高度和左右位置都乘它。**只给了旋钮，没替 CC3 拧**：每一场该多大，要在整屏截图里看 |

**清单上没有、我自己在 B11 写出来的一个错**：换场时我先让「对一遍台上的人」跑完，才定这一场的阵容。于是每一场第一个开口的人如果不在前两位，引擎查到的是一张空名单，不把她换上台。阿荻在第一章 03 场说话，台上站的却是主角和宋蕙贞。已改成阵容先定、换图随后再对。

**截图验过**：本地临时把序幕前三句的说话人改成题记，从头开一局，三段各截一张。手机和宽屏、3D 和 CSS 都截了：

截完已把数据改回原样。环境声那边，这一句里带「鼓」字，本来就会敲一通街鼓，所以人上台和鼓声是同一下。

**要说清楚的三件**：

1. **你引的是旧稿的句子。** 「五更三点，街鼓打到第四百下」「阶下有人叫名字，连姓一起叫」是日志里一份早先的序幕表，现在的剧本里没有。现在的序幕是：
   - 题记三句；
   - 第四句「（二十四岁，才人，入宫第四十一日；还在昭阳殿外候名。）」；
   - 第七句「晓鼓还未歇，阶下已有人连姓叫你的名字。」，鼓和叫名字并成了一句。

   我按意思对位：**墨晕开在题记之后第一句，人上台在叫名字那一句。** 一个字没改。

2. **M7 里三段都有了。** C13 已把前三句改成题记，接入之后不改代码、不临时改数据，从头开一局截的三张和第三节写的一样（发布之前线上只有第三段）。
