## 一、默认 3D（D-069）

普通网址现在加载 3D 舞台。CSS 版只在三种情况下出现：3D 起不来、这台设备最近卡到退过、或者验收时手动指定。

**回退的判据**：

| 判据 | 数 | 为什么 |
|---|---|---|
| 前几秒不看 | 4 秒 | 首场推镜 2.6 秒，加上编译着色器，本来就慢 |
| 看多少帧 | 最近 120 帧 | 流畅时约 2 秒 |
| 什么算慢 | 七成以上低于 24 帧 | D-003 的线是 30 帧，这里放宽，因为这一刀不可逆，宁可晚切 |
| 什么时候收工 | 累计 20 秒没判慢 | 看够了就不看，不来回抖 |
| 什么不算 | 单帧间隔超过 1 秒 | 切后台、系统弹窗 |

**退了之后**：当场换成 CSS 版，停在同一场同一句，玩家手上的事照常；这台设备记住，**七天内**直接走 CSS，过了七天再给 3D 一次机会。`?renderer=three` 立刻清掉记录重试，而且这个参数下**不自动退**——验真机帧数时要看的就是它慢的样子。

浏览器里验过：用 `?dev=1` 留的把手手动触发回退，画面从 3D 换成 CSS，停在同一场同一句，接着点照常往下走，刷新后这台设备直接走 CSS。判据本身有 6 项单元测试。

**有一件没验到**：帧数触发的那一段。浏览器面板不在前台时动画帧根本不跑，监看也正确地停了，所以我在这边没法真的让它「卡」起来。这一条要 YIDI 的手机来证。

## 二、立绘的错（D-072）

先做了两个工具，因为这几个错单看一张立绘看不出来：

- `npm run screens`：整屏截图，手机 390×844 和宽屏 1440×900 各一张。同时打印每个立绘格子的位置、大小、透明度——「看不见」到底是没画、画在屏幕外，还是透明，数字分得出来。
- `npm run check:sprites`：36 张立绘各画两遍，看每个朱砂点、紫点外面一圈有没有墨，再数半透明的像素。修之前 8 张不过，修完 36 张全过。

| 错 | 原因 | 怎么修的 |
|---|---|---|
| 宽屏立绘整层不显示 | 人的位置按屏宽算、大小按屏高算。竖屏上凑巧对得上，1440×900 上左边那位在 x=−266，右边那位在 x=1272，都被推到屏幕外 | 两样都按屏高算。手机那条单独调过的规则没动 |
| 人物半透明 | 披帛是 72% 不透明度画的，垂到身侧那一截透出背后的柱子；不说话的人整体还有 93% | 披帛改实心；不说话的人不透明度回到 100%，退后只靠位置、大小和一点点虚 |
| 红点浮空 | 宋蕙贞的尺子、温荞的纸是纸色的，铺进纸色的场景就没了，尖上那粒朱砂悬在半空；主角袖口的点写死在「压案」那个姿势上，换姿势手挪走了点还在 | 尺子改墨色，纸描一道墨边，袖口的点跟着姿势走 |
| 阿荻头身断开 | 颈子收在肩线上方 14 像素，她的短襦领口低，盖不住，露出一道纸色 | 颈子伸到肩线以下 |
| 人与案的比例 | 立绘在每一场都是同样大，和 3D 场景的远近无关 | 加了一个旋钮 `--stage-person`，默认 1，立绘的高度和左右位置都乘它。**只给了旋钮，没替 CC3 拧**——每一场该多大要在整屏截图里看 |

**清单上没有、我自己在 B11 写出来的一个错**：换场时我让「对一遍台上的人」先跑完再定阵容，于是每一场第一个开口的人如果不在前两位，引擎查到的是一张空名单，不把她换上台。阿荻在第一章 03 场说话，台上站的却是主角和宋蕙贞。已改成阵容先定、换图随后再对。

发髻形状、梯形身体没有动。

**截图里还看得出一件，不归我修**：宽屏上 3D 的机位离得太近，建筑占满画面，人显得小而且像飘着。这是 3D 取景按竖屏定的，归 CC3 的整屏闭环。
