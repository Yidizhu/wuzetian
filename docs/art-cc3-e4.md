## 二、立绘石青：这一轮最要紧的一条

**症状**：主角在昭阳殿里整个人被渲染成石青，和殿柱同色同位，剪影当场糊掉。

**原因**：立绘的颜色直接绑了 `--c-ink-*`，那是**场景色板**的变量。金碧板里 `--c-ink-1` 是石青，
于是「主调浓墨」的主角在朝廷场景里变成了一个石青的人。

**规则**（已写进 `art-style/references/character.md`「人不随色板变」和 `palette.md`）：

> 金碧只属于场景与器物。人永远走墨色。

实现是一组不随色板变的变量 `--c-char-line`、`--c-char-1` 到 `--c-char-4`，值就是墨五色，
两块色板下都不重新声明——和 `--c-ink-wash` 是同一个道理：有些东西不该跟着色板走。

三条推论一起记住：

1. **一个角色在两块色板下是同一个人。** 她走进朝廷不会变成朝廷的颜色。
   这不只是技术规矩，是这个游戏的意思：金碧是「被规定好的」，人不是。
2. **唯一的暖色仍是那一处朱砂点**，在金碧场景里按老规矩转泥金（D-010 硬规则 1），
   主角做不可逆决定的那一刻亮回朱砂。身上没有第二处暖色。
3. **对照表原来验不出这个 bug，也一并修了。** `docs/char-sheet.html` 用 `<img src>` 引 SVG，
   而 img 里的 SVG 是一个**独立文档，拿不到页面的 CSS 变量**——「切色板」那个按钮等于没接线，
   切到金碧，图还是用自己的回退色。现在改成内联，切色板与纯剪影两个按钮都说真话了。
   页面从 5 KB 涨到 158 KB，是 dev 文档，值。

**这条我要认**：桌面上屏幕大、立绘小，蓝得不明显；我三轮都是在桌面截图上自评的，
没在手机尺寸下逐场看过金碧场景里的人。手机实机一眼就是错的。

## 三、竖屏构图

三处，都对着手机上的实际观感：

**一、脚要露出来。** 地平线的下限从 -8% 卡到 **21%**——对话框的顶边大约在 19% 处，
再低，人就被切在小腿上，看着像半截埋进了框里。宁可让她站得比真地平线高一点点，也不能让她没有脚。

**二、人放大，上方留白收。** 手机上立绘从 64% 提到 72%（art-style 规格是 62%–78%）。
64% 那一版画的人只占到画面一半高，头顶上空着三分之一，而这一屏本来就窄。桌面从 78% 降到 76%，
两边靠拢，同一套构图在两种屏上不会差太远。

**三、不说话的人别太透。** 从 0.74 提到 0.86。人改走墨色之后本来就压在同样是墨的场景上，
再透就没有剪影了。退后靠位置和大小已经够。

**四根数值墨线**：宽度 2px → 3px，最高一档再加粗到 5px；色阶从清墨起步改成**淡墨起步**。
原来第 0 档是清墨 `#C9C4B8`，画在纸上根本看不见，头两档也分不开。
现在四档墨色加一档加粗，手机上「淡→重」那一跳看得出来。
（这一改动动了 ui.md 写的「用墨色浓淡表示高低」的字面：仍然是墨色浓淡，只是最高一档另加了宽度。
理由是纸上的清墨不是一个能被看见的值。）

## 四、D-046 三条的落地

**1. `_bare` 表驱动。** `src/char/sprite-rules.ts` 导出一张表和一个函数：

```ts
spriteKey(who, expr, has)   // has(flag) 由引擎给
```

表里现在只有一行：`liuchenghuan` ← `flag.chenghuan_returned` → 后缀 `bare`，
附一句为什么。以后谁再有这种事，往表里加一行，`CharacterLayer` 一个字都不用改。
函数返回的名字**不保证存在**，调用方拿不到图要退回 `<who>_<expr>`——
这样即使表里写错一行，最坏也只是没换成图，不会白屏。

**2. 公议走 `Scene.dressing`，而且调用顺序不再有讲究。** 有几种布置改的是几何和光，
不只是 `visible`（夜雨、受位）。原来这要求引擎必须在 `show` **之前**调用 `setDressing`，
那等于给别人加一条隐形的调用顺序规矩，迟早出错。
现在 `setDressing` 发现值变了就**原地重搭一次**——不走 `show`，所以没有墨晕，
也不打断正在跑的推镜。`show` 之前调、之后调，结果一样。已验：
`show` 之后调 `setDressing("yeyu")`，面数 856 → 928，夜与雨都上来了。

**3. 标题两个入口。** 主入口「入宫」，字大一档、墨色重一档；「接着上次」在它**正上方**，
小一档、淡一档，只有存档存在时才出现。两个都竖排——这一屏没有一个横着的字。

## 五、两个新场景状态

**女冠观 · 夜雨（`yeyu`，第三章 10 场夜谈三）。** 同一座观，换成夜里下雨，檐下一盏灯。
**一件几何都没改**——地方没变，是时候变了。改的是三样：ramp 从阴天的近乎平的三档换成夜的高反差、
半球光压到 0.34、檐下挂一盏灯并给它一个点光。雨是一层 CSS：两组疏密不同的斜线叠着慢慢平移。
一组匀速的雨在水墨里是假的，两组间距不成整数倍才像。
`negative.md` 禁的是粒子和发光，一层斜线不在其内。

**含元殿 · 受位议决（`shouwei`，第三章 12 场）。** 公议的案照摆，但光**从正面顶上压下来**，
全场最强，殿不再是剪影——**这是全游戏唯一一次金碧场景不压暗**。
前面十一场她都在逆光里看着这座殿，这一场殿被照亮了给她看。
