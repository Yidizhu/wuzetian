## 六问自答

1. 最重要的一步靠谁：13靠可核的调令与封簿，22靠各项劳动与支付实据，23才依法颁行。25柳确实替主角办成事，但主角能拒绝用她的抄试换自己的半日，不能把能力当无限征用的理由。
2. 女人之间的冲突，原因是价值观还是争宠：宋拒绝拿披帛换无限值夜，温许争工作时辰，李保留自己的财政主张。柳也不争谁更配主角，她把主角要的当自己的，这才构成另一种困难。
3. 本章的“无用”场景是哪一个：15—19五选一都无收益，21是另列的旁观，不把有新信息的场算作无用。柳自己的无用场另在第三章独处时写，不借她替主角端水充数。
4. 换成男主角会不会一样：私情被记录的时机、女冠的差务、结契者的生活都具体落在女性制度处境。承欢与阿荻一个请求被代言、一个拒绝，主角的两种反应比一句立场更能暴露她怎样使用别人的信任。
5. “她变成了她讨厌的人”的风险：有，25的接受明明白白让她得势、失心，26不否认被这种照顾爱着很舒服。全拒绝者仍可有心动，却不被强造一次接受；接受者也不能靠一句提点让承欢立即独立，第三章须逐件归还决定。
6. 一个2026年的拉拉朋友会不会觉得这是写给她的：能看见坚持边界的四位，也能认出把爱人当全部的承欢，后者没有被嘲笑或写死。她的能力与温柔都真，叙事把代价交给受益的玩家，不把她的困境当坏女人的报应。
