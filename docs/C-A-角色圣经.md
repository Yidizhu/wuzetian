## 六问自答

1. 最重要的一步靠谁：本稿还不是章节，但关键知识已分散到沈衡、唐简、阿荻、宋蕙贞等人手里。主角必须与她们共同解决问题，没有一个男性在幕后保证她成功。
2. 女人之间的冲突，原因是价值观还是争宠：清河公主争的是承统资格，宋蕙贞争的是改革过渡中的供给，沈衡争的是异议记录。四条亲密关系也不会把相互争夺主角变成她们的中心任务。
3. 本章的“无用”场景是哪一个：尚未交章节，不冒称已经满足每幕检查。第五节提供共读、拆衣结、学鸟叫等候选，采用后明确取消数值和隐藏收益。
4. 换成男主角会不会一样：这组冲突来自女性皇族拥有资格而普通女子仍被隔在外面的结构，也来自女性在内廷劳动、署名与照料中的处境。恋人是有自己政治边界的女人，不是给通用帝王故事换两张女性立绘。
5. “她变成了她讨厌的人”的风险：有，而且有具体触发点：替阿荻公开经历、要求沈衡删异议、让裴照夜以兵助势。若玩家坚持这些做法，正文必须保留关系破裂与制度伤害，不能用最终成功洗去。
6. 一个 2026 年的拉拉朋友会不会觉得这是写给她的：她能看见理直气壮的邀请、被照料的轻松，也能看见政治意见不同仍可亲密的难处。体验仍需正文验证，但本稿已排除刷满好感兑换恋人、把年长女性写成嫉妒者、把离开写成背叛的结构。
