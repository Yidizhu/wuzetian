## 二、自动审查循环

```bash
npm run art:loop                  # 全部
npm run art:loop -- --since E6    # 只跑这一批
npm run art:loop -- --only yilu   # 只跑一个场景
npm run art:loop -- --no-fix      # 只量不改
```

一条链，D-060 原样：自己起 vite（5177）和无头 Chrome → 视口压成 390×844 @2x → 逐个开舞台抽查台，
读它当场从画布像素算出来的数 → 按 `src/scene/shots.ts` 的 `GATES` 判六条（面数、每帧、留白、朱砂、紫、色板外）
→ 不过就改、重跑，最多三轮 → 还不过就停，报告写明卡在哪一条、值是多少。零新依赖（DevTools 协议 + Node 自带的 WebSocket）。

**两条边界照 D-060 守住：**

1. **只自动改一个旋钮：取景倍数。** 留白不够就往后退一成，到 1.3 倍为止；试出来的值写回 `src/scene/stage-tune.ts`。
   面数、毫秒、朱砂、紫、色板外卡住，**一律不自动改**——减哪件东西、哪一点红该留，是画面的意思。
   而且只要有一条不是取景能救的，连取景也不试：拿退镜头去稀释一点多出来的红，是作弊。
2. **一律手机视口、真 GPU。** 开头打印显卡名；遇到软件渲染，毫秒那一条自动标「不作数」而不是判过。

报告末尾把**机器不判的**列成清单，旁边是每张截图的路径：恐怖谷、是不是仙侠了、换成男主角会不会一样、剪影、姿态、节奏，
外加一条 E5 那匹马教的——**这里该不该有这个东西**。

**顺带改了测帧的方法。** `benchmark` 原来只量 CPU 把命令交出去的时间，GPU 画没画完不知道。
现在跑完最后读回一个像素，逼 GPU 把排着的帧画完再停表。试过逐帧读回，读回本身就要两三毫秒（280 面的碑量出 3.3 ms），
所以只读一次。**E6 起的毫秒和之前报告里的不能直接比**：量法变了，机器也从预览面板换成了无头 Chrome。

### 自检：那条改的分支是真的会跑

这一批第一轮就全过，「不过→改→重跑」一次都没发生过。**没跑过的代码不算做好了**，所以加了 `--blank-bump`，
把留白门槛临时抬高逼它走一遍：

```
昭阳殿 · 夜 · 一盏灯   第1轮 fit 1.00  留白 48.5%  ✗ 留白
昭阳殿 · 夜 · 一盏灯   第2轮 fit 1.10  留白 52.8%  ✓
```

退一成、重跑、过、停。自检那一次**不写回** `stage-tune.ts`，这一条也验了（文件仍是空表）。

## 三、这一轮最该记住的一件事：五样新东西，闸门全过，其中三样眼睛一看是错的

指挥部说这是「第一批从头到尾没经过人眼估算的资产，正好当验证」。验证的结果是：

| 第一版 | 数字 | 截图上 | 改了什么 |
|---|---|---|---|
| 驿路 · 启程 | 留白 64.4%，六条过 | 路面从机位脚下铺起，竖屏下半张一整块灰楔子——**正是 E1 禁的那块地板** | 改了两次。第二版从车后铺起，还是楔子；第三版带子只画远的一段，近处只留两道车辙。留白 86.5% |
| 驿路 · 驿旁 | 留白 61.9%，六条过 | 驿贴着画面左边，屋顶被切成一块悬空的黑三角 | 驿挪到路左、人的身后，整个屋角进画 |
| 昭阳殿 · 水墨 / 夜灯 | 色板外 0.09%，过 | 横梁重墨，仰视下成了一道黑框；灯的暖光把近处浓墨柱子染出一道赭色 | 水墨版横梁退淡墨、帷幔退清墨；灯光近乎白、够不着柱子。色板外降到 0.00% |

**闸门量的是「有没有越线」，量不出「这是不是一块地板」。** 数像素这件事交给机器之后，人省下来的眼睛要花在截图上，
不是花在更信任数字上。这条写进了 `art-style/references/scene.md`「自动审查循环」一节。

## 四、五个新状态

**无字碑 · 碑样（`beiyang`，四章 18 夜谈五）。** 印拿掉之后画面上亮的只剩一样：碑前那张碑样纸。
碑面在夜里退到夜纸色，所以最亮的不是碑，是还没刻的那张样。纸角翻起一只（「纸角翻到背面，今夜不命人写满它」）。
旁边一小块浓墨是封着的私册——和碑是一对，谁都不打开。**没有月亮、没有灯**：这一场不作诗、不给答案，画面也不给光源这个「焦点」。
石是空的石，不是谁的帝陵，非登基线来这里也成立。

**驿路（`yilu`）。** 「关山有信」的意象就是路，所以路要真的在画面上：近处两道车辙从画面下沿进来，
远处才收成一条清墨的带子，**收进两片远山之间的空里——路的尽头是留白**，她要去的地方画面不替她画。
右侧三座里堠，牌子是空的（无字碑母题）。左边一株柳，不折。
- 启程：清晨雾，运粮车停在路上、车头朝路的尽头，辕还搭在地上——牲口没套、人没走。车下一摊重一档的车泥。
- 驿旁：一个月后的午后，横光。驿只露一角（驿是歇脚的地方，不是去处），一块坐人的石、一只倒放的靴（脱靴倒砂），
  远处路上一辆很小的车——先走的那一队已经在路上了。

**昭阳殿 · 水墨（四章 01、04）。** 她登基后回到这座殿，殿第一次是墨的。几何一件不动——还是那座殿，变的是谁在画它。
台基不铺（金碧的「满」散掉），地砖缝成了纸上四笔淡墨；三对柱子按远近退墨，近浓中重远淡；
匾是清墨的空匾。马的位置换成一张低案：一张纸，一支笔横在纸边，**笔没有落下去，那一笔归玩家**（01「自己落这一笔」）。

**昭阳殿 · 夜灯（`yedeng`，四章 06 夜谈四）。** 照女冠观夜雨的做法：几何不动，改光、挂灯。
灯在案角，比书阁那盏矮一截、盏小一圈——「灯油添到一半就停」，所以灯要小。补一面清墨后墙，不然柱子后面就是夜纸，远近没了。

**女冠观 · 开课（`kaike`，四章 11—13）。** 三领席、门前一张讲案（案上摊一叠经折册，不是线装，C-12 名物表）、
松与一根竹竿之间一道绳，挂三张纸——温荞槽里出的纸，还没有字。常驻、切 visible。
席横着、矮着，和这座观「横线多、块面矮」的松弛是一路，不画成学堂的规矩样。

**「最该改的一条」**：
- 碑样：夜靠的只是底色换夜纸，没有一件东西在说「夜」。
- 启程：路面带子的近端是一条硬边，看得出是一块板从那里开始。该做成两三段逐段变淡。
- 驿旁：焦点散——驿角、石与靴、远处的车三处差不多重。石与靴应该是那一处。
- 昭阳殿水墨：近处那对浓墨柱子仍是全场最重的，焦点被框抢走；那张案才该最重。
- 夜灯：留白 48.5%，离 40% 最近，两根柱子加后墙把右半张填得偏满。
- 开课：**全场最弱**。前景的香炉和席挤在下沿，晾纸那三张纸在屋檐的重墨前面几乎看不见——这一场的无字碑母题落空了。下一轮先改它。
