# 《吾则天》游戏电影美术分镜调研与镜头手册

> 版本：2026-09-16  
> 用途：指导剧本分镜、图片放置、镜头连续性、事件图立项与最终合成验收。  
> 适用对象：编剧、分镜、美术、提示词编写、前端演出与验收人员。

## 一、结论先行

《吾则天》最适合的镜头体系，不是把视觉小说剪成一部不断换机位的电影，而是：

**以稳定的“舞台空间”保证阅读与人物关系，以少量电影化切镜标记叙事关节。**

现有资产已经足以组成完整镜头语言：

1. 章首风景图负责“时代、地域、章节气息”；
2. 场景背景负责建立稳定空间；
3. 立绘负责普通对白、人物站位与关系距离；
4. 空镜负责换气、时间流逝和情绪余波；
5. 风物图负责物件特写、节令和民生证据；
6. 事件图负责身体动作、关系改变和不可逆时刻；
7. 结局图负责停止叙事，而不是继续解释。

推荐的总原则是：

> **每一次换图或换景别，必须至少增加一种新信息：空间、权力、动作、物证、关系或心理阈值。没有新信息，就不切。**

这条原则能直接解决三类常见问题：图片很多但像相册；单图漂亮但连续播放失去方向；事件图太密导致所有场面都一样重要。

## 二、调研所得：电影语言怎样翻译成游戏语言

### 2.1 电影的“镜头”，在本项目中不是一张图

电影镜头由景别、机位、构图、表演、运动和剪辑共同构成。《吾则天》没有自由摄影机，仍然可以通过以下变化制造镜头感：

- 背景是否有人；
- 同屏一人还是两人；
- 全身、膝上还是局部特写；
- 主体位于左侧、右侧或画外；
- 前景是否遮挡；
- 画面是场景、人物、物件还是事件图；
- 淡入、墨晕、停顿、声音桥与点击节奏；
- 切图前后的注视方向、动作和色彩是否相接。

所以分镜单元应定义为“玩家连续看到的一种画面状态”，而不仅是素材文件。

### 2.2 游戏不能照搬电影的切镜密度

电影会用正反打维持对白节奏；视觉小说的节奏主要由阅读和点击形成。如果每句话都换景别，玩家既要重新找人物，又要读文字，注意力会反复重置。

本项目建议：

- 普通对白以一个稳定中景承担；
- 关系或权力发生变化时才改变站位、人数或景别；
- 物证、手部动作、节令物件出现时切插入镜头；
- 身体接触、重大抉择、身份变化才使用事件图；
- 说完以后需要余味时，回到人物中景或退为空镜，不立刻接另一张高潮图。

这与《十三机兵防卫圈》的固定透视“舞台演出”思路、以及《Kentucky Route Zero》借鉴舞台美术和慢电影的做法更接近，而不是模拟真人电影的多机位拍摄。

### 2.3 连续性比单张构图更重要

电影连续性剪辑的核心，是让玩家始终知道人物在哪里、看向哪里、动作怎样完成。常用工具包括视线匹配、180°轴线、动作匹配和视觉焦点延续。对本项目而言，它们可以直接转化为：

- 同一场内人物左右位置不能无故互换；
- A 看向右侧，下一张被看的人或物应出现在画面左侧附近；
- 手伸向物件后，下一张特写要延续同一方向和同一只手；
- 上一张焦点在右上，下一张不要把新重点突然放到左下，除非要制造惊扰；
- 背景光从左侧照来，立绘和事件图也要服从同一光向；
- 人物脚底、地平线、室内台基高度要保持一致，避免人物“漂浮”。

## 三、项目资产与镜头职责

| 资产类型 | 在电影中的职能 | 最适合表达 | 不宜表达 |
|---|---|---|---|
| `vista_ch1—4` 章首风景 | 大远景／建立镜头 | 朝代气息、地域、章节转折 | 具体对白与细微动作 |
| `public/scene` 背景 | 主镜头／舞台全景 | 稳定空间、人物站位、权力格局 | 身体接触的细节 |
| 角色立绘 | 中景／中近景／双人镜头 | 对话、态度、关系距离 | 复杂的手部交互 |
| 无人空镜 | 空镜／反应后的停顿 | 时间、天气、余波、缺席 | 新剧情事实 |
| `wu_*` 风物图 | 插入镜头／物件特写 | 节令、饮食、民生、证据 | 角色关系高潮 |
| 普通事件图 | 关键动作镜头 | 触碰、递交、坐近、受位、拒位 | 日常寒暄和重复表情 |
| 结局图 | 终止镜头／尾声画面 | 不可逆结果与最后意象 | 补充剧情说明 |

### 推荐的素材调用顺序

```text
章首风景／空镜
        ↓ 建立时间与空间
背景 + 立绘
        ↓ 建立人物关系
单人或双人中景
        ↓ 推进对白
风物特写／事件图
        ↓ 给出证据或完成动作
返回中景／空镜
        ↓ 让结果落地
下一场
```

事件图不是“更漂亮的立绘”，而是前后两个画面状态之间的转折铰链。

## 四、《吾则天》应采用的镜头类型

### 4.1 建立镜头 EST／大远景 EWS

**素材：**章首风景、无人背景、殿宇或坊市全貌。  
**用途：**第一次进入地点、时间大幅跳转、章节开头、政治空间变大。  
**长度：**通常一格文字或一次短停顿即可。

使用规则：

- 第一次进入新地点必须建立空间；同一章节频繁返回旧地点不必重复；
- 画面只交代“看得见的事实”，不代替旁白解释情绪；
- 下一镜主体应落在建立镜头已经留下的视觉区域内；
- 朝廷空间可更整饬、更满；私人空间和主人公视角保留更多空白。

### 4.2 全景／全身镜头 WS／FS

**素材：**全身立绘 + 背景。  
**用途：**人物入场、离场、站位、身体姿态、权力距离和玩家做决定的时刻。

本项目现有“出现选项时退成全身”的规则是正确的：决定前镜头退开，玩家能重新看到人物与空间的完整关系，而不是被面部情绪替她做决定。

### 4.3 膝上中景 MS／MLS

**素材：**膝上立绘 + 背景。  
**用途：**普通对白的默认镜头。

它应该承担全游戏最多的时长。中景稳定，才能让近景和事件图显得重要。

### 4.4 单人中近景 MCU

**素材：**单人膝上立绘，另一人退出或转淡。  
**用途：**提出关键条件、承认真实意图、拒绝、追问、改变立场。

不要因为“这一句很感人”就切近。判断标准应是：**这句话是否改变了下一步行动。**

### 4.5 双人镜头 Two-shot

**素材：**背景 + 两人立绘，或双人事件图。  
**用途：**结盟、对峙、照料、试探、关系被重新定义。

构图要求：

- 一屏最多两人，继续保留；
- 避免两人等高、正面、左右镜像，像证件照；
- 主动者可稍前、被动者稍后；说话者更实，沉默者更淡；
- 两人视线同向表示暂时同盟，反向表示分歧，相向表示直接交锋；
- 同框不等于亲密。空隙大小、遮挡与朝向才定义关系。

### 4.6 越肩镜头 OTS／带肩单人镜头

**素材：**可用前景衣袖、肩部暗形或局部遮挡模拟；不建议为普通对白大量新绘。  
**用途：**审问、逼迫、窥见对方表情、权力明确不对等的谈判。

由于本项目重视女性主体，不应把越肩镜头做成窥视身体的构图。前景只负责交代空间关系，不能遮住关键手势和面部。

### 4.7 特写 CU／大特写 ECU

**素材：**风物图、手、纸、印、针、灯、绳、衣袖、折痕。  
**用途：**证据、劳动、触碰前后的犹疑、权力落在具体物件上的瞬间。

本项目应优先拍“手与物”，少拍孤立的脸部大特写。唐代生活质感、女性劳动与制度权力都更容易通过物件显形，而且不会把人物变成被观看的面孔。

### 4.8 插入镜头 Insert

**素材：**`wu_*` 风物图，或未来新增的小型物证图。  
**用途：**灯轮、冷灶、月酒、茱萸、酥山、冷淘，以及信、名簿、差牌、稿纸、印绳等。

插入镜头最好采用三拍：

```text
人物看／伸手 → 物件特写 → 人物回应或动作结果
```

这样物件不是插图，而是被人物看见、触碰并改变了行动的叙事材料。

### 4.9 事件图 CG

**用途：**普通立绘无法准确表达的身体关系或不可逆动作。

满足以下任一条件，才值得新增事件图：

- 两人发生明确的手部或身体接触；
- 人物递交、放下、穿上、解下某件改变身份的物件；
- 主角先主动靠近、亲吻、坐到对方身侧；
- 一次动作同时改变人物关系和后续分支；
- 场面依赖特殊空间构图，立绘站位无法表达。

如果只是换表情、说一句重话或呈现已有地点，不应新增事件图。

### 4.10 高机位、低机位与倾斜构图

- **高机位／俯看：**适合朝议、制度压人、个人被空间吞没；不用于表现女性弱小或供人观看。
- **低机位／仰看：**适合殿柱、台阶、受位等制度性威势；不要把人物自动拍成英雄海报。
- **倾斜构图：**只在认知失衡、路线断裂或蓄意越轴时使用；普通紧张不需要倾斜。

本项目的“镜头角度”更多应由背景透视、台阶高度、主体在画面中的上下位置完成，而不是新画大量不同角度立绘。

## 五、图片放置规范

### 5.1 画面必须先为 UI 留位置

最终画面不是原图，而是：

```text
背景 + 立绘／CG + 对话框 + 姓名 + 选项 + HUD + 手机裁切
```

因此构图与验收都必须看最终合成，不能只看美术原图。

现有安全区继续作为硬约束：

- 画面底部约 22% 可能被对白区域遮挡；
- 左右各约 8% 可能在设备适配中损失；
- 重要面部、手、信、印、差牌等不能落入这些区域；
- 横向 CG 的关键焦点必须登记 `focus`；
- 竖向 CG 在宽屏使用完整展示和两侧虚化时，中央原图必须独立成立；
- 画面留白应朝向人物的视线或运动方向，而不是随机留在背后。

### 5.2 建议的横向九宫格

```text
┌────────┬────────────┬────────┐
│次要环境│ 标题／远景  │次要环境│
├────────┼────────────┼────────┤
│左人物区│ 关系／动作区│右人物区│
├────────┼────────────┼────────┤
│可遮区域│ 对话框区域  │可遮区域│
└────────┴────────────┴────────┘
```

- 面部通常落在上中部，不贴顶；
- 双人动作应发生在中央关系区，但人物不要都居中；
- 物件若要被读到，应高于对白框上沿；
- 背景中最强对比和最亮区域不要与文字争抢；
- 手机竖屏裁切时，核心叙事应能落在中央约三分之一区域。

### 5.3 背景的“人物停靠区”

每张背景至少要有一处低干扰区域供人物站立：

- 背后不出现穿头的柱、树、门框或高亮灯笼；
- 脚下有明确承重点，地面透视和人物比例一致；
- 左右两侧至少一侧能容纳第二人；
- 光源方向和强弱明确，便于立绘匹配；
- 夜景不要只把背景压黑，人物仍需受到同一颜色的环境光。

### 5.4 留白比例与权力表达

- 水墨场景留白不低于约 40%；
- 金碧朝廷场景可更密，但仍应保留约 30%呼吸区；
- 朱砂等强调色控制在约 3%，用于不可逆决定或关键物件；
- 主角越能自主决定，构图越应给她面向的方向留空间；
- 制度压迫越强，建筑、帷幕、台阶越可挤压人物，但不靠缩小、俯视女性身体来表达。

## 六、连续性圣经

### 6.1 轴线与左右位置

两人对话时，在她们之间想象一条线。一个场景内，所有画面默认从同一侧观看：

- 已建立“吾则添在左、对方在右”，后续单人镜头也应保持对应朝向；
- 不得因素材构图方便而突然镜像人物；
- 必须换边时，先使用正面双人镜头、无人空镜，或展示其中一人穿过另一人的动作；
- 蓄意越轴只能用于权力翻转、认知断裂或关系重新定义，并在分镜表中写明原因。

### 6.2 30°变化原则的项目化版本

同一人物连续两张图，如果构图变化太小，会像人物突然跳动。每次切换至少做到一项：

- 景别跨一个完整等级，例如全身到膝上、膝上到手部特写；
- 人物数量变化，例如双人到单人；
- 动作状态发生清楚变化；
- 视角越过明确的前景层；
- 时间、地点或光线发生变化。

否则使用淡变或保持原画，不要硬切。

### 6.3 视线匹配

- 人物向右看，下一张被看对象应偏左出现；
- 两人相看时，眼睛高度不必完全相同，但透视和站位要说得通；
- 人物先看，物件后出现，玩家会自然理解物件属于她的注意；
- 若人物避开视线，下一镜不要立刻给正面凝视，除非这是明确的关系转折。

### 6.4 动作匹配

重要动作应跨镜头连续完成，而不是每张图各摆一个姿势：

```text
手开始伸出 → 事件图中接触／递交 → 回到中景，手已经收回或物件已换主
```

项目现有事件图的前后规则可继续固定为：

1. 前一格写她看见了什么或动作将要发生；
2. 事件图完成动作；
3. 后一格写动作之后没说出口的东西或现实后果。

### 6.5 道具、服装与身体连续性

每场分镜必须记录：

- 信、纸、印、灯、针、朱绳等在谁手里；
- 使用左手还是右手；
- 物件是完整、展开、折起、放下还是已交给别人；
- 主角当前穿青、绯或其他身份装束；
- 发式、冠饰、伤病、湿衣、灰尘是否延续；
- 座次、台阶、案几、门口方位是否保持。

### 6.6 光线与色彩连续性

- 同场景所有人物服从同一主光方向；
- 日景进入夜景必须有时间桥，不直接改色；
- 事件图若色温明显不同，应把它定义为主观记忆或重新调色；
- 水墨与金碧的变化对应主人公和朝廷力量关系，不因单张图好看而任意切换；
- 朱砂变化要与决定发生在同一叙事拍点。

### 6.7 声音桥

图片切换前先让下一场声音出现，可以减少硬切感：雨声、马铃、纸响、殿上脚步、灯轮转动、远钟、风过栏杆。声音桥尤其适合：

- 空镜转人物；
- 室外转室内；
- 章首风景转第一场对白；
- 事件图结束后回到中景。

## 七、五套可直接套用的分镜序列

### 7.1 普通双人对白

```text
1. 背景空镜／全景：建立地点
2. 双人膝上中景：建立左右关系
3. 当前说话者更实，另一人退淡：维持对白
4. 关键条件出现时切单人中近景
5. 出现选项时退到全身
6. 选择后给对方反应，再回双人中景或空镜
```

不需要每一句正反打。只有第 4、5、6 步真正改变画面。

### 7.2 朝议／权力谈判

```text
1. 殿宇大远景：制度先出现
2. 不对称双人或单人全景：明确谁掌握空间
3. 册页、差牌、诏书插入镜头：权力落到物上
4. 提出代价者的单人中近景
5. 选项时全身，主角与殿宇同时可见
6. 受位／拒位事件图：完成不可逆动作
7. 回到更空的殿内或人物中景：展示结果而非庆祝
```

### 7.3 亲密场景

```text
1. 有风、灯、纸或月色的空镜
2. 两人中景，朝向渐趋一致
3. 手、袖、凳、纸角等局部特写
4. 事件图完成接触
5. 回到中景，两人距离已经改变
6. 空镜留一拍，让亲密不被下一句立即消费
```

亲密的关键是“关系位移”，不靠裸露、夸张脸部特写或镜头贴身。

### 7.4 调查／发现／物证

```text
1. 人物视线落向画外
2. 物证插入镜头
3. 单人反应镜头，不立刻解释
4. 双人中景，物证进入两人关系
5. 若物证改变路线，再使用事件图或选项
```

### 7.5 换场／时间流逝

```text
上一场结尾物件或声音
        ↓ 形状、颜色、动作或声音匹配
下一场空镜
        ↓
人物进入或对白开始
```

例如：上一场灯芯被剪短，可接下一场天将亮的灰白窗纸；上一场纸页合上，可接下一场殿门合拢。匹配剪辑能让章节更像一条视觉叙事，而不是场景菜单。

## 八、现有事件图的标准落法示例

### 示例 A：`peizhaoye_3_woshou`

| 镜号 | 画面 | 素材 | 连续性重点 |
|---|---|---|---|
| A1 | 苑里空镜，风先动 | 场景背景 | 交代风向与两人位置 |
| A2 | 吾则添左、裴照夜右，膝上双人 | 立绘 | 保持轴线，不对称站位 |
| A3 | 裴照夜垂眼看手 | 单人／双人中景 | 视线先指向下方 |
| A4 | “这只手，给我握一会儿” | 对白原画面 | 不抢先展示结果 |
| A5 | 两人握手，裴照夜看手 | 事件图 | 动作、手别、衣袖与光向一致 |
| A6 | 回到双人中景，距离比 A2 更近 | 立绘 | 关系改变必须留在后续画面中 |
| A7 | 苑里风声或衣角空镜 | 空镜 | 给触碰留下余波 |

### 示例 B：`wuze_shouwei`／`wuze_juwei`

| 镜号 | 画面 | 素材 | 连续性重点 |
|---|---|---|---|
| B1 | 含元殿大远景 | 场景背景 | 主角先被制度空间包围 |
| B2 | 差牌／衣物／漆盘特写 | 插入镜头或背景局部 | 明确选择的物质载体 |
| B3 | 主角全身，出现选择 | 全身立绘 | 不用近景替玩家决定 |
| B4a | 穿绯、袖口沉下 | `wuze_shouwei` | 赭黄仍在盘中，服装状态正确 |
| B4b | 解下差牌、丝绦留空 | `wuze_juwei` | 手的位置与前镜动作相接 |
| B5 | 回到殿内，人物站位重新定义 | 背景 + 立绘 | 选择之后的权力关系必须可见 |

## 九、分镜表模板

以后每一场建议先填此表，再决定是否需要新图：

| 字段 | 填写内容 |
|---|---|
| 场次／分支 | 章节、场次、触发条件 |
| 镜号 | 如 `ch03-12-B04a` |
| 戏剧拍点 | 进入、试探、拒绝、递交、决定、余波等 |
| 对白范围 | 从哪一格到哪一格 |
| 资产类型／key | 背景、立绘、空镜、风物、CG、结局图 |
| 景别 | EWS、WS、MS、MCU、CU、Insert |
| 人物与左右位置 | 谁在左、谁在右、谁前谁后 |
| 视线／轴线 | 看向哪里，是否越轴，若越轴写原因 |
| 动作起止 | 动作从何处开始、在哪一镜完成 |
| 道具状态 | 谁持有、哪只手、展开或收起 |
| 服装／时间／光线 | 连续性锚点 |
| 焦点 | 横图填写 x/y 百分比 |
| UI 安全区 | 面部、手、物件是否避开遮挡 |
| 转场／声音 | 淡变、墨晕、硬切、声音桥 |
| 是否需新素材 | 是／否；若是，写“现有组合为何不能表达” |

### 一句话分镜测试

每个镜头都应能用一句话回答：

> “这一镜比上一镜多让玩家知道了什么？”

答不出来，就删掉这一镜或与上一镜合并。

## 十、新镜头素材的立项标准

### 10.1 优先复用，不优先扩张

按以下顺序解决画面需求：

1. 现有背景 + 现有立绘能否表达；
2. 改变站位、人数、景别或停顿能否表达；
3. 现有风物图或背景局部能否承担特写；
4. 现有事件图能否通过前后镜重新获得含义；
5. 以上都不行，才新增素材。

### 10.2 值得新增的四类素材

- 反复出现、会改变归属的关键物件特写；
- 现有立绘无法完成的身体动作；
- 新地点第一次建立空间所必需的背景；
- 分支结局中真正不同、不可由文字解释的最终状态。

### 10.3 不值得新增的素材

- 只为一句对白配图；
- 与现有背景仅有装饰差异；
- 只换人物表情、不改变动作；
- 只因为某一张图单独看很美；
- 无法在手机中央裁切中保留核心信息；
- 与前后镜的服装、光向、站位接不上。

## 十一、参考作品：借什么，不借什么

| 作品／方法 | 可借鉴 | 不应照搬 |
|---|---|---|
| 《十三机兵防卫圈》 | 固定透视如舞台；用分层物件、逆光和人物调度制造深度 | 现代都市高饱和光效；频繁横向走动 |
| 《Kentucky Route Zero》 | 舞台美术、慢电影、留白、场景本身承担叙事 | 过度抽象到看不清唐代物质细节 |
| 《Pentiment》 | 历史美术语言与 UI、文字、人物动作统一；视觉风格服务时代认知 | 直接模仿欧洲手抄本式扁平造型 |
| 电影连续性剪辑 | 180°轴线、视线匹配、动作匹配、声音桥 | 每句对白都做正反打 |
| 电影插入镜头 | 用手、器物、制度物件把抽象冲突落地 | 把食物和节庆拍成旅游宣传片 |
| 舞台调度 | 一屏两人、进退、前后层次、沉默者仍在场 | 所有人并排正面站立 |

这三款游戏共同说明：有限机位不是短板。只要空间、光线、人物进退和切镜时机稳定，少量资产也能形成强烈的电影感。

## 十二、交付与验收清单

### 12.1 单镜验收

- [ ] 这一镜提供了新信息；
- [ ] 主体明确，第一眼能找到；
- [ ] 面部、手和关键物件避开 UI；
- [ ] 人物比例、脚底和背景透视一致；
- [ ] 光向、色温和本场一致；
- [ ] 构图没有把女性身体当作窥视对象；
- [ ] 留白方向与视线、运动或叙事压力有关；
- [ ] 手机裁切后仍能读懂动作；
- [ ] 事件图确实完成了普通立绘不能完成的事。

### 12.2 连续镜头验收

- [ ] 人物左右位置没有无故互换；
- [ ] 视线能自然引向下一镜；
- [ ] 动作、手别、道具归属连续；
- [ ] 服装、发式、伤病、天气和时辰连续；
- [ ] 同一人物连续切换满足明显景别或动作变化；
- [ ] 高潮图前有准备、后有余波；
- [ ] 不连续空镜，不把节奏切碎；
- [ ] 声音能够跨图延续，不随每次换图重新开始。

### 12.3 最终合成验收

必须以真实游戏画面验收，至少检查桌面横屏和手机窄屏：

- 背景、人物、CG、对白框、HUD 一起出现时，信息层级是否仍清楚；
- 是否有柱子穿头、对白框切手、人物漂浮、夜景光向不一致；
- 两人同屏是否像一场关系，而不是两张立绘拼贴；
- 朱砂、金、紫等强调色是否有叙事意义；
- 单张画面的美术质量是否服务前后镜，而不是抢戏。

## 十三、建议的下一步执行顺序

1. 先选第一章一个普通对白场和一个已有事件图场，按模板做完整分镜；
2. 在真实游戏中截取每个画面状态，排成横向分镜条；
3. 先修轴线、站位、比例、光向和 UI 遮挡，不急着新增图片；
4. 通过样场确定“普通对白多久换一次画面”的节奏基线；
5. 再批量为四章标注景别、空镜、风物与事件图落点；
6. 最后从分镜表的“现有组合不能表达”项中生成真正的新素材清单。

建议第一轮样场直接使用 `peizhaoye_3_woshou` 和 `wuze_shouwei／wuze_juwei`。一个测试亲密关系，一个测试政治选择，能覆盖本项目最重要的两种演出。

## 附录：本手册与现有项目规则的对应

- `src/scene/shots.ts`：场景、色板、章节和布置，是建立镜头与光色连续性的基表；
- `src/scene/cgs.ts`：事件图人物、叙事拍点、焦点和落点，是事件镜头登记表；
- `src/ui/CharacterLayer.ts`：两人同屏、主角固定、说话者前置、换人淡入淡出，是舞台调度的执行层；
- `src/ui/CgLayer.ts`：事件图覆盖顺序、首次停留、墨晕过渡和横竖适配，是高潮镜头的执行层；
- `public/scene/`：建立空间和维持场景连续性；
- `public/cg/`：事件、风物和结局镜头；
- 最终判断标准：不是文件夹里某张图是否漂亮，而是它在前一格、后一格、对白框和手机裁切之间是否成立。
