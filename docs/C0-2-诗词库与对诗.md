## 四局对诗

本批为“限定条件选最佳对句”，不是自由作诗评优。正确项均为唐人原句；十二条干扰项均为本作原创练习句，不能署给古人，也不属于上表三十首。若题目取消所列限制，不能继续声称只有一个文学上成立的答案。

平仄用传统四声：平声为平，上、去、入为仄；不按普通话一二声机械推算。下列只就明确位置下判断，不借笼统的“意境不对”扣分。

### 第一局 · 松间月

| 字段 | 值 |
|---|---|
| 出句 | 明月松间照 |
| 出处 | 王维《山居秋暝》，上表26 |
| 难度 | 1 |
| 给玩家的题面 | 接五字句：自然物、处所、动作三层相应；末字用平声。 |
| 正确答案 | B |
| 判题重点 | 词组结构、句脚；不要求玩家背整首 |

| 选项 | 对句 | 对错 | 为什么 |
|---|---|---|---|
| A | 清泉穿石冷 | 错 | 末字“冷”为上声，未满足题面的平声句脚；不是泉水意象本身不合。 |

## 六问自答

1. 最重要的一步靠谁：本件是诗库，没有替代正文的转折。女性作者作品占主要部分，诗才来自阅读与女性之间的切磋，不来自男性暗授。
2. 女人之间的冲突，原因是价值观还是争宠：《游崇真观南楼》用于讨论资格，《啰唝曲》用于讨论谋生。不同女人可以对诗意提出异议，不以是否讨好主角定胜负。
3. 本章的“无用”场景是哪一个：尚未成章；《鸳鸯草》《题隐雾亭》《忆荔枝》提供闲处候选。最终入章须取消数值、剧情和隐藏奖励，不能把对诗小游戏冒充无用场景。
4. 换成男主角会不会一样：几首山水诗当然人人可读，但女性功名与纸笺互赠的使用语境不同。诗库不把女作者筛成只会等待男人的怨妇。
5. “她变成了她讨厌的人”的风险：主角可能用识诗高低衡量人的价值。对局失败分支必须保持对方尊严，普通宫人的手艺也不能被诗才压低。
6. 一个 2026 年的拉拉朋友会不会觉得这是写给她的：亲密包含分果、读字迹、共同发呆，也容许离别。古诗被她们重新使用，但不会篡改作者身份来制造认同。
