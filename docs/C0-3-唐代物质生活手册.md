# C0-3 · 唐代物质生活手册（写戏用，不是百科）

> 2026-09-13 由 Cowork 调研整理。给 ChatGPT（台词与旁白里的名物）和 CC3（画面里的东西）共用。
> 与 `C0-1-称谓与礼制表` 分工：那份管**怎么称呼、怎么行礼、什么程序**，这份管**看得见摸得着的东西**。
> 本世界是平行唐朝（女皇已在位、非宗室可受位），**制度可以改，物不要改**——物一改，读者就不信了。

## 零、三条使用规矩

1. **名物要能长在一句台词里。** 不写"殿内陈设庄严"，写"案上那盏双盘烛台只点了一支"。查得到的东西才写，写不进对话的就别写。
2. **每场至少两处感官锚点，且锚在具体名物上。** 现在第一章的旁白全是动作（纸、桶、笔、名册），一句气味、温度、光都没有——不是要堆形容词，是要让人相信这屋子存在。香、冷热、纸的手感、鼓声，四样里每场至少挑两样。
3. **不确定就不写。** 宁可少一个名物，不要写错一个。第十节是穿帮清单。

## 一、时间与声音（最省力的沉浸感）

- **街鼓**：日出前擂**晓鼓（顺天鼓）**、日落擂**暮鼓**，各**八百下**（一说六百），鼓声由承天门传到六街，鼓绝闭坊门。犯**宵禁**者"笞二十"。宫城里不闭坊门，但鼓声一样听得见——**这是全城通用的钟表**。
- **夜里分五更**，每更五点，打更报点。写"三更"比写"半夜"准，也更好听。
- **朝会**：元日、冬至在**含元殿**大朝；朔望（初一、十五）在**宣政殿**；日常"常参"在**紫宸殿**——**紫宸是内朝，能进这里说话本身就是身份**。这一层可以直接当政治筹码写。
- **上朝极早**，五更前就要在宫门外候着，冬天等在风口是常事。
- **假**：旬假（每十日一天）、寒食清明连假、元宵三夜不禁。"今日旬假"是个很好用的场景由头。

**怎么用**：夜谈戏写鼓声（"鼓打到第几下"是天然的计时器和催促感）；公议戏写"卯时未到，阶下的人已经站了半个时辰"；情绪转折可以正好压在一声鼓上。

## 二、建筑与空间（对应游戏八个地点 key）

大明宫按**外朝—中朝—内廷**三段：

| 地点 key | 实指 | 该有的样子 |
|---|---|---|
| `hanyuan` 含元殿 | 外朝正殿 | 建在高台上，前面是**龙尾道**（长坡道，分三层，走上去要很久），两侧**翔鸾阁、栖凤阁**双阙。**站在这里说话，声音是散的** |
| `zhaoyang` 昭阳殿 | 议事殿 | 比含元殿小、能围案说话。柱列、帷幔、地衣（毯）；公议时抬出案与**收封簿** |
| `shuge` 书阁 | 秘书省一类 | 卷架、麻纸卷、镇尺、砚、封泥与印；纸多的地方**冷**，怕火，灯要罩 |
| `yeting` 掖庭 | 掖庭宫（宫城西） | 内侍省下辖，**身份最杂的地方**：不受宠的妃嫔、罪臣家属、宫人。日常是**养蚕、采桑、洒扫、缝织**，井然有序。上官婉儿就是从这里出来的——柳承欢住这儿，是有分量的设定 |
| `nvguan` 女冠观 | 女道观 | 唐代女道观占全国道观**三分之一**，由女性独立治理；观有**田产、磨坊（磑）**，是真的经济体，不是清修布景。有客舍、访客要登记 |
| `shishe` 诗社 | 私宅或观舍 | 纸槽、晾纸的空纸、笺、案；这是"不算数的册子"该在的地方 |
| `yuanye` 苑野 | 禁苑 | 马、泥、风、换防鼓 |
| `wuzibei` 无字碑 | —— | 已有设定 |

**里坊**：全城一百多坊，**坊有墙有门**，夜里落锁。"她住在哪个坊"决定她赶不赶得到——这是免费的时间压力。

## 三、室内与器物

- **唐是坐姿转型期**：跪坐、盘腿、垂足**并行**。低案配席、**胡床（马扎）**、**绳床（可倚靠的坐具）**、**月牙凳**同时存在。写"她坐下"时选一种，选定就别换。
- **"床"在唐代是宽泛词**：置物、坐人、睡卧都叫床——**食床**（矮足小案，进食用）、**茶床**、**承物之床**。角色说"把它放床上"完全可以指一张矮案。
- **屏风**：唐代多**中轴对称式**构图，不是宋以后的写生花鸟。（CC3 注意）
- **烛台**：**双盘式**，金属或陶瓷。**不要**画枝形烛台。
- **香**：熏炉、香球（银薰球，内有常平环，滚动不倒）。宫中常用**甲煎、沉香、麝**。**香是最好用的感官锚点**——它会留在衣服上，会隔夜不散，会暴露谁来过。
- **帷幔、地衣、屏、帘**是分隔空间的全部手段；"隔着帘子说话"在这个游戏里是天然的政治场面。

## 四、纸、笔、文书（这个游戏的核心道具）

- **麻纸**是唐代公文与写经的主力（白麻纸、黄麻纸）。**硬黄纸**涂蜡、防蛀、透明，用于摹拓与重要文书。
- **染潢**：用黄檗汁染纸防虫，所以唐代文书常是**黄的**——"黄卷"不是修辞。
- **笺**：小幅彩纸，写诗写私信用。**薛涛笺**（成都、深红色小幅）是中唐女诗人自制笺的代表——温荞的诗社做纸，正好接这条。
- **双鲤**：李冶"尺素如残雪，结为双鲤鱼"——把信纸折成双鱼。本项目已定为女人写给女人的记号（D-035）。
- **印与封**：文书用印、封题；私信有**封口折数**（C-8 已写"封口有两道折"，很准）。
- **告身**是任官凭证；**鱼符/鱼袋**是身份凭证（五品以上银鱼袋，三品以上金鱼袋）。
- **砚、镇尺、笔架、水注**；毛笔是**兔毫、鸡距笔**（短锋硬毫），写小楷。

**怎么用**：这个游戏的所有权力都通过纸发生——谁署名、谁抽页、谁截信。纸的**物理属性**（黄、蜡、折数、能不能改、改了看不看得出）就是剧情本身。"硬黄纸涂了蜡，刮改会留一块亮"——这种细节比任何形容词都有力。

## 五、服饰（对应十一个角色）

**品色服**（官员常服颜色定品级）：**三品以上紫、四品五品绯（红）、六品七品绿、八品九品青**。配**幞头、圆领袍、革带、乌皮靴**。
→ **"紫"作为暗号（D-035）成立的前提就是这条**：女子服紫本是僭越。

**女子常服**：
- **襦/衫**（短上衣，衫无里）+ **裙**（高腰、齐胸），**半臂**（半袖罩衣），**帔帛**（长条披巾，绕臂垂下，可长达两米）。
- 裙名：**石榴裙**（红）、**间色裙**（多色竖条拼）、**留仙裙**。
- **鞋**：**笏头履、云头履**（翘头，可勾住裙摆）、**线鞋**（编织，轻便）。
- **妆**：**蛾眉/阔眉**、**花钿**（额上贴花）、**斜红**（太阳穴两道红痕）、**面靥**（嘴角两点）、**点唇**（小口）。
- **发髻**：**半翻髻、单刀半翻髻、高髻、双鬟望仙髻、堕马髻**。（CC3 已用单刀半翻髻给柳承欢，对）

**女着男装**（史实，非现代投射）：宫人"袍袴宫人扫御床"——穿**幞头、圆领袍、袴、蹀躞带、靿靴**，与男子同。《新唐书》记太平公主着"紫衫、玉带、皂罗折上巾"，高宗武后笑问"女子不可为武官，何为此装束"。
→ **裴照夜常年男装的史料支点就是这段**，她那句"衣裳合身，不必合谁的意"接的正是这一问。

**女冠服**：不剃发，**黄冠、道帔、簪**，衣饰讲究——史料明说"唐代的女道士不用剃头，还穿着漂亮的衣服"。她们有公开活动与社交的自由。许静和这条线立得住。

**宫人（掖庭）**：素色襦裙，无帔帛或帔帛极素；干活时挽袖、束带。柳承欢腕上那根朱绳作为**工具而非首饰**，非常准。

**幂篱 → 帷帽 → 露髻**：初唐女子出行戴**幂篱**（全身遮蔽），高宗时改**帷帽**（帽檐垂网，只到颈），开元后连帷帽也不戴了。**这条演变本身就是一段女性史，可以在戏里被人当作论据引用。**

## 六、饮食

- **主食是"饼"**（一切面食都叫饼）：**胡饼**（烤，撒芝麻，"面脆油香新出炉"）、**古楼子**（大胡饼夹一斤羊肉，椒豉、酥，入炉）、**汤饼**（面片汤/面条，索饼、馎饦）、**蒸饼**、**煎饼**。
- **肉以羊为主**。**冷修羊**（羊肉加香料煮熟去骨压平，切片冷食）。宫廷有**通花软牛肠、羊皮花丝**（见"烧尾宴"食单）。
- **鲙**（生鱼片）是风雅之食：**"鲙莫先于鲫鱼，鳊、鲂、鲷、鲈次之"**，刀法有**小晃白、大晃白、舞梨花、柳叶缕**，蘸**豉醯**。
- **蔬**：**葵（露葵）**、菠菜（波棱，贞观二十一年自泥婆罗传入）、茄子（炙食）、**槐叶冷淘**（夏日凉面）。
- **乳制品**：**甜酪、酢酪、干酪**；**酥山**（碎冰淋酥，插花草，夏日消暑，宫中显贵之物）；**玉露团**（雕酥）。
- **甜**：**蜂蜜、石蜜、砂糖、蔗浆**；**巨胜奴**（撒黑芝麻的油炸蜜面）、**透花糍**（豆馅米团，做成花形）。
- **茶**：唐是**煎茶**——**碾碎的茶饼下沸水，加盐**，陆羽《茶经》时代。**不是**冲泡散茶。
- **餐制**：一日**三餐**；**分食制向合食制过渡**——正式场合仍是**一人一案**。
  → **"一人一案"在公议戏里是画面骨架，也是权力图：谁的案在近处，谁的案被挪走。**

## 七、马与骑具（第一章直接要用）

- **内厩**属**闲厩使**管；马籍、饲料、牵行都有簿册——第一章"这马是谁的""昨日送来"完全站得住。
- **骑具**：**鞍（前后鞍桥）、鞯（鞍下垫）、障泥（挡泥，垂两侧）、辔头、衔与镳、马镫、攀胸（胸前带）、鞧带（臀后带）、杏叶（垂饰）**。
  → **杏叶多见于乘骑出行与仪仗用马**，打马毬的马基本不挂——**挂不挂杏叶，就是"这是仪仗还是干活"的视觉判据**，正好给裴照夜"我把队列撤了"那场用。
- **马鬃**常剪成**三鬃（三花马）**：三簇留长突起，岑参"平明剪出三鬃高"。**马尾常编缚**，编得很短、微上翘。
- 女子骑马是常态（骑马俑大量出土），配帷帽或不戴。

## 八、节令

- **元宵（正月十四、十五、十六三夜）**：**金吾弛禁**，全城不宵禁，"贵族戚属及下隶工贾，无不夜游"。**灯轮（七层）、灯树（高百尺）、影灯（走马灯）**，宫中**踏歌**。→ **一年里唯一一个"规矩自己让路"的夜晚**，这个游戏应该用它。
- **寒食清明**：禁火冷食，连假；**上巳（三月三）**：曲江水边宴游；**七夕**：乞巧，穿针、陈瓜果；**中秋**：赏月尚在成形；**除夕**：**驱傩**（戴面具逐疫），守岁。
- **旬假**每十日一次。

## 十、穿帮清单（唐代**没有**的东西）
