## 一、信纸顶部被切（B24 第一件）

**原因不只是 `100vh`。** `.inbox` 原来是 `display:flex; align-items:center; overflow-y:auto`：

> flex 居中的内容一旦比容器高，**多出来的一半溢出到容器上边，滚动只能往下滚，顶上那一截永远够不着。**
> 回过信之后回法收成一行「已回过」，信变短、装得下，就好了——这正是你说的那条证据。

**矮屏复现**（360×560，沈衡第二章那封信，内容高 911 像素）：

| | 信纸顶在哪 |
|---|---|
| 旧写法 | **−159 像素**（屏幕外，滚不到） |
| 新写法 | 16 像素 |

**改法**：容器从顶开始排，信纸本身 `margin:auto`——装得下时照样居中，装不下时从顶开始、整封都滚得到。截图 `b24-信纸顶部-360x560.png`：「沈衡 笺」在最上面。

**`100vh` 那一层也改了**：整个游戏的根容器 `#app` 原来是 `height: 100vh / 100dvh`。微信内置浏览器和一部分 iOS 不认 `dvh`，退回 `100vh`，而 `100vh` 比实际可见区高——**整个游戏比屏幕高一截，底部的对话框也会有一截在屏幕外**。改成 `position: fixed; inset: 0`：盒子就是可见的那一块，不靠任何视口单位。

**全库查过一遍**：

| 地方 | 情况 |
|---|---|
| 信箱 | 就是它，改了 |
| 存档面板 | **同一个坑**（flex 居中、没有滚动），改了 |
| 对诗、章末结算 | 不居中，本来能滚，靠 `#app` 那一处就好了 |
| 题记、标题 | `fixed` 贴视口，内容很少，不会溢出 |
| 题画 | `fixed` + flex 居中，**同一个坑的形状**；但题画现在没接进游戏，接的时候要一起改，记在这里 |

**这一条必须在微信内置浏览器真机上验**，我这边只能在桌面浏览器里用矮屏复现 flex 那一层，`100vh` 那一层只有真机才出现。**要 YIDI 发布后在微信里打开一封长信看一次。**

## 二、「她没写的」和引诗：手机上的入口（B24 第二、三件）

**第三层**唯一的提示是 `:hover`，手机上没有 hover，那一块就是一片什么都没有的空白。

入口只挑了一种：**一道很淡的虚线框**。只说「这里空着一块」，不说里面有什么；碰过之后框撤掉，不留痕迹。

**引诗那一层**是同一个毛病：上下两道线看得出是一栏，看不出能点。出处后面跟一个很淡的「⋯」，只说「还有」；点开过一次就撤掉。

截图 `b24-信的入口-390x844.png`：沈衡那封，引诗「尺素如残雪，结为双鲤鱼」出处后面一个淡省略号，下面那块空白一道淡虚线框。**两样都淡到不抢正文**，数在 `inbox.css` 里，CC3 看了觉得太淡或太重可以调。

### 要 CC3 知道的一件：横构图在手机上只剩中间一条

事件图是横构图，手机竖屏按铺满，**只看得到中间三分之一左右**。截图里驿路那张就只剩路和一棵柳。

**双人图风险最大**：阿荻补袖两个人要是左右排开，手机上可能只剩一个人或一只手。两条路，你挑：
1. 构图时把要紧的动作放在中间三分之一（最省事，引擎不用改）；
2. 每张图在 `cgs.ts` 里记一个焦点，引擎按焦点对齐（我这边加一个字段就行）。
