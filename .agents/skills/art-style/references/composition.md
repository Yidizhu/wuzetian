# 构图

## 硬指标

| 指标 | 要求 | 怎么查 |
|---|---|---|
| 水墨场景留白 | ≥ 40% | 把图缩到 10×10 格，数纯底色或接近底色的格子 |
| 金碧场景留白 | ≥ 30% | 同上。金碧的语义是「满」，留白刻意比水墨少 |
| UI 界面负空间 | ≥ 35% | 同上 |
| 朱砂占比 | ≤ 3% | 见 `palette.md` |
| 主体位置 | 偏离画面中心 | 中心点落在中央 1/3 方框内就算居中，退回 |

留白 40% 不是美学偏好，是主题要求。这个游戏讲一个女人拒绝被填满、拒绝被定义。一张塞满的画面在说反话。

## 三段式

沿用水墨立轴的分段习惯，从上到下：

- **天**：纯留白，或极淡的墨晕。占 30% 到 50%。这是画面里"还没发生的事"。
- **人**：主体所在。占 25% 到 40%。
- **地**：墨晕、水痕、投影。占 15% 到 25%。用 `smoothstep` 加噪声做，边缘要软、内部要不均，不要用规整的椭圆阴影。

## 主体偏置

**主体偏左下，题跋区在右上。** 这是传统立轴的常见布局，也有一个功能上的好处：右上的题跋区正好留给游戏的状态条和章节标题，不用另外挖地方。

金碧场景放宽到 30%。金碧的语义就是「满」，留白太多它就不压人了。但不能再低，低于 30% 画面会糊成一片装饰。

**留白留在她要走的方向。** 如果这一幕她在往前推进，留白在她面前；如果这一幕她在退守，留白在她身后。这条会让静止画面产生方向感，比加动效便宜得多。

## 无字碑母题

**每一幕至少出现一次"空白的、本该有字的地方"。** 形式不限：

- 一卷未展开的诏书
- 一张铺开但没写字的笺
- 一面素屏风
- 一块碑
- 对话框在她沉默时保持空白，只有一条淡墨线

这是全游戏的视觉锚点，玩家不会意识到自己在收集它，但通关时最后一幕的无字碑会因为前面铺垫过而成立。

## 立绘与背景的关系

立绘不居中，也不左右对称摆放。同屏两个角色时，两人不要等高、不要面对面正对——正对是审讯的构图。用一前一后、一坐一立、或者两人都看向同一处（这是结盟的构图）。

绝不使用影楼式对称构图和自下而上的仰角特写。构图上她必须是观看的主体，不是被观看的对象。审图时问：这个机位有没有在窥视她。
