# 吾则天 · 视觉规范

> **E11（D-095、D-096、D-103）起：立绘与背景是 AI 生成的光栅图，国漫厚涂半写实。** 下面的门槛、提示词、命名都是新管线的。
> 旧的 SVG 剪影与 3D 舞台规矩在 `references/legacy-svg.md`，fallback 期间仍适用。

## 一条总原则

**留白就是她的权力。无字碑是这个游戏的视觉母题。**

中国画里最有力量的是没画的部分。这个游戏讲的是一个女人拒绝被定义，所以画面里"空着的地方"必须比"画满的地方"更有分量。任何时候你想往画面里加东西，先问：拿掉它会不会更强。

这条不是修辞。它对应两个可检查的硬指标：留白面积和朱砂占比。见 `references/composition.md`。

## 验收生成图的七道门槛（E11）

**顺序就是优先级：前一道不过，后面不用看，直接退回重生成。** 每一道都要能「看图一眼」判定——
下面写的都是图上指得出来的东西，「感觉不太对」不算理由，也不算过。

生图模型有自己的默认：它默认给你和服、清宫戏、仙侠、现代汉服商品照，或者一张今天的网红脸。
这七道门槛卡的就是这些默认，所以每一条都写成了**这张图最可能错成什么样**。

先跑机器（`npm run art:post -- portrait <套>`）：背景不纯、出画、要放大才够尺寸，这三样机器会报，报了就不用人看。

### 1　剪影：缩到 120px 高，像不像唐代、认不认得出是谁（D-103，放在第一）

`npm run art:post -- silhouette <新图> <同一批已验收的图…>`，看上排那一行实际 120px 的。**剪影不过，细节画得再好也打回。**

立绘逐项指：
- **头**：指得出是哪一种髻或冠。两个圆球、一个圆柱发包、两只实心犄角、一团看不出形的黑 → 退
- **腰在哪**：襦裙的人，裙子从胸下就往外放，上身短；外轮廓在自然腰收一道 → 退。
  **胸下那条腰带在纯黑剪影里是看不见的**（它是内线）——看的是裙子从哪儿开始放
- **帔帛**：两条细带离开身体垂下来。肩上挂成一个三角形的斗篷、把手臂盖没了 → 退（v2 就是这样）
- **手臂**：至少一侧手臂和身体之间透出空隙。两臂贴死在身上、整个人是一根柱子 → 退
- **随身物**：在 120px 里看得见，伸出了身体轮廓。看不见 → 退（它是十一人识别的一部分，C0-3 第九节）
- **脚**：裙摆下露出翘起的鞋头，或靴
- **认得出是谁**：和同一批已验收的人排在一起，指得出是她。和她最像的那个人（柳承欢对主角、唐简对沈衡），剪影上至少差一样：头、下摆、道具

背景：缩到 120px 高眯眼看，只剩三四块明暗；指得出是殿、阁、观还是野外；**画面中央下半是一块完整、安静的地面**（人要站进去）。

### 1a　环里透光（E14，只管有空心髻、空心冠的人；现在是主角的双鬟望仙髻）

**连三版没过的一条，单列一道，不和别的混在一起判。** 主角 v2、v3、v4 都画成实心——圆柱发包、犄角、犄角。

- **机器量**：`npm run art:post -- portrait wuze_default --eye <眼>` 会报「头顶透光」——眼睛那一行以上被挖成透明的孔，各多宽多高。
  **过：两个孔，每个宽 ≥ 28、高 ≥ 50 像素**（原件尺寸）。
  实测：v2 一道 19×40 的缝，v3 两道 16×46、18×45，v4 两道 20×45、20×46——**全是缝，不是孔**，和人眼判的「实心」对得上；
  v5 两个 33×60、32×61，120px 剪影里两个孔清清楚楚。
  **这条线校过一次（E15）**：E14 按推算定的是 45×60，手上只有缝、没有一个真孔可以对；v5 是第一个真孔，按原来的线它不过，但剪影里明明看得见。
  线改划在缝（≤20 宽）和孔（≥32 宽）中间。改线是在看过 v5 之后，Cowork 可以否决，否决就退回 45×60、v5 不过
- **人看**：`art:post -- silhouette` 上排 120px 那一格，头顶指得出两个洞；检查图品红底那一格，两个环里是品红
- 机器说过、人看不出 → 退（孔被发丝切碎了）；人看得出、机器说不过 → 看检查图，多半是孔里有发丝把它连到了头发上，照实记，交 Cowork 判
- 账本里单独一张小表记这一勾（`docs/art-gen-ledger.md`「环里透光」）

### 2　形制：是唐代，不是「中国古装」

- **领**：交领要右衽——从观者这边看，外层领口从画面右上斜到左下，像字母 **y**。反过来（左衽）→ 退。圆领袍的扣在穿着者右肩
- **袖**：窄袖贴臂，袖口不宽于手腕两倍。中等宽度的垂袖（宋明）、方形筒袖 → 退。大袖只给礼衣
- **腰**：襦裙是胸下高腰（第 1 道的外轮廓之外，这里看腰带的位置）；圆领袍是自然腰的革带。宽板腰封 → 退
- **带**：胸下小结、短垂带。蝴蝶结加两条长垂带（现代汉服商品照）→ 退
- **鞋**：翘头履（宽而圆钝的高头）或乌皮靴。现代布鞋、尖头弯钩鞋 → 退
- **别的朝代**：立领竖领、马面裙（明）；马蹄袖、旗头、花盆底（清）；腰后大结、木屐（和服）→ 退

背景：斗栱硕大简洁、柱是铅丹不是大红漆、直棂窗、低案与席。椅子、高桌、太师椅、成串红灯笼、盘龙金柱、障子门、榻榻米、玻璃、电灯 → 退。

### 3　脸：挡住默认脸，放开每个人的脸（E18 改写，D-135、D-136）

> **E12–E17 这一道写的是「必须面型偏圆、眼细长、眉粗平、嘴小」七项——肯定式。它生产了模板**：
> 第一批五张里阿荻、唐简、许静和三张几乎一张脸；已上线的主角和沈衡遮住头发看，是全套里最像的一对。
> 同一份文件里第 1 道（120px 剪影认得出谁）是结果式的，它成功了。**不是用不用心的差别，是判据的形式决定的**（R-030）。
> 所以这一道拆成两半：**否定式挡住模型的默认脸，结果式判十一个人是不是十一张脸。** 长相这件事不再用肯定式。

**① 否定式（硬，看到任何一条就退）**，在原件上放大到原尺寸看脸：

- 尖下巴、V 脸：下巴收成一个尖点，腮边一道折角
- 欧式脸：深眼窝、高鼻梁（从眉心到鼻尖一道亮线加两侧阴影）、窄高的鼻翼
- 现代妆：**眼线描黑、眼尾挑出黑线**、卧蚕高光、鼻影、修容、美瞳、亮面唇釉、细挑的弯眉（写了花钿、斜红的人除外）
- 网红脸的组合：尖下巴 + 双眼皮大眼 + 小窄鼻，三样同时出现
- 像某一个真人明星（D-137）：一眼认得出「这是谁」的脸 → 退；**提示词里也不许写任何真人姓名**
- 同一个人的另一套装束（主角·绯、李令仪·紫）：和定妆图并排，发际线、眉形、脸型对不上 → 退（两张脸就是两个人）
- 手：多指、少指、手指融在一起 → 退

**② 结果式（只能看，不可数）：十一张脸认得出谁是谁**

`npm run art:post -- faces <原件>:<脸中心x>,<脸中心y>,<发际到下巴的高>…` 把几张脸缩到同样大小并排，**椭圆遮掉头发、冠帽和衣领**，只剩脸。
- **过**：遮着名字，指得出每一张是谁。靠的是 `character.md`「脸的差别」那张表写的东西——脸的长短方圆、眼的开合、眉的浓淡曲直、嘴的大小、肤色、常态表情
- **退**：有两张分不开（遮住名字认错、或者要靠肤色深浅才分得开）。退的是**后来的那一张**，已上线的不因为后来的人像它而退
- 新的一张要和**已验收的全部**并排比，不只和同一批比

**唐代审美的参考区间（说明，不是门槛）**：唐代壁画和女俑的脸大多面庞丰润、下颌圆、眉宽、嘴小——这是区间，不是模子。
一个人可以长脸、方脸、眼睛圆、嘴宽，只要不落进上面 ① 的任何一条；她具体长什么样，看 `character.md` 那一行。

### 4　颜色与画法：厚涂的矿物色，落在她的品色上

- **画法**：缩到拇指大还看得出衣褶的明暗块面。淡彩、水彩、照片感、三维渲染感 → 退（v1 是淡彩）。
  满身同一种方向的短笔触、读成布上的花纹 → 退（v2 就是这样）
- **主色**：缩到拇指大，这个人读成什么颜色？和 `character.md` 品色表那一格说得是同一个名字吗（青、深绿、胭脂绯……）。
  天蓝读成「青」不算；温荞和裴照夜并排都读成「红」→ 退（D-093）
- **朱砂**：全身只有一处正红，在她的身份锚上。第二处正红（唇、花钿、腰带、鞋）→ 退。
  铅丹（偏橙）、胭脂（偏紫红）不算朱砂，但它们也不许是正红
- **紫**：只在宋蕙贞的簪头（比她的朱砂小）和李令仪的礼衣上。别人身上有紫 → 退（D-035、D-092）
- 背景：柱子比将来站在前面的人亮 → 退（E10 第 1 条）

### 5　身材：画出了差别，站在同一把尺子上（D-095 第 3 条）

- `npm run art:post -- lineup`：已出的全身立绘脚底对齐排一排。高矮顺序和 `src/char/portraits.ts` 的身高一致吗？裴照夜最高最宽肩、阿荻最矮最瘦、何太后下摆最厚——**排出来十一个人一样的身板 → 退**
- 体格是提示词里的必填项。生成图里「偏瘦肩窄」「结实骨架大」「微胖肩圆」要一眼看得出，不能都是同一个模特身材
- 背景：柱高、门高、案高按一个 1.6 米的人比，合不合理

### 6　她是看的人，不是被看的（精神指南第 4 节）

**把她换成一个男主角，这个姿势、这个机位还会这样画吗？** 不会 → 退。
- 退：露肩、露胸、衣料贴出身体曲线、湿身透；S 形扭腰、回眸、撩发、咬唇、手指点唇；仰拍或俯拍；影楼式对称的「精致美女照」
- 要：平视、站得稳、手里在拿她自己的东西

### 7　杂质：画面里不该有的东西

- **任何文字**：匾额、屏风、纸上、衣服上的字（生成的汉字几乎一定是乱码；空白本身是无字碑母题）→ 退
- 签名、水印、印章、边框 → 退
- 发光、粒子、光晕、飘带悬空、飘落花瓣 → 退（仙侠）
- 立绘：背景有地面、有投影、有渐变或暗角 → 退（抠不干净；机器会报「背景不是纯色」）
- 立绘，浅色衣服（月白、缃、灰青、本色麻）：墨底那一格**衣服边被啃出锯齿**、品红底那一格**衣服上有洞**（不是臂弯、帔帛和身体之间）→ 退。
  E18 许静和 v1 在中灰底上就是这么坏的，浅色衣服改绿幕底（`portraits.ts` 的 `bg`）。
- **底色规格（D-149，写死）**：白底默认；暖的中间调（本色麻）中灰底；浅色、灰色系**且身上没有绿**的用绿幕；
  **穿绿的人（沈衡、唐简，将来任何主色落在绿里的）一律不许绿底**——绿幕抠绿衣会把人抠没。
  `art:post` 管这条，而且是报错不是警告：`portraits.ts` 写错了任何命令都不跑；原件底色和主色相近，那一张不出图。
  **它只查主色**：衣服暗面落到底色上（许静和 v1 那种）主色查不出来，墨底那一格照看
  `art:post` 报的「险边」只作诊断参考：E17 定过 3% 报警线，E18 两张真样本（阿荻 22% 干净、许静和 12.8% 坏）证明它分不开好坏，已降级（D-129）
- 背景：画面里有人 → 退

### 两条硬否决：看到就重生成，不走上面七道

- **脸糊了。** 远景小人、五官糊成一团、头（颅顶到下巴，不算发髻冠帽）不到画面高度八分之一（`art:post` 检查图第一格那几道线，一格就是八分之一），
  或者放大到原尺寸分不清两只眼睛、鼻子和嘴 → 重生成。**不修，不放大**——AI 画全身人像的头号失败，修出来也还是糊的
- **裴照夜被画成男人，或者被「帅气化」。** 她穿男装，不是男的。
  有喉结、胡茬、方下颌、男性的平胸窄臀骨架、短发 → 重生成；
  仰拍、披风、铠甲、握刀或拔刀摆姿势、冷酷俯视、嘴角邪笑、风吹衣摆（偶像剧「帅气女将」）→ 重生成

### 过了之后

1. `docs/art-gen-ledger.md` 记一行：哪一版、七道各过没过、谁看的
2. 过了的那张原件**不改、不覆盖**，后处理（`art:post`）出引擎用的全身与膝上两种裁切
3. 再用 `art-director` 打分。**合规是门槛，不是成绩**

## 一次过（D-200，YIDI 定）——D-186 之后新出的图都按这一节，优先于下面各节的「退」

**生图只出一版，不退、不重出。** 下面「验收事件图」「验收结局图」「验收风物图」各节列的门槛，从这一条起**用在写提示词上，不用在退图上**。

- **写提示词**：把门槛一次写全——装束（这一场她是谁）、手（逐只写在哪）、光向、无字、安全区（脸和手在中间七成、最下面四分之一以上）、同框的脸怎么分开、这一张最可能画错的那件东西写成否定式禁止。出图前的功夫花在提示词上。
- **Codex**：每张只出一版。
- **验收只做两件**：
  1. **硬伤**（C0-3 第十节穿帮清单里最重的三类）：**画面里出了不该有的人**（风物图、无字之碑）、**可读的字**、**现代物件**。有硬伤才退。印文那种篆书样的曲折笔画不算可读的字（D-201）。
  2. **裁切上线**：`art:post -- cg <key>`／`scene <key>`，横图记 `focus`，提交（D-157）。
- **其余一律记账不退**：装束细节、幞头缠法、手出安全区、配角脸出边、地面反光、边角的线装书或高桌……写进 `docs/art-gen-ledger.md`，不重出。
- **已经在路上的退图不再追**：挡风（`peizhaoye_2_dangfeng`）v1 的软裹巾 YIDI 认了，D-077 硬脚幞头那条对这一张不追，v1 上线，v3 提示词作废（D-200）。

下面各节保留，是写提示词时的检查单；其中「→ 退」「→ 重生成」的字样，D-200 之后只对上面三类硬伤生效。

## 验收事件图（CG，E19，D-142～D-146）

事件图是一件正在发生的事：**默认竖构图 1024×1536，只有主体本身是宽的才横**（D-150）、有地方、有人在做事、不看镜头。立绘的七道门槛里，**第 2（形制）、3①（脸的否定式）、4（颜色）、6（被看）、7（杂质）照用**；
第 1 道（120px 剪影）和第 5 道（同尺排队）是给正面站姿的，事件图不用。另外加下面几条。

### 事件图的硬否决（看到就重生成，不走别的门槛）

- **脸不是她的脸**（单人、双人都适用）。把 CG 里的每一张脸和她已验收的定妆图一起放进 `npm run art:post -- faces <CG>:<cx>,<cy>,<h> <定妆图>:<cx>,<cy>,<h> …`，
  遮住头发衣服并排：**遮着名字，CG 里的每一张脸配得上她自己的定妆图**。配不上、配错人 → 重生成。
- **双人：两张脸必须还是她们各自的脸**（E19）。除了上一条逐张配得上，**两张脸之间也要分得开**——生图模型画两个人最常见的坏法，是把两个人画成同一张脸、或者把一个人的五官挪到另一个人脸上。
  两张脸配反了、两张脸像同一个人、其中一张变成了模型的默认脸 → 重生成。
- **手的数量和位置要对**（双人尤其）。提示词里逐只写了手在哪；验收时**逐只数**：
  每一只看得见的手指得出是谁的、连着哪条手臂、在做提示词写的那件事；
  **多一只、少一只（没有被身体或衣服挡住却不见了）、一只手连在两个人身上、六指或手指融在一起、手和手臂接反** → 重生成。不修，修出来的手还是错的。
- **性内容**（D-143）：亲密只到身体的靠近与触碰——手、肩、发、并肩、依偎、额头相抵、同盖一件衣服。衣衫不整、性暗示的姿势 → 重生成。

### 事件图的其余几条

- **手机上看得见事**：`npm run art:post -- cg <key>` 的检查图画出手机竖屏铺满时看得见的那一条（品红框）和底部对话框暗条。
  竖图框是中间 69%；**横图框按 `src/scene/cgs.ts` 的 `focus` 画**——横图先量焦点、填表，再跑一次看框（没填 `check:art` 会拦）。
  **所有人的脸和所有看得见的手都在框里、不压在暗条下**；脸出了框 → 退；手擦着框边、事还看得出 → 记下，不退（E22 抄纸右手）。
- **远景的朝代**：宫殿屋顶是灰瓦、鸱尾。黄琉璃瓦、红墙黄瓦的故宫样子是明清 → 远景小、缩到手机看不出的记下不退（E22 驯马、握手），占画面显眼处的退。
- **装束跟身份，不跟参考图（E24，D-164）**：
  - **写提示词时**：每张 CG 提示词里，主角（和任何这一场身份与定妆图不同的人）单独一行「装束」，先写「这一场她是谁」，再写穿什么。参考图只管脸和身材。
  - **身份表**在 `references/character.md`「主角的装束跟身份」：才人青、受位绯、离宫布衣、才人·行装、满殿无声赭黄。绯的意思是「坐上那一席，没把天子穿到身上」，登基线的图都按这个画。
  - **验收时**：先对剧本这一场她是谁，再看衣服。出了宫还穿青、受位后穿赭黄（满殿无声除外）、行路穿曳地长裙 → 退。E23 五张结局图写成「主角的青」就是这个错，错在提示词，所以先查提示词那一行。
- **只改一行的重出，附上一版当构图参考（E31，D-193）**——**但错处本身是一件看得见的形时不附**（E32 挡风 v2 的教训）：
  附上一版锁住的是整张画，模型会把画对的构图和画错的那一件一起抄过去。错在形上（头上戴的、领子、手里拿的东西）→ 不附上一版，改附一张**那一件画对了的已上线图**，写明「只照这一件」；错在文字能说清、模型不会照抄的地方（比如画错的是颜色深浅、少了一件小物）→ 附上一版。
  关山有信 v3 附 v2 改领子成功了，挡风 v2 附 v1 改幞头没成——领子在 v2 里占面积小、提示词写得死；幞头是裴照夜的剪影中心，模型照图抄。
- **结果式：说得出这张图里谁在对谁做什么。** 缩到手机大小、不读剧本，说得出「她在给她补袖口」「她在安抚一匹马」。说不出，或者说成了别的事（伺候、打架、摆拍）→ 退。
- **视线**：人不看镜头。有人正对镜头 → 退。
- **主仆和高低**：两个人的相处不许画成一个伺候另一个、一个俯视另一个（除非剧本那一刻就是这样，并在提示词里写明）。

## 验收结局图（E23，D-159／D-160）

结局图是事件图的一种，上面「验收事件图」的硬否决和其余几条全部照用，另外加四条。提示词在 `references/ai-prompt.md` 第十二节。

- **一个字都没有**（硬否决）。纸、碑、招牌、衣服上出现字、假汉字、像字的笔画、印章 → 重生成。登基三张的正文分天／曌／不改，图只有一张，有字就错了三分之二的玩家。
- **「无字之碑」一点红都不许有、纸心要平**（硬否决）。印由引擎叠；纸心有褶、有影子、压着东西，印就叠不上 → 重生成。
  过了之后量纸面坐标（纸的外框、纸心那块平整空白的外框，原件像素），写进汇报给 CC1——和碑面坐标同一个做法。
- **结果式：八张并排、遮着标题，对得上八个结局名。** 八张全到齐之后缩到手机大小并排看；有两张对不上、互相换了也说得通 → 重出更不像的那一张。
  最容易撞的三对：满殿无声／未竟之诏（都是天子对着案）、未竟之诏／纸上有名（都是一个人对着纸）、不受／纸上有名（都是一个人松下来）——提示词里各自拉开了光、地方、手上的动作，验收就看这三处拉没拉开。
- **冷不冷看光和姿态**：满殿无声的颜色是满的（gold），冷在平光、齐整和空座上；它被画成暗、灰、没颜色 → 退。其余七张被画得悲情（流泪、仰天、回望） → 退。

## 验收风物图（E28，D-180）

风物图画一样东西、不画人，走事件图那一层（beat「风物」）。提示词在 `references/ai-prompt.md` 第十六节。事件图的「手机上看得见事」「无字」照用，脸和手那几条不用；另外三条：

- **画面里有人就退**（硬否决）：脸、手、人影、剪影都算。
- **穿帮清单过一遍**（硬否决）：`docs/C0-3-唐代物质生活手册.md` 第十节——椅子、散茶盖碗、辣椒番茄玉米、炒菜、线装书、枝形烛台、青花、玻璃器。节令的另外几条红线见 `docs/唐代民俗文化调研-节庆娱乐与饮食.md` 3.x「不宜写」与 5.3：月饼、汤圆、兔儿爷、寒食冷盘宴。
- **结果式：遮住 key，说得出这是哪个节令／哪一种吃的，是谁的**。上元的灯说不出是宫里的、冷灶说不出是寒食没火、酥山看成冰淇淋 → 退。

## 文件与命名

```
assets/portraits/<who>_<身份>_<色>_<表情>_v<N>.png   生成原件，一版一个文件，不覆盖（例：wuze_cairen_qing_default_v2.png）
assets/scenes/<场景>_<状态>_v<N>.png                背景原件（例：zhaoyang_gold_v1.png）
public/char/full/<引擎名>.webp                      全身，透明底，1024×1536，同一把尺子（例：wuze_default.webp）
public/char/knee/<引擎名>.webp                      膝上裁切，1024×1080，同一张图裁出来，不另生成
public/scene/<场景>_<状态>.webp                      背景，长边 ≤ 1920
assets/cg/<人>_<第几张>_<事>_v<N>.png               事件图原件（E19，例：adi_1_buxiu_v1.png）
assets/cg/ending_<结局 key>_v<N>.png                结局图原件（E23，key 同 endings.json，例：ending_wuzibei_v1.png）
public/cg/<人>_<第几张>_<事>.webp                    事件图，默认竖 1024×1536（D-150）；横的要在 src/scene/cgs.ts 填 focus
public/cg/ending_<结局 key>.webp                      结局图，八张全竖
```

每一套的原件名、引擎名、身高、底色都在 `src/char/portraits.ts`，别处不抄（D-098）。目录、后处理、裁切的理由见 `references/raster-pipeline.md`。
