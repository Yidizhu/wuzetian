# 双色板

> **E11**：光栅图的颜色纪律（品色服、朱砂排他、铅丹柱）见 `character.md`「品色服（E11 定稿）」与 `SKILL.md` 第 4 道门槛。下面的 CSS 变量仍管 UI、旧 SVG 与 3D 舞台。


> **E9 提案（D-082，待 Cowork 审过对照图再生效）**：色板换成唐代矿物重彩，见文末「唐代矿物重彩」。
> 审过之前下面这套仍是正式色板；新的一套已写进 `palette.css`，挂在 `data-palette-set="tang"` 上，默认不启用。

这个游戏有两套色板，**任何一屏只属于其中一套，不混**。

这不是装饰性的变化，是叙事本身。唐代绘画的主流是金碧青绿（石青、石绿、泥金，李思训一路），水墨在唐代还是另类，五代以后才成为主流。所以「金碧」就是当时的既定秩序，「水墨」就是她带进来的那个尚未被承认的东西。

| 色板 | 底 | 用在哪 | 含义 |
|---|---|---|---|
| **水墨**（宣纸） | 纸 `#EDE7DA` | 她的私人世界、女人之间的场景、诗、夜、无字碑 | 她的方式：留白、判断、关系 |
| **金碧**（绢） | 绢 `#E6D9B9` | 朝会、典礼、册封、公开的权力场合、朝廷视角 | 旧秩序：满、亮、被规定好的 |

两板合计 12 个值，另有两个**受限值**（`--c-ink-wash` 与 `--c-purple`，见下面两节），合计 14 个。
色板外颜色为零，可以 grep 查。

## 水墨板

墨五色是传统水墨的浓淡分级，朱砂是唯一暖色，纸色是承载它们的底。

| 名 | Hex | CSS 变量 | 语义 | 典型用途 |
|---|---|---|---|---|
| 焦墨 | `#1A1815` | `--c-line` | 决断、不可逆 | 最强的轮廓线、标题、无字碑、关键选项边框 |
| 浓墨 | `#33302B` | `--c-ink-1` | 主体、在场 | 正文文字、角色主轮廓、近景 |
| 重墨 | `#55524A` | `--c-ink-2` | 次要、中景 | 配角、中景建筑、次级文字 |
| 淡墨 | `#8C8880` | `--c-ink-3` | 退后、已成过去 | 远景、已读文本、未选中项、旁白 |
| 清墨 | `#C9C4B8` | `--c-ink-4` | 边界、将消未消 | 分隔线、禁用态、雾、最远的山 |
| 朱砂 | `#A8232A` | `--c-accent` | **她的欲望与决断** | 见下方专节 |
| 纸 | `#EDE7DA` | `--c-ground` | 底 | 页面底色、对话框底、宣纸纹理基色 |
| 纸（夜） | `#D8D2C4` | `--c-ground-night` | 夜景的底 | 御花园夜等夜场 |

朱砂是干了的印泥，不是鲜红。选这个偏深偏沉的值，是因为它要能和墨共处而不跳出来喊。

## 金碧板

| 名 | Hex | CSS 变量 | 语义 | 典型用途 |
|---|---|---|---|---|
| 焦墨（线） | `#1A1815` | `--c-line` | 同水墨板，两板共用线色 | 一切轮廓与文字 |
| 石青 | `#2F5C8F` | `--c-ink-1` | 官位、品秩、冷 | 朝服、殿柱、远山 |
| 石绿 | `#5B8C6A` | `--c-ink-2` | 山水、仪仗、装饰 | 屏风、帷幔、瓦当 |
| 赭石 | `#8B4A2F` | `--c-ink-3` | 土木、梁柱、旧 | 建筑结构、地面 |
| 泥金 | `#B8964F` | `--c-ink-4` | 权威、典礼、被规定 | 器物、纹样、匾额、诏书轴头 |
| 绢 | `#E6D9B9` | `--c-ground` | 底 | 页面底色、对话框底、绢纹基色 |

注意变量名两板共用。切换色板时不换变量名，只换 `data-palette` 属性上挂的那组值。这样所有组件代码不需要知道自己在哪套色板里。

**金碧板里没有 `--c-accent`，也没有 `--c-purple`。** 见下面第一条硬规则。

实现上有一个坑，值得单写一行：CSS 里 `:root` 和 `[data-palette="gold"]` 特指度相同，
**金碧板必须把这两个变量显式写成 `initial`，不能只是「不声明」**。不声明的话它们会从 `:root`
那条规则继续生效，于是金碧场景里 `--c-accent` 仍然是朱砂，所有 `var(--c-accent, var(--c-ink-4))`
的回退永远轮不到——硬规则 1 就被静静地破了，而且屏幕上看不出来（立绘上那一点红本来就小）。
`initial` 让自定义属性取「保证无效」值，`var()` 才会落到回退。

## 五条硬规则

1. **朱砂只属于水墨板。金碧板里没有红。** 所以朝廷的画面里一旦出现一点朱砂，意思就是「她在这里做了一个自己的决定」。这是全游戏最省力的一个叙事装置，用一个像素说清一件事。
2. **任何一屏只属于一个色板，不混。** 切换用墨晕转场。
3. **水墨侵入朝廷的进度就是她的权力进度。** 第一幕的朝廷场景全金碧；第二幕的朝廷场景里出现一个水墨元素（她带进来的屏风、她写的字）；第三幕的朝廷场景以水墨为主、金碧只剩残余；登基那一场是金碧被墨晕整片盖掉的转场；无字碑结局纯水墨加一枚朱砂印。
4. **如果结局是「她变成了她推翻的那个人」（势高心低），画面回到金碧。** 这是视觉上的判词，不需要旁白说一个字。
5. **色板外颜色为零。** 两板合计 12 个值加两个受限值，代码里禁止出现字面量颜色，一条 grep 就能查。

暗色模式不做反色。宣纸和绢都不会变黑。夜景靠把主体推到焦墨、把底色换成 `--c-ground-night` 来实现，色板本身不变。

## 朱砂的用法

朱砂代表主角的欲望和决断，对应精神指南 2.3 节 Audre Lorde 那条「她的欲望本身就是政治的」。它不能当装饰用，一旦滥用就什么都不代表了。

**允许出现朱砂的场合，只有这些：**

- 玩家主动做出的不可逆选择（选项被点中的一瞬间，左侧亮起一个朱砂点）
- 印章与落款（结局卡片的题跋、诗词图鉴的收藏印）
- 每个角色身上的一处「朱砂点」，是她的身份锚（见 `character.md`）
- 好感度升到「盟」的那一帧
- 无字碑结局：碑面全空，只有一枚朱砂印
- **金碧场景里的朱砂，必须对应她的一个具体决定。** 说不出是哪个决定就删掉

**硬指标：任何一屏，朱砂像素占比不超过 3%。**

## 一点紫（D-035）

**紫是结契者之间认人的暗号，不是一个装饰色。**

来历见指挥日志 D-035：唐制三品以上才许服紫，女子服紫本是僭越，太平公主偏穿。本世界里
「一点紫」长在结契者的衣缘或簪头上，官府不认，她们自己认。角色圣经写明：不是每个结契者
都佩戴，没佩戴也不能据此判断关系。

| 名 | Hex | CSS 变量 | 出现在哪 |
|---|---|---|---|
| 紫 | `#6A4470` | `--c-purple` | 结契者的衣缘或簪头，二选一 |

**四条规矩，比朱砂更严：**

1. **只在水墨板。** 金碧板里 `--c-purple` 置为 `initial`，和朱砂一样回退到泥金——
   朝廷不认这个记号，所以在朝廷的画面里它就不存在。这条与「金碧场景里朱砂点转泥金」是同一条规则。
2. **只在结契者身上。** 主角在结契之前不许出现紫。谁是结契者以角色圣经为准（本轮只有宋蕙贞）。
3. **面积上限是朱砂的一半：任何一屏 ≤ 0.5%，且必须小于同屏那个角色的朱砂点。**
   朱砂是她的决断，要被看见；紫是暗号，认得的人才看得见。紫比朱砂大就本末倒置了。
4. **一个角色身上，紫和朱砂不在同一处。** 朱砂点的位置已在 `character.md` 冻结，紫另选一处。

选位置时想一想：这一点紫是给谁看的。它不是给玩家看的，是给另一个女人看的。

## 人的墨色（`--c-char-*`）

立绘身上的颜色走 `--c-char-line`、`--c-char-1` 到 `--c-char-4`，值就是墨五色，
**两块色板下都不重新声明**。理由和 `--c-ink-wash` 是同一个：有些东西不该跟着色板走。

金碧只属于场景与器物，人永远走墨色。绑 `--c-ink-*` 的那一版，主角进了昭阳殿整个人变成石青，
和殿柱同色同位，剪影糊掉——手机实机才看出来。规矩与推论见 `character.md`「人不随色板变」。

## 水墨侵入用的墨（`--c-ink-wash`）

`--c-ink-wash: #33302B` 就是水墨板的浓墨，**两块色板都不重新声明它**。

它存在的唯一理由是 D-010 第 3 条：金碧场景里她带进来的那一件东西（屏风、她写的字、案上一方砚），
以及盖在整屏上的那层墨，都必须是墨色。直接用 `--c-ink-1` 会在金碧板里变成石青——
那就成了「朝廷自己的一块蓝」，不是「她带进来的墨」，意思正好反了。

所以它不是第 13 个颜色，是浓墨在金碧屏幕上的专用引用。

## CSS 变量声明

两组值挂在 `data-palette` 上，组件只认变量名。

```css
:root,
[data-palette="ink"] {
  --c-line:   #1A1815;
  --c-ink-1:  #33302B;
  --c-ink-2:  #55524A;
  --c-ink-3:  #8C8880;
  --c-ink-4:  #C9C4B8;
  --c-accent: #A8232A;
  --c-ground: #EDE7DA;
  --c-ground-night: #D8D2C4;
  --c-ink-wash: #33302B;   /* 两板共用，见「水墨侵入用的墨」 */
  --c-purple: #6A4470;     /* 受限色，见「一点紫」 */
}

[data-palette="gold"] {
  --c-line:   #1A1815;
  --c-ink-1:  #2F5C8F;
  --c-ink-2:  #5B8C6A;
  --c-ink-3:  #8B4A2F;
  --c-ink-4:  #B8964F;
  --c-ground: #E6D9B9;
  /* 必须显式写 initial，不能只是不声明，见上面「金碧板」一节的那个坑 */
  --c-accent: initial;
  --c-purple: initial;
}
```

切色板就是在根元素上改一个属性：`root.dataset.palette = scene.palette`。场景 JSON 里的 `palette` 字段（值为 `"ink"` 或 `"gold"`）是唯一来源，`SceneRenderer` 和 UI 都读它。

代码里禁止出现字面量颜色。任何 `#` 开头的颜色都必须是上面 12 个之一，且通过变量引用。

## Three.js 里怎么用

`MeshToonMaterial` 的 `gradientMap` 用一张 1×5 的像素图，**每套色板一张**：

- 水墨板：清墨、淡墨、重墨、浓墨、焦墨，从左到右
- 金碧板：泥金、石绿、石青、赭石、焦墨，从左到右（由亮到暗，泥金是受光面）

要点：`minFilter` 和 `magFilter` 必须设成 `NearestFilter`，否则五级色阶会被插值成渐变，平涂效果就没了。`gradientMap` 是非颜色数据，纹理的 `colorSpace` 保持默认的 `NoColorSpace`。

轮廓线两板都用焦墨。全屏最后叠一层纸纹，`multiply` 混合，不透明度 0.25 到 0.35：水墨板叠宣纸纹，金碧板叠绢纹（更细、更规整、略带经纬），让两套画面连质感都不一样。

## 唐代矿物重彩（E9 提案，D-082）

**为什么换**：敦煌与乾陵壁画是矿物重彩，线描勾勒 + 色彩填充。水墨是宋以后文人画的审美。
**墨线一层不扔**——它本来就是这套做法的一半。

**两块板的名字不改**（数据里 `palette: ink / gold` 一个字不动），换的是板里装的颜料：

| 板 | 旧 | 新 | 用在哪 |
|---|---|---|---|
| `ink` | 水墨 | **素彩**：纸底、墨线、淡设色 | 她的地方 |
| `gold` | 金碧 | **重彩**：绢底、石青石绿泥金满铺、殿柱铅丹 | 朝廷的地方 |

### 纪律：换颜料，不换规矩（D-082）

1. **色板外颜色仍然为零。** 色板变长了，闸门不放宽。
2. **留白照旧**：素彩 ≥ 40%、重彩 ≥ 30%。敦煌壁画也留大量壁面。
3. **朱砂的排他性不放宽。** 画面上的红分三种，色相拉开：铅丹偏橙、胭脂偏紫红、朱砂居中正红。
   机器数朱砂时按色相窄窗数，**铅丹与胭脂不算朱砂**；朱砂占比上限可以从 3% 放宽，但一屏里除了她拿主意那一下、印、身份锚，不许有第二处朱砂。
4. **紫仍然小于朱砂**，仍然只在结契者身上。
5. **人的颜色两块板下是同一种**（E4「人不随色板变」照旧成立）。人的主色从唐代品色服取，见 `character.md`。

### 三幕弧线的等价物（提案，还没做）

原来是水墨一层层盖过金碧。重彩之后改成：**一幕重彩板饱和度最高、泥金最多；二幕泥金减半；三幕石青石绿压暗两档、泥金几乎不见，朱砂开始出现在她身上。**
实现是渲染器按幕数调重彩板四个值的明度与饱和度，不再叠一层墨——那一层墨在重彩画面上会读成脏。
