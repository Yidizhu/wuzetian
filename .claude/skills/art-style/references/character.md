# 立绘规格

## 风格：水墨剪影

**面部不做写实细节。** 这是硬规定，理由有三条：

1. AI 生成的人脸在同一角色的多张图之间几乎不可能保持一致，剪影风把识别负担转移到轮廓和服饰上，这两样 AI 反而稳定。
2. 写实人脸 + 水墨背景 = 恐怖谷，两种语言打架。
3. 水墨人物画本来就不靠五官，靠的是笔势和姿态。

眉眼用一两笔淡墨点到为止。不画眼白、不画瞳孔高光、不画鼻影、不画写实嘴唇。

## 人不随色板变（E4，硬规则）

**金碧只属于场景与器物。人永远走墨色。**

立绘身上的颜色走一组**不随色板变**的变量 `--c-char-line` 到 `--c-char-4`，
值就是墨五色，两块色板下都一样。**不要绑 `--c-ink-*`**——那组是场景色板，
在金碧场景里 `--c-ink-1` 是石青。

手机实机上发现的：主角在昭阳殿里整个人被渲染成石青，和殿柱同色同位，剪影当场糊掉。
桌面上屏幕大，一时看不出来；手机上一眼就是错的。

三条推论，一起记住：

1. **一个角色在两块色板下是同一个人。** 她走进朝廷不会变成朝廷的颜色——
   这不只是技术规矩，是这个游戏的意思。金碧是「被规定好的」，人不是。
2. **唯一的暖色是那一处朱砂点。** 在金碧场景里它按老规矩转泥金
   （`var(--c-accent, var(--c-ink-4))`，D-010 硬规则 1），主角做出不可逆决定的那一刻亮回朱砂。
   身上除此以外没有第二处暖色。
3. **对照表要内联 SVG，不能用 `<img src>`。** 用 img 引进来的 SVG 是一个独立文档，
   拿不到页面的 CSS 变量，「切色板」那个按钮等于没接线——上面那个 bug 就是这么漏过去的。
   `docs/char-sheet.html` 现在是内联的。

4. **3D 人物（P2）同样适用。** 材质的颜色从 `--c-char-*` 取，不从场景色板取。
   规格与验收见 `docs/art-cc3-p2-spec.md`。
5. **人不透明。** 说话的人 `opacity: 1`，不说话的 0.93（E5）。0.94 / 0.86 那两档在金碧场景里
   会让殿柱的石青从身上透出一道来，剪影被切开——和上面那条是同一类毛病。

## 纯剪影按钮验不出的两件（E8，R-017）

对照表上一个头有手掌大；游戏里人收到竖屏四成高，头只有指甲盖大。**同一张立绘在两个尺寸下是两样东西**：

- **双环望仙髻的环心不许掏成纸色。** 两个白洞在游戏尺寸下就是两只眼睛，整个头读成一张猫脸。环心改成一道淡墨弧。
- **朱砂点不要画成圆点加一圈墨。** 在游戏尺寸下读成一朵小红花。主角的袖口朱砂改成贴着袖口的一小段横笔——角色表写的本来就是「滚边」。

验立绘从此看整屏截图（`npm run art:screens`），对照表只用来查形体。

## 尺寸与安全区

| 项 | 值 |
|---|---|
| 源图 | 1024 × 1536，透明底 PNG |
| 导出 | webp，质量 82 |
| 屏上显示高度 | 格子是视口高的 76%（桌面）/ 72%（手机）乘 `--stage-person`。3D 舞台按相机算 `--stage-person`，下限 0.62；CSS 版恒为 1 |
| 底部安全区 | 图像底部 22% 会被对话框遮住 |
| 脚落在哪 | 背景层给的 `--stage-floor`（地平线离画面底边的百分比），**下限 21%** |
| 侧边安全区 | 左右各 8%，窄屏会裁掉 |

重要信息（那处朱砂点、专属道具、发髻轮廓）必须落在安全区内。

**脚要露出来。** 地平线的下限卡在 21%，因为对话框的顶边大约在 19% 处——
再低，人就被切在小腿上，看着像半截埋进了框里。宁可让她站得比真地平线高一点点，
也不能让她没有脚。手机上人还要再放大一档（72%），上方的留白跟着收：
64% 那一版画的人只占到画面一半高，头顶上空着三分之一，而这一屏本来就窄。

## 三种表情差分

只做三种，多了做不完也记不住。

| key | 中文 | 怎么表达 |
|---|---|---|
| `default` | 常态 | 肩颈放平，袖手自然垂 |
| `guarded` | 收敛 | 肩略收，下颌微收，袖手交叠于前 |
| `open` | 松动 | 肩线放低，头微侧，一只手离开袖口 |

**表情靠肩颈角度和袖手姿态，不靠嘴型。** 这既符合水墨语言，也让三张差分可以共用同一个头部，工作量减少一半。

## 角色怎么区分

不靠脸。靠这三样，每个角色都要在设定阶段定死：

1. **剪影**：发髻形制、有无帔帛、圆领袍还是襦裙、幞头还是黄冠。远远一个黑影就要能认出是谁。
2. **墨色深浅**：每个角色占据墨五色里的一个主调。主角是浓墨，最强的对手是焦墨，女冠是清墨，等等，以下面的十一人表为准。
   主调在十一人里允许重复（墨只有五色）；**同场两人尽量错开**，撞了靠剪影和道具分人。
   （E5 更正：这一条原来写「女冠是淡墨」「同场两人的主调不能相同」，前者与十一人表和 D-040 定的清墨相反，
   后者与表下那句「主调允许重复」相反。D-040 那一轮只改了角色圣经，漏了这份。）
3. **一个专属道具**：砚、笺、剑穗、拂尘、笏板、酒盏。

## 朱砂点

**每个角色身上有且只有一处朱砂。** 它是这个角色的身份锚，位置在设定阶段定死，之后所有图都在同一位置。

候选位置：唇（一点）、腰间绦带、袖口滚边、手中的一方印、发间一支簪头、手里那张笺的朱丝栏。

选位置时想一想：这一点红在说她是谁。拿印的人和拿酒盏的人不是一种人。

**在金碧场景里，所有角色的朱砂点转成泥金。** 金碧板没有红（`palette.md` 硬规则 1）。朝廷是一个把人的欲望统一漆成金色的地方，这一条正好把美学规则和主题接上。

唯一的例外：**主角做出一个不可逆决定的那一刻，她的朱砂点亮回朱砂**，停留到这一幕结束。所以在整个第一幕的朝廷戏里，画面上唯一出现过红的时刻，就是她自己拿主意的时刻。这是全游戏最省力的叙事装置，用一个像素说清一件事。

## 一点紫：结契者的暗号（D-035）

朱砂是**每个**角色都有的身份锚，紫只属于**结契的人**，而且不是必须。规矩见 `palette.md` 的「一点紫」专节，这里只记落到立绘上的三件事：

1. 位置在**衣缘或簪头**，与这个角色的朱砂点不在同一处。本轮取簪头：D-035 写的是结契的两人互换发簪，
   簪头这一处有出处；而且衣缘画成一道线，面积反而会超过朱砂点（试过，第 2 条当场就破了）。
2. 比朱砂点更小。朱砂要被看见，紫是给认得的人看的。
3. 金碧场景里它和朱砂一样转泥金——写法同样是 `var(--c-purple, var(--c-ink-4))`。

本轮名单：**宋蕙贞**（簪头一点紫，半径 5，比她的朱砂点小一圈；她与伴侣结契多年，现分居两处）。角色圣经里其他人没有写明结契，就不加。
主角在结契之前身上不许出现紫；如果剧本走到她结契，再在这张表上加一行，不要临时决定。

## 柳承欢：两处特例（D-038）

她是第 11 人，也是唯一破了两条通则的人。两处都不是例外，是她这个人本身。

**一、guarded 不画道具。** 角色圣经写的是「空手却仍维持托纸姿势」——手还端着一份不存在的稿。
所以她的 guarded 用同一套手位，只是稿没了。别的角色三张差分共用同一件道具，她不是。
生成器里这一条叫 `hidePropOn: ["guarded"]`。

**二、另有一套无朱砂的 `_bare`。** 她的朱砂点不是她自己的东西，是主角暂借给她系稿的一根朱绳。
「归还」那一场之后（D-038 第 8 条），绳还回去了，她身上就不该再有那一点红。
文件名 `liuchenghuan_<expr>_bare.svg`，六张。除了那根绳，其余一笔不差。

**这两条是同一件事的两半**：先是手里的东西没了（guarded），最后是身上借来的东西也还了（bare）。
她剩下的是她自己，画面上就是一个没有任何记号的剪影——十一个人里只有她会走到这一步。

## 唐代服饰参考方向

考据交给 ChatGPT 的礼制表（见开发计划 6.6），这里只记美术侧要点：

- **后宫女性**：襦裙、半臂、帔帛。帔帛是最好用的剪影元素，一条飘带就能区分动静。
- **女官**：圆领袍加幞头。唐代女着男装是真实存在的制度性现象，不是穿越梗，可以放心用，而且它本身就是主题的一部分。
- **女冠（女道士）**：黄冠、羽衣、拂尘。这是唐代女性合法脱离婚姻的通道，视觉上要给足"自由"的松弛感，衣褶线条最长最软。
- **女将**：明光铠的简化剪影，但不要做金属高光，用焦墨块面表示甲片。
