## 一、立绘骨架

分两段。**公共段一批里逐字相同，一个字都不改**——D-114 那一批三张要验的是「像不像同一个世界里的人」，画风、光、底、取景、脸型的写法只要有一句不一样，三张不像就分不清是模型的问题还是提示词的问题。人物段才因人而异。

### 公共段（逐字照抄）

```
中国唐代（公元8世纪，盛唐）人物立绘。
国漫厚涂风格：颜料厚，笔触可见，笔触顺着衣褶和身体的起伏走；每块布料分出亮面、中间调、暗面三层，有体积；
色彩饱和浓郁，是矿物颜料的浓度——不是淡彩，不是水彩，不是照片。布料本身素面无纹，笔触不是布上的花纹。
全身正面站姿，平视，不仰拍不俯拍。头顶上方留出画面高度 3% 以上的空白；脚底大约在画面高度 93% 处，鞋或靴完整露出；左右留白。
中性表情，目光平视前方。
光：柔和的主光从左上方来，衣褶有明确的明暗；不画地面，脚下不投影。
竖构图 2:3。面部清晰可辨、五官完整；头（颅顶到下巴，不算发髻、冠、幞头）不小于画面高度的八分之一。

脸的形状（逐项照画）：
- 面型偏圆：颧骨处的脸宽接近发际到下巴的长度，两颊饱满，从颧骨到下巴是一道圆弧，没有折角；
- 下颌不尖：下巴底部是一段平缓的圆弧，不是一个尖点；
- 眼细长、微上挑：眼睛的长度约是睁开高度的三倍，外眼角比内眼角略高；看不见双眼皮的褶；
- 眉粗而平：眉头到眉尾差不多一样粗，几乎是一条平直的线，不弯、不挑、不细；
- 鼻梁不高：正面看不出一条从眉心到鼻尖的亮线，鼻头小而圆；
- 唇小：嘴明显比两个黑眼珠中心之间的距离窄，唇略厚，唇色自然；
- 脖子不长；
- 眼睛不描眼线：上眼皮没有一道黑色的线，眼尾没有往外挑出去的黑色延长线。
脸型参照唐代永泰公主墓壁画里宫女的脸和唐三彩女俑的脸：圆脸、细长眼、平眉、小嘴。只取脸的形状，画法仍是上面的厚涂。

硬性形制：交领右衽（从观者这边看，外层领口从画面右上斜到左下，像字母 y）或圆领；
          窄袖（袖子贴着手臂，袖口不宽于手腕的两倍）或大袖礼衣；腰间是帛带或革带，不是宽板腰封。
禁止：和服；明制立领、竖领、马面裙、飞鱼服；清宫马蹄袖、旗头；仙侠飘带、发光特效；
      蝴蝶结和两条长垂带（现代汉服商品照的系法）；披肩、斗篷；
      现代妆容（上挑眼线、卧蚕、美瞳、亮面唇釉、修容、细挑眉）；
      网红脸（尖下巴、V 脸、瓜子脸、高鼻梁、深眼窝、双眼皮大眼）；
      满布全身、不随衣褶走的装饰性笔触纹理；露肩、露胸；
      画面里任何文字、印章、签名、水印。
```

## 二、背景骨架（E13 重写：和立绘共用一段画风）

**背景和立绘是两张图拼成的一屏**，到 E12 为止两套提示词是各写各的，合不合得上从来没验过（D-118）。所以背景也分两段，而且**画风那两行（「国漫厚涂风格……」「色彩饱和浓郁……」）和立绘公共段逐字相同，光向那一句用同一个说法**——这几句只有一份原文，改一处两处一起改。

### 背景公共段（逐字照抄；画风两行与立绘公共段相同）

```
中国唐代（公元8世纪，盛唐）宫廷场景图，横构图。
国漫厚涂风格：颜料厚，笔触可见，笔触顺着衣褶和身体的起伏走；每块布料分出亮面、中间调、暗面三层，有体积；
色彩饱和浓郁，是矿物颜料的浓度——不是淡彩，不是水彩，不是照片。布料本身素面无纹，笔触不是布上的花纹。
光：柔和的主光从左上方来，物体有明确的明暗。
画面上有一层很细的布面纹理，和人物立绘上的一样。

这是一张给人物立绘做背景的图：
- 画面中无人物。人物之后会单独叠在画面前景，站在画面下方，身高约占画面高度的六成。
- 平视，相机高度约一人眼高，视平线在离画面上边约三分之一处；地面占画面下方大半。
- 近处没有东西。建筑、器物都在几步开外的中景与远景，按一个一米六的人比，门、柱、案的大小要对。
- 画面中央三分之一宽度、从画面底边往上到一半高度，是一片完整、平整、安静的地面：不放器物、没有光斑、没有强烈的明暗对比——人物要站进去。
- 手机竖屏只看得见画面中间三成宽，这一条要自己成立：只看中间一条也看得出是什么地方。
- 背景比人物低一档：明暗对比弱一些，细节少一些，边缘软一些；颜料浓度与笔触和人物一样，不能一个厚涂一个水彩。
- 墙、木、砖、布本身素面无纹，笔触不是物体表面的花纹。

禁止：任何文字（匾额、屏风、纸上、门牌上都不许有字；匾额和门牌是空的）；椅子、高桌、太师椅、明清家具；成串红灯笼；
      盘龙金柱、大红大金；日式障子门、榻榻米、鸟居；玻璃、现代灯具、电线；地面镜面反光；
      景深虚化、镜头光斑、发光、体积光柱、漂浮粒子、飘落花瓣；人物、人影、动物；签名、水印、边框。
```

**哪几句和立绘一样、为什么**：
- 画风两行逐字照抄，连「衣褶」「布料素面」也不改——背景里也有帷幔、帘、地衣，这两句一样成立；改成背景自己的说法，就又是两套原文。
- 光向用同一个说法「柔和的主光从左上方来」，是人和殿明暗对得上的前提；立绘那一句后半的「衣褶」「不画地面，脚下不投影」背景不要。
- 「一层很细的布面纹理」立绘提示词里没写，是**三张立绘实际画出来的样子**（放大看布面上有细的斜纹理）。背景要跟着实物走，不跟着提示词走。

### 场景段

```
地点：[实指]，[色板：重彩／素彩]，白天[时辰]。
颜色：[这一板装什么颜料；素彩写「颜料一样厚，只是颜色种类少」]。
建筑：[柱、墙、梁、窗、瓦、地面，具体到形状和颜色]。
光：[从左边哪一处进来，色温，影子的样子]。
器物：[两三件，具体到形状，放在画面左右两侧或后方]。
无字的那一处：[scene.md 表里「无字碑母题的落点」]。
[这一张专有的禁止]
```

### 其他

- **默认只画日景**（D-107）：夜场由引擎在同一张图上套冷暗滤镜。**例外：苑野出一张真夜景，不套滤镜**（D-121，E14）——B18 整屏证明滤镜把苑野压成了黄昏；它是全剧十三场、最多的户外场，值得一张专门的图。其余夜场仍用滤镜。
- **尺寸**：生成参数 1536×1024（横 3:2），后处理只缩不放（`art:post -- scene`）。原件 `assets/scenes/<key>_v<N>.png`，`<key>` 就是背景表 `src/scene/backdrops.ts` 的键。
- **平视**：scene.md 里「低机位仰视柱列」「轻俯视」是 3D 舞台的机位（D-106 已停投），光栅背景一律平视——仰视的殿配平视的人，人会像贴在墙上。
- **「色板」在光栅图里是什么**：`gold` 画成**重彩**（石青、石绿、泥金铺开，柱铅丹，朝廷的地方）；`ink` 画成**素彩**（木色、白壁、赭、淡石绿，颜色种类少，她的地方）。**素彩不是淡彩**：颜料一样厚、一样浓，只是用的颜色少——不然背景是水彩、人是厚涂，一屏两种画。

### 四种类型怎么分的

D-143 定了三段（她的本行、她为主角做了一件事、亲密），D-148 最要紧的一条是「主角要有欲望」。C32 给四条线各选了一个 CG 位置，恰好是四种不同的表达形式（沉默、身体、玩笑、物件）。把两件对上：

| 张 | 类型 | 哪条线 | C32 的形式 | 画的那一刻 | 画面里谁先动 |
|---|---|---|---|---|---|
| 1 | **注意到她**（D-143 第一段的意思：主角第一次真的在看她） | 温荞 ch01-15 | 玩笑 | 猜纸时偷睁一只眼，温荞把纸藏到身后笑得收不住，两人对看 | 主角偷看 |
| 2 | **她为主角做了一件事** | 李令仪 ch01-16 | 物件 | 主角把她碰过的叶子收进素帕，她另递一片断梗叶，眼睛看着那截袖口 | 主角先收 |

**文件名的「第几张」**：1 本行／注意到她、2 为主角做的事、3 亲密、**4 主角先想要（E21 加）**。

### 亲密那张为什么挑裴照夜（这一条是我定的）

1. **四处里只有她这一处真的有触碰。** 沈衡样稿写明「不画覆手」，温荞是对看，李令仪是递物、指尖不碰。D-143 的亲密范围是身体的靠近与触碰，**只有握手在范围里**。
2. **C32 给她定的形式就是「身体」**，而且样稿写明是主角先翻掌要握（「这只手，给我握一会儿」）、裴照夜放下衣带主动递手——**双方都有动作，不是跌倒扶一把，也不是误碰**。亲密那张要的正是两个人都愿意。
3. **这张是全批最难画的**：两只握着的手叠在一起，每只五根手指要看得出是谁的。双人硬否决（手逐只数）最该在它身上先试一次；如果握手都画不对，后面额头相抵、同盖一件衣服那一类更画不对。
4. 顾虑说一句：裴照夜已经有一张驯马了，这一批她又占亲密那张，四条线里她先有两张。沈衡、温荞、李令仪的亲密那张以后各自补，这一张是**先把亲密这个类型试出来**，不是说她的线最重。

### 四张共同的写法

- **位置和手都从样稿原句来**：沈衡「扶住凳沿坐下，手还没去拿卷」「手仍护着卷」；裴照夜「掌根贴过来」「拇指在你虎口停着」；温荞「两张纸都藏到身后」；李令仪「捡起一片断梗的，递到你面前。眼睛却还看着你的袖口」。
- **每张都写了主角的视线**（D-144）：她在看沈衡的脸、看裴照夜的脸、追温荞的目光、看李令仪的脸。**四张里对方的视线各不相同**：沈衡看她、裴照夜看两人的手、温荞看她那只睁开的眼、李令仪看她的袖口。
- **手逐只写**：沈衡那张看得见三只（沈衡左手在案下）；温荞那张两只（温荞的手背在身后）；裴照夜、李令仪各四只。
- **这一张专有的禁止**里，把每一张最可能被模型「加戏」的方向写死：沈衡不许覆手拥抱；裴照夜的衣带不许画成捆绑、不许湿身；温荞不许画成做活计或天女；李令仪的叶子不许发光心形、不许画成信物。
