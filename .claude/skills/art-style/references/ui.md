# UI 与排版

UI 遵守双色板，并且**随当前场景的色板整体切换**：水墨场景里界面像一张宣纸上的墨迹，金碧场景里像一幅绢本上的题记。切换靠根元素的 `data-palette` 属性，组件只认 CSS 变量名，代码不需要知道自己在哪套色板里。见 `palette.md`。

无论哪套色板，界面都不应该看起来像一个盖在图上的应用。

## 对话框

不用矩形框。用宣纸卷轴的一段：

- 上下各一条淡墨横线，**没有左右边框**。左右不封口，画面才透气。
- 底色用 `--c-ground`（水墨场景是纸，金碧场景是绢），不透明度 92%，让背景隐约透上来。
- 不要圆角超过 4px，不要阴影，不要毛玻璃。
- 角色名不放在框内的小标签里，放在上边线之上、左对齐、浓墨、比正文大一号。

## 选项

竖排。每项左侧一条短墨线（像题跋的起首），文字浓墨。

- 未选中：短线淡墨
- 悬停/按下：短线转浓墨
- 选定的一瞬间：短线位置亮起一个朱砂点，停留 400ms 后随场景一起淡出。**金碧场景里这一点朱砂尤其重要**，它是朝廷画面上唯一的红，等于在说这一步是她自己决定的
- 条件不满足：整项转清墨，右侧用淡墨小字标出缺什么（比如「才 不足」），不要只是灰掉不给理由

## 状态条

**不用进度条。** 势、名、才、心四项各是一根竖直的墨线，**用墨色浓淡表示高低**：值低是清墨，值高是焦墨。

这样做有两个好处。墨色本身就是数值，符合美学而不是硬贴上去的；同时它天然模糊，玩家能感到趋势但读不出精确数字，这正好压掉"刷数值"的冲动，让注意力回到关系上。

四根线排在右上题跋区，下方各一个小字标注。数值变化时那根线做一次墨晕扩散，不做数字弹出。

## 字体

思源宋体（Source Han Serif SC），必须子集化。全量中文 woff2 有数兆，手机上直接劝退。用剧本全文扫描出字符集再生成子集，构建期跑一次。

| 用途 | 字号 | 行高 | 颜色 |
|---|---|---|---|
| 对话正文 | 17px | 1.9 | 浓墨 |
| 角色名 | 19px | 1.4 | 浓墨 |
| 旁白/内心 | 16px | 1.9 | 淡墨，行首缩进两字 |
| 诗词 | 18px | 2.1 | 浓墨，居中，字间距 0.08em |
| 题跋/落款 | 15px | 1.6 | 淡墨 |

行高 1.9 对中文长段是偏松的，这是刻意的，和留白原则一致。诗词单独放宽到 2.1 并加字距，让它在视觉上从散文里跳出来。

不用无衬线体。不用居中的大标题。不用现代卡片式布局。

## 转场

**转场用「墨晕开」，不用淡入淡出。**

实现是一个 radial mask 加噪声，从画面某一点向外扩散，边缘不规则。时长 300 到 450ms，缓动用 `cubic-bezier(0.22, 0.61, 0.36, 1)`。

场景切换从画面中心扩散；进入回忆或诗词段落从主角所在位置扩散；进入结局从无字碑的位置扩散。

数值变化、好感升级、诗词判定，各自的反馈动效都用同一个墨晕，只是尺度不同。全游戏只有这一种动效语言，越统一越像一个作品。

## 题画（D-014）

玩家把这一刻存成一张 3:4 的图。**版式是立轴，不是截图。**

截图带着对话框、状态条和按钮，那是「游戏的界面」；题画要的是「她这一刻的样子」。
`composition.md` 的主体偏左下、题跋区在右上，本来就是立轴的布局，所以这张图不用另设计版式。

| 部件 | 规矩 |
|---|---|
| 幅面 | 900 × 1200（3:4）。竖的，因为立轴是竖的 |
| 画心 | 偏左下，四周留边。只用一条淡墨细线框住，**不做裱框**——框会把画变成商品 |
| 立绘 | 底对齐画心下沿，两人一高一低、一前一后，绝不左右对称摆 |
| 题诗 | 右上竖排，从右往左，浓墨。最多四句 |
| 落款 | 接着诗往下写，同一列，小一号、淡一档 |
| 印 | 款的末尾一枚。全图唯一的红，面积约占千分之三 |
| 纸纹 | 最后压在所有东西上面，整张才像画在一张纸上，而不是几层图叠出来的 |
| 底色与印色 | 跟当前场景的色板走。**金碧场景里印转泥金**，和立绘的朱砂点同一条规则 |

保存：手机上「存相册」靠长按图片，`<a download>` 在 iOS Safari 上不可靠，所以两条都要给——
一个存图按钮，外加一行「长按图片可存进相册」。

## 移动端

- 触控目标最小 44×44px，选项之间垂直间距不小于 12px。
- 竖屏为主。横屏时不放大立绘，而是加宽留白。
- 首屏加载目标两秒内，字体子集和首个背景要 preload。
- 系统深色模式不做反色，见 `palette.md`。
